11月の買い物は毎年荒れる。半額、70%オフ、90%オフという数字が一斉に並び、日頃は手が出ない価格のものが急に手の届くところまで降りてくる。その熱に当てられて、その場のノリで買ったものが年明けに一度も開かれないまま並んでいる、というのを何度か繰り返してきた。

反省の結論ははっきりしていて、**失敗の原因はセール当日ではなく、その前の準備にある**。何が足りていないのかを決めないまま値札だけを眺めれば、安いものを買うのではなく、安く見えるものを買うことになる。だから計画は10月のうちに立てておきたい。この記事では、2026年のブラックフライデーまでに何を整理しておくべきかを、日程の読み方、環境の棚卸し、値下がりの傾向、価格表示の見方という順番でまとめていく。

## 2026年のブラックフライデーは11月27日、ただし当日はあまり関係ない

<figure class="photo photo--left">
<img src="/images/bf-plan/black-friday-sign-rotterdam.jpg" width="220" height="124" alt="路上に置かれた「BLACK FRIDAY SALE」と書かれた黒い立て看板と、その奥の衣料品のラック" loading="lazy">
<figcaption>街頭に出るセールの立て看板。11月の恒例になって久しい</figcaption>
<span class="credit">Photo: Donald Trung Quoc Don / Wikimedia Commons (CC BY-SA 4.0)</span>
</figure>

ブラックフライデーはアメリカの感謝祭の翌日にあたる。感謝祭は11月の第4木曜日なので、2026年は11月26日が感謝祭、**11月27日(金)がブラックフライデー、11月30日(月)がサイバーマンデー**ということになる。ここまでは暦の計算で確定する話だ。

ところが、この日付を手帳に書いて当日を待つのは、実はあまり意味がない。音楽制作まわりのソフトウェアに関して言えば、**セールが始まるのは当日ではなく、3週間から4週間ほど前**だからだ。2025年の例を思い出すと、10月末には早期アクセスという名目で大きなバンドルが動き始めていたし、11月の第1週にはすでにいくつものメーカーが値下げに入っていた。大手の「サイバーシーズン」のような長期キャンペーンは11月半ばに始まって12月半ばまで続いていたし、年明けの1月初めまで値段が戻らなかったバンドルもあった。

つまり実務上の買い時は、金曜の1日ではなく、**おおよそ11月の頭から12月の第1週まで、長いものは年明けまで**という幅のある期間になる。「ブラックフライデーを逃した」と焦る必要はあまりないし、逆に言えば11月に入った時点でもう判断を求められているということでもある。10月のうちに準備しておくべきだという話の根拠はここにある。

一方、国内の通販セールはもう少し動きが違う。Amazon.co.jpの場合、ここ数年は11月下旬に先行セールを数日はさんでから本セールに入り、8日間ほどで終わるという形が続いてきた。2023年は11月24日から12月1日、2024年は11月29日から12月6日、2025年は11月24日から12月1日という具合だ。ただし2025年は本セールの開始が月曜になっていて、「金曜に始まる」という前提はすでに崩れている。**2026年の日程は現時点では発表されていない**ので、予想を見かけても確定情報として扱わないほうがいい。11月の中旬には公式の案内が出るはずなので、それを待って最終的な予定を組めば十分間に合う。

国内の楽器店・機材店はさらにばらつきがある。楽器系の通販では値引きではなくポイント還元の形をとることが多く、しかも在庫品限定という条件が付くことがある。輸入代理店が担当ブランドごとに独自のセールを張ることもあって、こちらは海外本国のセールより早く始まり、終わるのも早い場合がある。要するに締め切りは店ごと・ブランドごとにばらばらで、「11月27日まで」という一本の線は存在しない。

## 買う物を決める前に、自分の環境の穴を洗い出す

<figure class="photo photo--right">
<img src="/images/bf-plan/home-studio-cluttered.jpg" width="220" height="146" alt="機材とケーブルが棚いっぱいに積み上がった狭い自宅スタジオ。キーボード2台とミキサー、マイクが並ぶ" loading="lazy">
<figcaption>増やし続けた結果の部屋。足りないものより、使っていないものが先に目につく</figcaption>
<span class="credit">Photo: Dai Stanton / Wikimedia Commons (CC BY-SA 2.0)</span>
</figure>

計画の出発点は値札ではなく、自分の環境のほうだ。この順番を逆にすると、安くなっているものの中から欲しい理由を後付けで探すことになる。先にやるべきは、いま制作が止まる場所、やり直しが発生する場所、面倒で避けている作業を思い出して、箇条書きにすることだと思う。

書き出してみると、意外と上位に来るのはプラグインではない。音を判断できない部屋で延々とミックスをやり直している、録音のたびにケーブルを挿し替えている、プロジェクトを開くのに時間がかかる、といった地味な問題のほうが時間を食っている。そして厄介なことに、**この種の問題を解決するものほど、11月に安くならない**。

とくに部屋の音響処理は、セールとほとんど縁がない分野だ。吸音材やベーストラップを扱うメーカーは、11月だからといって大きく下げてこない。むしろ秋口に出る固定額のクーポンのほうが条件がよかった、ということすらある。一方でソフトウェアは半額から9割引まで下がる。この落差があるせいで、**セールの構造そのものが、本当に効く買い物から人を遠ざける方向に働いている**。ここは自覚しておいたほうがいい。

しかも音の環境を良くするうえで最も効果が大きい手当ては、お金がかからない。スピーカーの置き場所と左右の対称性、壁からの距離、耳の高さに合っているかどうか。ここを直すのが先で、吸音材はその次だ。横に向けて置かれたスピーカー、部屋の隅に押し込まれたスピーカー、左右で条件の違う配置——このあたりを放置したまま新しいモニターを買っても、価格差のぶんの違いは聞き分けられないと思う。薄いウレタンのパネルを壁に貼るだけ、というのも落とし穴で、高音ばかり吸って低音は残るので、こもった割に低域は暴れたままという状態になりやすい。

機材のほうにも、同じように「買い替える条件」を先に決めておくと迷いが減る。たとえばオーディオインターフェイスなら、入出力の数が足りない、プリアンプのノイズやヘッドルームに不満がある、ドライバが落ちる、OSやDAWの更新に付いてこられなくなった——このどれかに当てはまるなら買い替えの価値がある。逆に言えば、どれにも当てはまらないのに新型が3割引だからという理由で入れ替えても、作業はたぶん何も変わらない。

ソフトウェアについては、ひとつだけ質問を用意しておくと効く。**「これを半年後もプロジェクトで開いているか」**。この問いに具体的な場面を思い浮かべて答えられないものは、だいたい買わなくていい。EQを何十種類も持っていても普段使うのは2つ3つ、コンプレッサーも同じ、というのはよくある話で、増やしたぶんだけ迷う時間が増えるという副作用もある。

同じ「セール」でも、分野によって下がり方はまるで違う。ここを頭に入れておくと、待つべきものと待っても無駄なものを事前に仕分けられる。過去数年の傾向をざっくり整理すると、おおむね次のようになる。

| 対象 | 値引きの目安 | 判断 |
|---|---|---|
| ソフトのバンドル | 70〜95% | 11月に買う価値がある。ただし中身の精査が必須 |
| ソフトの単品 | 20〜80% | メーカーによって差が大きい |
| SSD・ストレージ | 20〜40% | 年間でも最安になりやすい。買うなら11月 |
| 一般向けヘッドホン | 25〜60% | 下げ幅は大きい |
| 定番のスタジオヘッドホン | 15〜30% | 悪くないが、年間最安とは限らない |
| シンセ・グルーヴボックス | 10〜50% | 旧仕様の在庫ほど深い |
| 普及価格帯のモニター | 20〜25% | 11月向き |
| 上位クラスのモニター | 0〜10% | 待っても下がらない |
| MIDIコントローラー | 10〜35% | 安価な機種ほど率が大きい |
| オーディオインターフェイス | 10〜20% | 率は小さい。付属ソフトで埋める形が多い |
| 定番マイク | 10〜15% | 率は小さく、年中そこそこ安い |
| 吸音材・音響処理 | ほぼ0〜10% | 11月を待つ意味がない |

ソフトウェアの9割引という数字は、ほぼ例外なくバンドルで出てくる。単品で8割を超えることは滅多にない。そして**バンドルは後悔の最大の発生源**でもある。60本入りで9割引と言われると得に見えるが、実際に開くのはそのうち数本で、残りはリストを長くするだけということが起きる。月曜日に開くものを買う、博物館を作らない、というくらいの基準でちょうどいいと思う。

メーカーごとの性格の違いも大きい。たとえばリバーブで知られるValhalla DSPは、値引きを一切しない方針を公言していて、全プラグインが通年で同じ価格に据え置かれている。安くなるのを待つという選択肢がそもそも存在しない。FabFilterは逆に毎年きっちり25%引きを出すが、**夏にも同じ25%のセールをやる**ので、11月まで待つ必然性は薄い。しかも購入本数に応じた割引が積み上がる仕組みがあり、本数が増えるほど単品で買ったほうが有利になる場面がある。

DAWも性格が割れている。Logic Proは一度も値引きされたことがなく、買い切りで更新が無料という形を通している。FL Studioは生涯無料アップデートを掲げていて、11月は3割前後、アップグレードは半額まで下がる年があった。Ableton Liveは本体25%・ハードウェア20%あたりが相場で、派手ではないが毎年ある。一方でCubaseは、**そもそも11月にセールをしない**。新バージョンの発売が11月前後に重なるためで、大きく下がるのは夏と9月だ。2026年も9月に4割引のセールが終わったばかりで、ここを逃した人が11月に期待しても何も起きない可能性が高い。

ハードウェアで素直に得をしやすいのはSSDだ。大容量のNVMeは年間の最安値が11月に出ることが多く、サンプルライブラリの置き場所に困っているなら、ここは迷わず11月でいい。シンセやグルーヴボックスも下げ幅が大きいが、深い値引きが付いているのはたいてい後継機が出た旧仕様の在庫だという点は意識しておきたい。それが問題にならない買い物なら、むしろ好機ではある。

## 「◯％オフ」をそのまま信じない

<figure class="photo photo--right">
<img src="/images/bf-plan/black-friday-crowd-nyc.jpg" width="220" height="146" alt="ブラックフライデーの朝、店舗前の歩道を埋め尽くす大勢の買い物客" loading="lazy">
<figcaption>数字が大きいほど冷静さが要る、というのは実店舗でも通販でも同じ</figcaption>
<span class="credit">Photo: JoeInQueens / Wikimedia Commons (CC BY 2.0)</span>
</figure>

表示されている割引率は、そのまま受け取ると二重に裏切られる。ひとつは比較の土台のほう、もうひとつは還元の形のほうだ。

まず土台の話から。通販サイトに出ている「参考価格」は、必ずしも普段の販売価格ではない。セールの直前に参考価格だけを引き上げて、値引き幅を大きく見せるというやり方が実際に行われていて、人気商品の価格推移をまとめて追いかけた報告では、**セール品のうち3割ほどがこの種の見せかけだった**という結果も出ている。景品表示法の二重価格表示に触れうる行為なので全部がそうだとは言わないが、数字を信じる根拠にはならない。

対抗手段はひとつしかなくて、**参考価格ではなく、直近30日の最安値と比べる**こと。価格推移を記録しているサービスを使えば、その商品が過去1年どのくらいの値段で売られてきたかが一目でわかる。音楽ソフトについても同じことができるサイトがいくつかあり、「過去最安がいつ、いくらだったか」まで追える。10月のうちに候補をリストに入れて、通常価格と過去最安を書き写しておけば、11月に出てきた数字が本物かどうかを数秒で判断できるようになる。この作業が今回いちばん効く準備だと思う。

もうひとつが還元の形だ。日本の小売では「最大20%ポイント還元」のような打ち出しが多いが、**これは20%引きではない**。1,000円の買い物で20%分の200ポイントが付いた場合、1,000円の支払いで最終的に1,200円分のものを手にすることになるので、実質の値引き率は200÷1,200で約16.7%になる。計算式としては、還元率をrとすると実質はr÷(1+r)だ。10%還元なら約9.1%、30%還元なら約23.1%。**同じ数字なら、現金値引きのほうが必ず有利**ということになる。

しかもポイントには有効期限があり、期間限定ポイントなら使い道も限られる。失効させてしまえば実質の値引き率はさらに下がるし、1ポイントが必ず1円として使えるとも限らない。ポイント中心の店と値引き中心の店を比べるときは、この換算を一度挟んでから並べたほうがいい。家電量販店の20%還元より、通販の15%引きのほうが有利だった、というのはふつうに起こる。

## 11月を待たないほうがいいもの

セールを待つ、という判断そのものが損になる場合もある。いくつか典型を挙げておきたい。

**年中安いもの**。プラグインの中には、11月を待たなくても定期的に同じ値段まで下がるものがある。単品が通年で30ドル前後に据え置かれていて、年に何度も全製品が同じ価格に揃うメーカーもあり、この手のものを定価で買う理由はそもそもない。11月に追加されるのは複数本をまとめたときの割引だけ、ということも多い。

**11月より12月のほうが安いもの**。年末のホリデーセールがブラックフライデーと同じか、それ以上の値引きになるメーカーは珍しくない。11月に9割引だったものが、12月末には9割2分になっていた、というようなことが起きる。大型のバンドルが年明けまで同じ価格で売られ続けることもある。ここで焦って11月に飛びつく必要はない。

**発売直後のもの**。新製品はセールの対象から外れる。発売から半年経っていない製品は大きな値引きの対象にしない、と明文化しているメーカーもあるし、音源ライブラリでは発売1年以内のものだけ値引き率を低く抑える運用が一般的だ。つまり**発売時の導入価格が、しばらくの間はその製品の最安値になる**。欲しい新製品があるなら、11月を待つより導入価格のうちに決めたほうがいい。

**分割で買うもの**。月額を払い続けて最終的に自分のものになる、という買い方は、セール価格が適用されない。定価で分割しているのと同じなので、半額になっている期間でも支払総額は変わらない。支払いが止まればソフトも使えなくなる。11月に一括で買えるなら、そのほうがほぼ確実に安い。

**定番のスタジオ用品**。長く作られ続けている定番のヘッドホンやマイクは、年間の最安値が11月以外に出ることがよくある。春先や初夏に過去最安を記録していた、というのはごく普通に起こる。この種のものは「11月が最安」と決めつけず、欲しくなったときに価格推移を見て判断すればいい。

## 型落ちと、買ったあとに効いてくる条件

値引き率の次に見ておきたいのが、買った直後に後悔しないための条件だ。

まず製品サイクル。オーディオインターフェイスはおおむね3年から4年で世代が変わる。たとえば定番シリーズの第2世代が2016年、第3世代が2019年、第4世代が2023年という間隔で来ているので、2026年の時点で現行世代はそれなりに時間が経っていることになる。後継の発表は誰にも予告できないが、「深い値引きが付いている=入れ替え前」である可能性は常に頭に置いておきたい。型番にMk IIが付いた製品が出たあと、無印が大きく下がるのも同じ構図だ。

逆に、サイクルをほとんど気にしなくていい分野もある。1991年の設計がいまも現行品として売られているヘッドホンや、何十年も型番が変わらないマイク、長く定番の座にある普及価格帯のモニター。この手のものは買った翌月に新型が出る心配がほとんどない。値引き率は小さいが、長く使えるぶん総額では悪くない買い物になる。

**ポイントやクレジットの期限**も見落としやすい。通販サイトで貯まる購入額の数%が残高として戻ってくるタイプのものは、**1年で失効する**ことがある。何か買えば期限が延びる仕組みになっていることが多く、結果として「期限が切れる前に何か買う」という行動を誘発する。11月に残高があるなら使い切る前提で計画に入れ、逆に残高を作るためだけに買い足すのは本末転倒だと考えたほうがいい。無料配布のプラグインも期間が極端に短いことがあるので、気になるものがあれば受け取りだけ先に済ませておくといい。

**ライセンスの扱い**も確認しておきたい。ドングル管理のプラグインは譲渡に手数料がかかるし、教育版や非売品ライセンスはそもそも譲渡できない。中古で安く手に入れたつもりが、後から正規の経路でないことが判明して面倒になるという話もある。安さだけを見て経路を選ばないほうがいい。

海外から直接買う選択については、円が弱い時期は旨味が薄い。海外のストアで表示されている価格に消費税が乗ると、国内の代理店経由とほとんど変わらないか、むしろ高くなることがある。国内で買えば日本語のマニュアルとサポートが付き、楽器店独自の保証が付く場合もある。機材の個人輸入についても、関税は楽器類なら基本的にかからないが消費税は課税価格に対してかかり、初期不良の対応は海外の販売店と直接やりとりすることになる。差額が数千円なら、国内で買うほうが結果的に安く付くことが多いと思う。

もうひとつ、2026年に関しては業界側の再編も重なっている。大手メーカーの経営形態が年初に変わり、長く一緒に売られてきたブランドが別の会社に移るといった動きがあった。既存のライセンスやダウンロードはそのまま使える形になっているが、**これまで毎年同じ組み合わせで行われてきた合同セールが、同じ形で来る保証はない**。去年の構成を前提に予定を組まないほうが安全だ。

## 欲しい物リストの作り方

ここまでを踏まえて、10月のうちにやっておく作業を手順にしておく。紙でも表計算でも何でもいいが、形に残しておくことが大事だと思う。

1. **穴を書き出す** — 制作が止まる場所、やり直しが起きる場所、面倒で避けている作業を10個ほど列挙する。製品名は一切書かない。
2. **優先順位を付ける** — 置き場所の調整のように無料で直せるものを最上位に。次に時間を食っている問題、最後に「あると気分がいい」もの。
3. **穴ひとつに候補ひとつ** — 同じ用途の候補を複数並べない。迷っているなら、それはまだ必要になっていない。
4. **通常価格と過去最安を書き写す** — 候補ごとに、いまの価格と過去1年の最安値、そしてそれがいつだったかを記録する。これが11月の判断基準になる。
5. **目標価格と上限額を決める** — 「この値段まで下がったら買う」をあらかじめ書く。さらに全体の予算の上限も決めて、合計がそれを超えるならリストのほうを削る。
6. **待つものを分ける** — 吸音材、上位クラスのモニター、定番マイクのように11月が最安とは限らないものは、「11月枠」から外して別のタイミングに回す。
7. **リストにないものは買わない** — これが最後にして最大の項目になる。どうしても気になるものが出てきたら、その場で買わずに翌日まで置く。翌日も同じ気持ちなら、リストのどれかと入れ替える。

この7項目の中で、実際に効くのは4番と7番だと思う。価格の記録があれば「安い気がする」という感覚を数字で潰せるし、入れ替え制にしておけば総額が勝手に膨らまない。逆に言うと、この2つが無いままセール期間に突入すると、あとは雰囲気で決めることになる。

## まとめ

計画の要点を整理しておく。

| 項目 | 結論 |
|---|---|
| 2026年の日程 | ブラックフライデーは11月27日(金)、サイバーマンデーは11月30日(月) |
| 実際の買い時 | ソフトは11月頭〜12月第1週。長いものは年明けまで |
| 国内通販 | 例年は11月下旬に先行+8日間ほど。2026年の日程は未発表 |
| 最初にやること | 製品名ではなく、自分の環境の穴を書き出す |
| 11月向き | ソフトのバンドル、SSD、普及価格帯のモニター、ヘッドホン |
| 11月を待たなくていい | 吸音材、上位クラスのモニター、定番マイク、年中安いプラグイン |
| 割引率の見方 | 参考価格ではなく直近30日の最安値と比べる |
| ポイント還元 | 実質は r÷(1+r)。20%還元は約16.7%引き |
| 買う直前の確認 | 後継機の有無、ライセンスの譲渡条件、残高の有効期限 |

結局のところ、セールで得をするかどうかは11月の判断力ではなく、10月の準備で決まってしまう。足りないものが先にわかっていれば、割引率はそれを買うかどうかの材料のひとつに過ぎなくなる。逆に準備がなければ、割引率そのものが買う理由になってしまう。

去年の自分の買い物を振り返って、いま手元で動いているものと、そうでないものを分けてみるのがいちばん早い準備かもしれない。動いていないものがなぜ動いていないのかを一度考えておけば、今年の11月は少し静かに過ごせると思う。
