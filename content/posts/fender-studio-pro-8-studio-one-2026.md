2026年1月13日、PreSonusのDAWとして長く親しまれてきたStudio Oneは、Fender Studio Pro 8という新しい名前で再出発した。バージョン番号はStudio One 7の続きの「8」で、中身がまったく別のソフトに入れ替わったわけではない。それでも、毎日ソフトを開くたびに見慣れないロゴが出てくると、何が残って何が変わったのかが気になってくる。

改名から9か月ほどがたち、6月には最初の大きな更新である8.1も届いた。この記事では、Studio Oneから引き継がれた操作の流れと、Fenderの名前になって新しく加わった機能、そしてFender Motionというコントローラーを買うとStudio Proが付いてくる仕組みまでを、Studio Oneから移る人の目線で整理していく。

## 1月13日、名前と売り方がまとめて変わった

<figure class="photo photo--left">
<a href="https://fenderstudiopromanual.fender.com/" target="_blank" rel="noopener"><img src="/images/fender-studio-pro/presonus-namm.jpg" alt="2014年のNAMMショーのPreSonusブースで、Studio One Artistを含む制作セットをモニタースピーカーとMIDIキーボードとともに展示している様子" width="220" height="147" loading="lazy"></a>
<figcaption>2014年のNAMMショーで展示されたPreSonusの制作セット。看板にはまだStudio One Artistの名前がある<span class="credit">Photo: Matt Vanacoro / CC BY 2.0</span></figcaption>
</figure>

PreSonusは2021年にFenderの傘下に入っていて、今回の改名はその流れの延長にある。スピーカーのErisシリーズやデジタルミキサーのStudioLiveなど、ハードウェアには引き続きPreSonusの名前が残る一方で、DAWだけがFenderの名前を名乗ることになった。あわせて、製品の登録やライセンスを管理するアカウントも、これまでのMyPreSonusからMyFenderへ移されている。

売り方もかなり整理された。Studio OneにはArtistとProfessionalという価格帯の違うエディションがあり、どちらを買えばいいのか迷う人が多かったと思う。Fender Studio Pro 8では有料版が一本にまとまり、買い切りのライセンスが199.99ドル、Studio One 6や7からの乗り換えは99.99ドルで用意されている。エディションごとに使える機能を見比べる手間がなくなったのは、素直にありがたい変化だと感じている。

サブスクリプションも名前が変わり、これまでのStudio One+はFender Studio Pro+になった。料金は月額19.99ドル、年額なら179.99ドルで、買い切り版のライセンスと追加のサービスがまとめて付いてくる形だ。また、これとは別に、16トラックまで録音でき、アンプやエフェクトも使える無料のFender Studioというアプリが、スマートフォンやタブレット、パソコン向けに配られている。無料版で曲の骨組みを作り、続きをStudio Proで仕上げるという入り口が、Fenderの側から用意されたことになる。

## Fenderのアンプが、最初からDAWの中に入っている

<figure class="photo photo--right">
<a href="https://www.amazon.co.jp/s?k=Fender+Rumble+100&tag=nakimoto1-22" target="_blank" rel="noopener sponsored nofollow"><img src="/images/fender-studio-pro/rumble-100.jpg" alt="床に置かれたFender Rumble 100ベースアンプのコンボ。銀色のグリルにFenderのロゴが付いている" width="220" height="165" loading="lazy"></a>
<figcaption>FenderのベースアンプRumble 100。Studio Pro 8には、このRumbleの名前を冠したベースアンプのモデルが入っている<span class="credit">Photo: Elmschrat / CC BY-SA 4.0</span></figcaption>
</figure>

改名でいちばん分かりやすく変わったのは、ギターとベースの音作りだと思う。Studio Pro 8には、Fenderのデジタルアンプの系譜を受け継いだMustang Nativeと、ベースアンプのRumbleを元にしたRumble Nativeという2つのプラグインが標準で入っている。どちらもアンプのモデルに加えて、歪みやモジュレーション、空間系のエフェクトをまとめて備えていて、ギターやベースをオーディオインターフェースにつなぐだけで、Fenderらしい音色で録り始められる。

Studio Oneにも以前からAmpireという自社製のアンプシミュレーターがあり、宅録のギターには十分使えるものだった。ただ、Fenderのアンプの名前と音の方向性を、そのままDAWの中で選べるというのは、Fenderの傘下に入った意味がもっとも分かりやすく出た部分だと感じる。ギタリストやベーシストが、別売りのアンプシミュレーターを買い足す前に、まず付属のものだけでどこまで行けるかを試せるようになった。

もう一つうれしいのは、無料のFender Studioアプリと同じアンプやエフェクトの考え方が共有されている点だ。スマートフォンで録ったギターのアイデアを、音色の設定ごとStudio Proに持ち込める。外出先で思いついたフレーズを、家に帰ってから同じ音で続きを作れるのは、宅録をしている人にとっては地味に効いてくる便利さだと思う。

## 音声を音符に変える機能と、8.1で加わったもの

ギター以外で目立つ新機能は、録音した音声を音符のデータに変換するAudio-to-Noteだ。歌や楽器のフレーズを録ったあとで、その音の高さと長さを読み取り、ピアノロールの音符として取り出せる。鼻歌で浮かんだメロディを録っておき、あとからシンセサイザーの音色に置き換える、といった使い方がしやすくなった。

コード進行を考えるための支援機能も強化された。Studio Oneの時代からあったコードトラックに加えて、次に置くコードの候補を示してくれる機能が入り、曲作りの初期段階で手が止まったときの助けになる。ミキサーの側では、各チャンネルの設定をまとめて見渡せるChannel Overviewという画面が加わり、画面のデザインも全体に新しくなった。

6月9日に配信された8.1は、改名後の最初の大きな更新だった。ここで加わったのは次のようなものだ。

- **Studio Assistant**: ソフトの中から操作方法や機能について質問できる案内役。Pro+の利用者向けに試験版として提供されている
- **Moisesとの連携**: 1曲をボーカル・ドラム・ベースなどのパートに分ける機能や、声の加工、伴奏の生成をStudio Proの中から使える
- **Vocal Tune**: 歌の音程を補正する標準のプラグイン。声の質感を保ったまま高さを動かせる
- **音声イベントの音程カーブ**: 録音した音声の音程の動きを、線として見ながら編集できる
- **Audio-to-Noteの強化**: ドラムの録音からも音符を取り出せるようになった

歌の音程補正は、これまでStudio Oneの中に統合されたMelodyneを使うのが定番だった。Vocal Tuneはそれを置き換えるものではなく、手早く整えたいときの選択肢が一つ増えた、と受け止めるのが自然だと思う。

## 名前が変わっても残った、Studio Oneらしい操作

<figure class="photo photo--left">
<a href="https://www.amazon.co.jp/s?k=PreSonus+StudioLive&tag=nakimoto1-22" target="_blank" rel="noopener sponsored nofollow"><img src="/images/fender-studio-pro/studiolive.jpg" alt="PreSonus StudioLiveデジタルミキサーのフェーダーとつまみが並んだ天面" width="220" height="220" loading="lazy"></a>
<figcaption>PreSonusのデジタルミキサーStudioLive。ハードウェアの多くは、改名後もPreSonusの名前のまま販売されている<span class="credit">Photo: Stephen Heywood / CC BY 2.0</span></figcaption>
</figure>

Studio Oneを長く使ってきた人にとっていちばん気になるのは、手に馴染んだ操作がそのまま使えるかどうかだと思う。結論から言えば、Studio Oneらしさを作っていた仕組みはほとんど残っている。

まず、ブラウザから音源やエフェクト、オーディオファイルをトラックへ引きずって置くだけで作業が進む、ドラッグ・アンド・ドロップ中心の操作はそのままだ。曲の構成をブロックごとに入れ替えられるアレンジャートラック、別の展開を試すための下書き用の作業領域であるスクラッチパッド、コード進行を書き換えると録音済みの演奏まで追従するコードトラックも引き継がれている。どれもStudio Oneを選ぶ理由として挙げられることの多かった機能で、ここが残ったのは大きい。

画面の構成も変わっていない。曲を作るソングページのほかに、複数の曲を並べて音量や曲間を整え、アルバムとして書き出すプロジェクトページがあり、ライブで演奏するためのショーページも残っている。録音から仕上げ、ステージでの再生までを一つのソフトで行えるというStudio Oneの組み立ては、Studio Pro 8でもそのままだ。

付属の音源もおなじみの顔ぶれが並ぶ。ドラム用のImpact XT、サンプラーのSample Oneは改良を受けて続投し、Melodyneとの連携もこれまでどおり使える。Linux向けの版も、試験版という位置づけのまま引き継がれていて、Ubuntu 24.04以降を対象に配られている。

画面のデザインが新しくなったので、最初はボタンの位置を探して戸惑うことがあるかもしれない。ただ、キーボードショートカットや作業の順番まで変わったわけではなく、一日触れば元の感覚に戻れる程度の違いだと感じた。

## Fender Motionを買うとStudio Proが付いてくる

<figure class="photo photo--right">
<a href="https://www.amazon.co.jp/s?k=PreSonus+FaderPort&tag=nakimoto1-22" target="_blank" rel="noopener sponsored nofollow"><img src="/images/fender-studio-pro/faderport.jpg" alt="フェーダー1本と再生・録音などのボタンが並ぶPreSonus FaderPortコントローラー" width="220" height="165" loading="lazy"></a>
<figcaption>Studio Oneとの連携を前提に作られたPreSonusのFaderPort。Fender Motionは、その役割をパッド中心の形で引き継ぐコントローラーだ<span class="credit">Photo: John Athayde from Washington, DC, USA / CC BY 2.0</span></figcaption>
</figure>

Fender Studio Proと同じ1月のNAMMショーで発表され、夏になって発売されたのが、Fender Motion 16とMotion 32という2台のコントローラーだ。どちらも色が変わるパッドを中心にしたMIDIコントローラーで、Motion 16は4×4の16パッドに8つのエンコーダーと1本のタッチストリップ、Motion 32は32パッドに8つのエンコーダーと2本のタッチストリップを備える。コード進行をパッドで鳴らしたり、音階を割り当てて旋律を弾いたりする機能もあり、鍵盤が弾けなくても曲の骨組みを作りやすい。

価格は海外でMotion 16が269.99ドル、Motion 32が329.99ドルで、国内ではそれぞれ42,570円、50,820円前後で扱われている。注目したいのは、どちらにもFender Studio Proの買い切り版ライセンスが付いてくる点だ。体験版や機能を削った版ではなく、単体で買えば199.99ドルの製品がそのまま付属する。

ほかのDAWとも普通のMIDIコントローラーとしてつながるが、Studio Proと組み合わせたときは、トラックの選択やプラグインの操作、コードの入力までを手元で扱える。PreSonusの時代にはFaderPortのような専用コントローラーがStudio Oneとの連携を売りにしていたが、Fenderの名前になってからは、パッドで曲を作る方向に重心が移ったように見える。これからDAWを始める人なら、Studio Proを単体で買うよりも、Motionを買ってソフトを付けてもらうほうが、手元に残るものが多い買い方になると思う。

## Studio Oneを使ってきた人は、いつ移ればいいか

Studio One 6や7を買い切りで使っている人なら、99.99ドルで乗り換えられる。8で加わったFenderのアンプとAudio-to-Note、8.1のVocal TuneやMoisesとの連携に魅力を感じるなら、移る理由は十分にあると思う。とくにギターやベースを録る人は、アンプの選択肢が増える分だけ恩恵が大きい。

一方で、Studio One 7の機能で困っていないなら、急いで移る必要はないとも感じている。これまでの作業の流れはそのまま残っているので、手持ちのプラグインや音源が新しい環境で動くことを確かめてから、制作の区切りで乗り換えれば十分だ。Studio Pro 8の動作環境はWindows 10・11の22H2以降、macOS 13.5以降なので、古いOSのままのパソコンでは、先にOSの更新が必要になる場合もある。

買い切りか、Pro+のサブスクリプションかで迷う場合は、新機能をどれだけ早く使いたいかで決めるといい。Studio Assistantの試験版のように、Pro+の利用者から先に届く機能もあるので、新しいものを早く触りたい人にはPro+のほうが向いている。

## まとめ

| 項目 | Studio One 7まで | Fender Studio Pro 8 |
|---|---|---|
| 製品名と運営 | PreSonus Studio One | Fender Studio Pro(アカウントはMyFender) |
| 有料版の構成 | ArtistとProfessional | 一本化。買い切り199.99ドル、乗り換え99.99ドル |
| サブスクリプション | Studio One+ | Fender Studio Pro+(月額19.99ドル・年額179.99ドル) |
| ギター・ベースのアンプ | Ampire | Mustang Native・Rumble Nativeが加わった |
| 音声から音符への変換 | なし | Audio-to-Note(8.1でドラムにも対応) |
| 主な操作の流れ | ドラッグ・アンド・ドロップ、アレンジャー、スクラッチパッド、コードトラック | そのまま残る |
| ページ構成 | ソング・プロジェクト・ショー | そのまま残る |
| コントローラー | FaderPortなど | Fender Motion 16・32(Studio Pro付属) |

Fender Studio Pro 8は、名前と売り方が大きく変わった一方で、Studio Oneを支えてきた操作の流れはほとんど手を付けずに残した更新だった。新しく加わったのは、Fenderのアンプと、音声を音符に変える機能、そして8.1で入った歌の補正やパート分けといった、制作の入り口を広げるための道具だ。Studio Oneに慣れた人は戸惑う時間が短く、これから始める人はMotionと組み合わせることで、手頃な入り口が手に入る。ロゴが変わっても中身は地続きだと分かれば、9か月前に感じた不安はだいぶ小さくなるはずだ。
