ミックスに使うプラグインを探し始めると、すぐにセールの情報と比較記事の山に埋もれる。名機の再現をうたうEQ、真空管の質感を足すというコンプ、何十種類もの部屋を持つリバーブ。どれも良さそうに見えて、気づけば使い方もよく分からないまま、プラグインの一覧だけが長くなっていく。私も最初の一年はそうだった。

いま振り返ると、あの時期に必要だったのは道具の数ではなく、少ない道具を深く知ることだったと思う。EQ・コンプレッサー・リバーブの三つは、ミックスでいちばん出番が多く、そのぶん効果も分かりやすい。そしてこの三つについては、無料で配られているもののなかに、有料品と並べても見劣りしない定番がある。

この記事では、EQに Tokyo Dawn Records の TDR Nova、コンプに Klanghelm の DC1A、リバーブに TAL Software の TAL-Reverb-4 を選び、この三本だけで一曲をまとめるときの考え方を整理する。それぞれの役割、設定の出発点、挿す順番、そして無料の範囲では届かない場所まで順に見ていく。

## 無料で足りる理由と、3本に絞る理由

<figcaption>無料のDAWに無料のプラグインを挿した画面。手前のリバーブにも、プリディレイや低域・高域を削るつまみがそろっている<span class="credit">Image: Derwok / <a href="https://commons.wikimedia.org/wiki/File:Ardour_6.7_Recorder_Editor_Mixer.png" target="_blank" rel="noopener">CC0</a></span></figcaption>
</figure>

無料のプラグインで本当に足りるのか、という疑問はもっともだと思う。結論から言うと、EQ・コンプ・リバーブという基本の三つに関しては、無料品と有料品の差は「音の良し悪し」より「操作の便利さ」と「色付けの種類」に出ることが多い。帯域を削る、音量の山をならす、残響を足すという仕事そのものは、無料品でも十分な精度でこなせる。

有料品が強いのは、特定の名機の癖を再現するような、音に個性を足す方向だ。これは仕上げの段階では魅力的だが、ミックスを覚える段階では、かえって判断を難しくする。音が良くなったのが自分の操作のおかげなのか、プラグインの色付けのおかげなのかが分からなくなるからだ。癖の少ない道具で基本の動きを覚えてから、色付けの道具を足すほうが、遠回りに見えて早いと感じている。

三本に絞るのにも理由がある。EQなら一種類、コンプなら一種類と決めておくと、つまみを回したときの音の変わり方が体に入ってくる。同じ役割のプラグインを何種類も持っていると、迷ったときに別のプラグインへ逃げてしまい、どれも中途半端にしか分からないまま終わる。少なくとも最初の三か月は、この三本だけで通すと決めておくのがいいと思う。

なお、ここで挙げる三本は、2026年10月時点でいずれも無料で配布されていて、WindowsとmacOSの両方で使える。登録やメールアドレスの入力が求められることはあるが、使用期間の制限や機能の制限はない。

## EQはTDR Nova、4つの帯域がそれぞれ動く

<figure class="photo photo--right">
<a href="https://www.tokyodawn.net/tdr-nova/" target="_blank" rel="noopener"><img src="/images/free-plugin-mix/eq.jpg" alt="スタジオのラックに並んだAPI 550イコライザーのモジュール。青い軸の白いつまみに周波数とゲインの目盛りが刻まれている" width="220" height="147" loading="lazy"></a>
<figcaption>周波数とゲインを選んで上げ下げする、ハードウェアのイコライザー。TDR Novaは、この考え方に「必要なときだけ動く」仕組みを足している<span class="credit">Photo: Will Fisher from Richmond, VA, United States / <a href="https://commons.wikimedia.org/wiki/File:API_550_Equalizer_-_angled_from_right_-_Control_Room_A,_In_Your_Ear_Studios.jpg" target="_blank" rel="noopener">CC BY-SA 2.0</a></span></figcaption>
</figure>

EQには、Tokyo Dawn Records が無料で配っている TDR Nova を選んだ。見た目は普通のパラメトリックEQで、4つの帯域と、低域を切るハイパスフィルター、高域を切るローパスフィルターを持っている。画面には入力の周波数分布が表示されるので、どのあたりに音が溜まっているかを目で確かめながら操作できる。VST3・AU・AAXに対応し、主要なDAWならほぼ使える。

このEQが無料の定番になっている理由は、4つの帯域がそれぞれダイナミックEQとして働く点にある。帯域ごとにしきい値（スレッショルド）と比率（レシオ）を設定でき、その帯域の音量がしきい値を超えたときだけ、上げ下げが効くようにできる。普段は何もしないが、問題が起きた瞬間だけ働くEQ、と考えると分かりやすい。

これが効くのは、ずっと削り続けると困るが、ときどき出てくる問題を抑えたい場面だ。たとえば歌の「さ」「し」が刺さる歯擦音は、5〜8kHzあたりに出ることが多い。普通のEQでこの帯域を下げると、歯擦音のない部分まで暗くなってしまう。TDR Novaなら、その帯域が大きくなったときだけ数dB下げる設定にでき、ディエッサーの代わりとして使える。同じように、ベースの特定の音程だけが膨らんで聞こえるとき、その周波数だけを動的に抑えることもできる。

ただ、最初からダイナミックの機能に頼る必要はない。私はまず、普通のEQとして使い切ることを勧めたい。各トラックのハイパスで不要な低域を落とし、200〜400Hzあたりのこもりを少し削り、耳に刺さる帯域を探して下げる。ダイナミックの機能は、こうした静的な処理では解決しない問題が出てきたときに初めて使う、くらいの位置づけがちょうどいい。

有料版の TDR Nova GE では帯域が6つに増え、ほかにも細かな機能が加わる。とはいえ、1トラックで4つの帯域を使い切る場面はそれほど多くない。ハイパスとローパスが別にあることを考えると、無料版で困るのは、かなり細かく作り込む段階に入ってからだと思う。

## コンプはKlanghelm DC1A、つまみ2つで決める

<figure class="photo photo--left">
<a href="https://klanghelm.com/contents/products/DC1A.php" target="_blank" rel="noopener"><img src="/images/free-plugin-mix/comp.jpg" alt="上下2段に並んだTeletronix LA-2Aのフロントパネル。中央にVUメーター、左右にゲインとピークリダクションの大きなつまみがある" width="220" height="125" loading="lazy"></a>
<figcaption>つまみが2つしかない名機として知られるLA-2A。DC1Aも、入力と出力の2つで圧縮の量を決める<span class="credit">Photo: Jon Gos (derivative work: Clusternote) / <a href="https://commons.wikimedia.org/wiki/File:Teletronix_LA-2A_Leveling_Amplifier_-_PatchWerk_Recording_Studios,_2007_(edit_%26_clip).jpg" target="_blank" rel="noopener">CC BY 4.0</a></span></figcaption>
</figure>

コンプレッサーは、ミックスを覚える人がいちばん戸惑う道具だと思う。しきい値、比率、アタック、リリース、ニー、メイクアップゲイン。つまみの意味は解説を読めば分かるが、それぞれをどう組み合わせれば良い音になるのかは、なかなか分からない。設定を変えても違いが聞き取れず、メーターだけを見て「何dB圧縮した」と確かめるような作業になりがちだ。

そこで、最初の一本には、あえてつまみの少ない Klanghelm DC1A を選んだ。主な操作は入力（INPUT）と出力（OUTPUT）の二つだけで、入力を上げるほど圧縮が深くなり、出力で音量を戻す。アタックやリリースは、入ってくる音に合わせて自動で変わる。比率もしきい値も自分では決めない。ここが、初心者にとってはむしろありがたいところだと感じている。

決めることが少ないので、耳は「どれくらい圧縮すると音がどう変わるか」という一点に集中できる。入力を少しずつ上げていくと、最初は音の粒がそろい、次に音が前に出てきて、さらに上げると音が詰まって平たくなる。この変化の境目を体で覚えることが、コンプを理解する最初の一歩だと思う。比率やアタックの意味は、その感覚ができてからのほうが入ってきやすい。

細かな調整のためのスイッチもいくつかある。DEEP は低域に反応しすぎないようにする切り替えで、ベースやキックに使ったときに、低音が出るたびに全体が沈むのを防いでくれる。RELAXED は反応をゆるやかにして、より自然な圧縮にする。DUAL MONO を入れると左右を別々に圧縮する。最初はすべて切った状態で始め、気になったときに一つずつ試せばよい。

歌に使うときの目安として、普通のコンプでは比率3:1〜4:1、いちばん大きいところで3〜6dBほど音量が下がる程度がよく使われる。DC1Aには比率のつまみがないので、メーターを見ながら、大きい箇所で同じくらいの量が下がるように入力を決めるとよい。6dBを大きく超えるようなら、圧縮しすぎを疑う。

なお、ミックス全体やドラムのまとめに使うコンプが欲しくなったら、同じ Tokyo Dawn Records の TDR Kotelnikov も無料で使える。こちらはステレオのまとめ用に作られたコンプで、音の瞬間的な山と平均的な音量に対して、別々に戻りの速さを設定できる。歌やベースのような単体のトラックには DC1A、全体をまとめる場所には Kotelnikov、という分担にしておくと迷わない。

## リバーブはTAL-Reverb-4を、センドで1台だけ

<figure class="photo photo--right">
<a href="https://tal-software.com/products/tal-reverb-4" target="_blank" rel="noopener"><img src="/images/free-plugin-mix/reverb.jpg" alt="金属のケースの中に長いコイルばねが2本張られ、両端に変換器が付いたスプリングリバーブのユニット" width="220" height="127" loading="lazy"></a>
<figcaption>ばねの振動で残響を作るスプリングリバーブ。金属の板を使うプレートリバーブとともに、録音スタジオの人工残響の原点になった<span class="credit">Photo: Ashley Pomeroy / <a href="https://commons.wikimedia.org/wiki/File:Spring_Reverb_8325.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a></span></figcaption>
</figure>

リバーブには TAL Software の TAL-Reverb-4 を選んだ。金属の板を振動させて残響を作るプレートリバーブの響きを下敷きにしたもので、1980年代の機材のような、少しにじんだ柔らかい響きを持っている。響きの立ち上がりが速く、余韻がなめらかに広がるので、歌やスネアになじませやすい。VST3・AU・AAXに加えてCLAPにも対応していて、Linuxでも使えるのは珍しい。

リバーブは、各トラックに一台ずつ挿すのではなく、一台だけを用意してそこへ音を送る使い方を勧めたい。DAWで新しいバストラック（AUXトラック）を作り、そこに TAL-Reverb-4 を挿す。リバーブ側のドライとウェットのバランスは、ドライを0、ウェットだけを出す状態にしておく。あとは歌やスネアなど、響きを足したいトラックから、センドでこのバスへ音を送る。どれくらい響かせるかは、トラックごとのセンド量と、バスのフェーダーで決める。

この形にすると、全部のトラックが同じ空間で鳴っているように聞こえ、曲にまとまりが出る。リバーブを一台で済ませられるので、パソコンの負担も小さい。響きの長さや質感を変えたいときも、一か所を触れば全体に反映される。個別に挿していると、トラックごとに少しずつ違う部屋が重なって、全体がぼやけてしまうことが多い。

設定の出発点として、歌に使うなら響きの長さは1.5〜2秒くらいから始め、プリディレイを20〜40ms入れる。プリディレイは、元の音が鳴ってから響きが始まるまでの間のことで、ここを少し空けると、歌の子音が響きに埋もれず、言葉がはっきり聞こえる。響きが歌に覆いかぶさる感じがしたら、プリディレイを少し伸ばしてみるとよい。

そしてもう一つ、リバーブのバスにはEQを挿して、響きの低域と高域を削っておく。低域は200〜600Hzあたりから下、高域は6〜10kHzあたりから上を落とすのが一般的な出発点だ。響きの低域が残っていると全体がもやもやし、高域が残っていると歯擦音が響きの中で何度も跳ね返って聞こえる。ここで、先ほどの TDR Nova がもう一度役に立つ。ハイパスとローパスだけを使えば足りる。

もっと大きく、現実にはない広さの空間が欲しくなったら、Valhalla DSP の Valhalla Supermassive も無料で使える。こちらはディレイとリバーブの中間のような効果を得意とし、パッドやアンビエントの音作りで力を発揮する。普段の歌やドラムには TAL-Reverb-4、曲の中で一か所だけ景色を変えたいときに Supermassive、という使い分けが合っていると思う。

## 3本をどの順で挿すか

道具がそろったら、次は順番を決める。一般的な出発点は、トラックごとに「EQで不要な帯域を削る → コンプで音量をならす → 必要ならもう一度EQで足りない帯域を少し持ち上げる」という並びにして、リバーブはバスに置く、という形だ。最初のEQで不要な低域を削っておくと、コンプがその低域に反応して余計に圧縮することがなくなる。

| 場所 | 挿すもの | 最初にやること |
|---|---|---|
| 各トラックの1段目 | TDR Nova | ハイパスで不要な低域を切り、こもりや刺さる帯域を少し削る |
| 各トラックの2段目 | Klanghelm DC1A | 入力を上げ、大きい箇所で3〜6dB下がるところで止める |
| 各トラックの3段目（必要なら） | TDR Nova | 足りない帯域を1〜2dBだけ持ち上げる |
| リバーブ用のバス | TAL-Reverb-4 → TDR Nova | ウェットのみにし、響きの低域と高域を削る |
| ミックス全体（必要なら） | TDR Kotelnikov | 全体が1〜2dB下がる程度の軽いまとめ |

全部のトラックにこの三段をそろえる必要はない。素材がきれいに録れていれば、EQのハイパスだけで済むトラックもある。挿したら必ずバイパスと切り替えて聞き比べ、良くなっていなければ外す。この習慣がいちばん大事だと思う。

もう一つ、周波数の分布を見る道具として、Voxengo の SPAN を足しておくと便利だ。無料のスペクトラムアナライザーで、マスターに挿しておくと、曲全体でどの帯域が多すぎるか、少なすぎるかが一目で分かる。ただし、グラフを平らにすることが目的ではない。耳で気になったことを目で確かめるための道具として使う。Windowsで使うなら、REAPER の開発元が無料で配る ReaPlugs（ReaEQ や ReaComp などをまとめたもの）も、他のDAWで使える選択肢として覚えておくとよい。

同じ一曲を題材に、EQ・コンプ・リバーブを一週ずつ練習していく進め方は、[ミックス独学の1か月、同じ曲でEQ・コンプ・リバーブを1週ずつ](/posts/mix-practice-1month/)にまとめている。この記事の三本は、その練習にそのまま使える。

## 無料では届かないところ

最後に、この三本で足りなくなるのはどこかを整理しておく。一つ目は、音に色を足す方向だ。真空管やテープ、特定のアナログ機材の質感を再現するプラグインは、無料のものもあるにはあるが、選択肢と完成度では有料品に分がある。三本で作ったミックスに「何か物足りない」と感じたとき、それが音の太さや温かみのことなら、ここで初めて有料品を検討すればいいと思う。

二つ目は、作業の速さだ。有料のEQには、問題のある周波数を自動で見つけてくれる機能や、帯域ごとの処理を一画面で何十個も扱える機能がある。同じ結果は無料の三本でも出せるが、時間はかかる。毎週何曲もミックスするようになったら、時間を買うという意味で有料品が効いてくる。

三つ目は、リバーブの種類だ。TAL-Reverb-4 はプレート系の響きに向いていて、小さな部屋や大きなホールの、自然な響きの描き分けは得意ではない。生楽器のアンサンブルを自然な空間に置きたいときは、部屋の響きを細かく作れるリバーブが欲しくなる。

逆に言えば、それ以外の部分、つまり不要な帯域を削る、音量をそろえる、空間を一つにまとめるという、ミックスの骨格になる作業は、無料の三本で最後まで通せる。有料品を買うのは、その骨格が自分で組めるようになってからでも遅くない。そのころには、何が足りないのかが自分の耳で分かるようになっているはずで、そうなって初めて、セールの情報も正しく選べるようになると思う。
