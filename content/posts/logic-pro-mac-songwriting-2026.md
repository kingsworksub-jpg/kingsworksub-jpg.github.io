曲を作り始めるとき、最初に悩むのは鳴らす音ではなく、手元に何が足りないかだと思う。ドラムを打ち込む根気がない、ベースラインが思いつかない、ミックスの仕上げ方が分からない、録った声の後ろの伴奏だけを抜き出したい。そのたびに別のプラグインを探し、体験版を入れ、ライセンスを管理する。作曲の時間より道具を揃える時間のほうが長くなってしまうのは、宅録をやっている人なら一度は経験があるはずだ。

Logic Pro は、その「足りないもの」を最初から同じ箱に入れて売っている DAW だと考えると分かりやすい。2026年1月に出た Logic Pro 12 で、伴奏を弾いてくれる Session Players に Synth Player が加わり、コードを自動で読み取る Chord ID も入った。9月末には 12.4 まで更新が進んでいる。価格は Mac App Store で3万円の買い切りのままで、買った後のアップデートは追加料金なしで受け取れる。この記事では、Mac 一台と Logic Pro だけで作曲から仕上げまでをどこまで任せられるのかを、機能ごとに整理していく。

## 3万円の買い切りと、新しく始まったサブスク

Logic Pro の値段はずっと3万円で、ここが他の DAW と比べたときにいちばん効いてくる部分だと思う。上位版と下位版の区別がなく、付属する音源やエフェクト、ループ素材もすべて同じ一本に入っている。2013年に Logic Pro X が出てから、10.x、11、12 と大きな更新が何度もあったが、既に買った人が追加で払う場面は一度もなかった。十年以上前に払った3万円で最新版を使い続けている人がいる、というのは DAW の世界ではかなり珍しい。

一方で、2026年からは Apple Creator Studio という月額制のセットも始まった。米国では月12.99ドル、年129ドルで、Logic Pro のほかに Final Cut Pro や Pixelmator Pro、Motion、Compressor、MainStage がまとめて使える。学生と教職員は月2.99ドルに下がる。買い切りの3万円が無くなったわけではなく、二つの入口が並んでいる形になっている。

どちらを選ぶかの判断は単純で、音楽だけを作るなら買い切りのほうが安く済む。年129ドルを三年払えば、買い切りの価格をはっきり超える。逆に、動画の編集もしていて Final Cut Pro を買うかどうか迷っていた人や、iPad 版の Logic Pro も併用したい人にとっては、サブスクのほうが話が早い。私は、音楽が中心なら迷わず買い切りでいいと思っている。一度払えば、更新のたびに財布の心配をしなくて済むのは精神的にも楽だ。

注意したいのは動作環境で、Logic Pro 12 から Apple silicon を積んだ Mac が必須になり、Intel の Mac は対象から外れた。macOS も 15.6 以降が条件になっている。アプリ本体の容量は6GB ほどだが、付属のサウンドライブラリをすべて入れると72GB 前後を使う。メモリは最低8GB とされているものの、ソフト音源を何本も重ねるなら16GB 以上あったほうが安心できる。古い Intel の iMac をまだ使っている人は、ソフトの値段より先に本体の買い替えを考える必要が出てくる。

## Session Players と Chord ID、伴奏を任せる仕組み

<figure class="photo photo--right">
<a href="https://www.apple.com/jp/logic-pro/" target="_blank" rel="noopener">
<img src="/images/logic-pro/main-window.jpg" alt="Logic Proのメインウィンドウ。左にライブラリ、中央にミキサー、右にトラック領域が並ぶ" width="220" height="138" loading="lazy">
</a>
<figcaption>空のプロジェクトを開いた直後の画面。左のライブラリから音色を選ぶところから曲作りが始まる。<span class="credit">Photo: Reguart Josemaria / CC BY-SA 4.0</span></figcaption>
</figure>

Logic Pro を作曲の道具として語るなら、Session Players を外すことはできない。もともと Drummer という、ジャンルと叩き方を選ぶだけでドラムを演奏してくれる機能が十年以上前からあり、2024年の Logic Pro 11 でそこに Bass Player と Keyboard Player が加わった。そして 12 で Synth Player が増え、ドラム、ベース、鍵盤、シンセという、ポップスの伴奏の骨格を一通り任せられる顔ぶれになった。

使い方の要になるのがコードトラックで、曲のコード進行をタイムラインの上に書いておくと、Session Players はそれに合わせてフレーズを組み立てる。ベースはルート音だけでなく経過音を挟み、鍵盤は和音の転回を自分で選び、シンセはパッドを伸ばしたり刻んだりする。進行を一か所書き換えれば、全員がそれに付いてくる。打ち込みでこれをやろうとすると、コードを一つ変えるたびにベースとピアノのノートを手で直すことになるので、試行錯誤の速さがまるで違う。

12 で入った Chord ID は、このコードトラックを埋める手間を減らすための機能だ。録音したギターや歌の伴奏、あるいは MIDI のピアノのリージョンからコードを読み取って、コードトラックに書き込んでくれる。弾き語りでざっと録ったデモを読み込ませ、コードを拾わせて、そこにドラムとベースを付ける、という流れが Logic Pro の中だけで回るようになった。自分で耳コピしてコード名を打ち込む作業は、慣れていない人にとってかなりの壁なので、ここが自動になる意味は大きいと感じる。

もちろん、任せきりにすると曲の個性は薄くなる。Session Players のフレーズはどれもよくできていて、破綻はしないのだが、その分だけ「どこかで聴いたことのある伴奏」に寄りやすい。私は、曲の骨組みを素早く確かめる段階で使い、気に入った部分を MIDI に書き出してから手で崩す、という使い方がいちばん実りがあると思う。叩き方の複雑さやスウィングの量、どの太鼓を使うかといった細かい指示も出せるので、最初の案を出してもらってから好みに寄せていく相手だと考えると付き合いやすい。

## Stem Splitter と Flashback Capture、録った音を後から扱う

</a>
<figcaption>リハーサルや本番の音をそのまま持ち帰って、後から分解したり組み直したりする場面はこれから増えていきそうだ。<span class="credit">Photo: Mitchschneider88 / CC BY-SA 4.0</span></figcaption>
</figure>

Stem Splitter は、一本にまとまったオーディオを楽器ごとに分ける機能で、Logic Pro 11 で入った。最初はボーカル、ドラム、ベース、それ以外の四つに分ける仕組みだったが、2025年5月の 11.2 でギターとピアノも個別に取り出せるようになった。スマートフォンで録ったバンドの練習音源からドラムだけを外して自分の練習用にする、古いデモの歌だけを抜き出して新しいアレンジに乗せ直す、といった使い道がすぐに思いつく。

分離の精度は、完全とまでは言えないものの、作曲の素材として扱うには十分な水準にあると思う。ボーカルを抜いた後の伴奏に、うっすら声の残りが聞こえることはある。それでも、別のアプリに書き出して、分離して、また読み込むという往復が無くなって、トラックを右クリックするだけで済むのは楽だ。処理は Mac の中で完結するので、音源をどこかのサーバーに送る必要もない。

同じ 11.2 で入った Flashback Capture も、地味だが助けられる機能だと感じている。録音ボタンを押していなかったのに、なんとなく弾いたフレーズがいちばん良かった、という経験は誰にでもあると思う。Logic Pro は再生中や停止中の演奏を裏で覚えていて、後から録音として取り出せる。MIDI だけでなくオーディオにも効くので、思いつきを逃す場面がかなり減る。

録音した素材を整える道具もひと通り揃っている。Flex Time は演奏のタイミングを、Flex Pitch は単音の音程を、MIDI のノートのように後から動かせる。歌のピッチを少しだけ整えたい、ギターのリズムのよれを直したい、という程度の用途なら、専用のプラグインを別に買わなくても足りる。12.4 でも Flex 系の改良が続いていて、使い込む人ほど細かな更新の恩恵を受けられる。

## Live Loops とサンプラー、曲の作り方を選べる

アレンジ画面に左から右へ並べていく作り方だけが、曲作りの入口ではない。Logic Pro には Live Loops という、ループやフレーズを格子状のセルに並べて、組み合わせを試しながら展開を探す画面がある。考え方は Ableton Live のセッションビューに近く、決まったフレーズを鳴らしながら、どれとどれを重ねると気持ちがいいかをその場で確かめられる。ここで作った組み合わせは、そのままアレンジ画面に録り込んで、普通の曲の形に整えていける。

ビートを組むなら Step Sequencer がある。昔のリズムマシンのように、マス目を押して音を並べていく画面で、ベロシティや発音の確率、ノートの長さを一歩ずつ決められる。12 では MIDI 2.0 のデータも表示できるようになり、再生の順番を変える新しいモードも増えた。打ち込みのピアノロールが苦手な人でも、ここなら手を動かしながら考えられると思う。

サンプラーも三種類ある。Quick Sampler は、録った声や効果音をドラッグするだけで鍵盤で弾ける音にしてくれる手軽なもの。Sampler は複数の音を鍵盤やベロシティに割り振る本格的なもの。Sample Alchemy は、一つの音をグラニュラー合成で細かく砕いて、まったく別の質感に変えていくためのものだ。Stem Splitter で取り出したギターのフレーズを Quick Sampler に入れて刻み直す、といった組み合わせも Logic Pro の中だけでできる。

ソフト音源では、何千種類もの音色を持つ Alchemy、アコースティックピアノの Studio Piano、エレクトリックベースの Studio Bass あたりが中心になる。付属品としては質が高く、デモを作る段階で外部の音源が欲しくなる場面は少ない。オーケストラの細かな奏法や、特定のビンテージ機材の再現にこだわり始めると物足りなさは出てくるが、それは3万円の付属品に求めるものではないと思う。

## Mastering Assistant と Dolby Atmos、仕上げまで一本で

</a>
<figcaption>ミックスの最終段では、画面の数値より耳とスピーカーの関係のほうがものを言う。<span class="credit">Photo: Musicianonamission / CC BY-SA 4.0</span></figcaption>
</figure>

曲を書き終えた後の仕上げも、Logic Pro の中である程度まで進められる。2023年の 10.8 で入った Mastering Assistant は、ミックスを解析して EQ、音量、ステレオの広がりを自動で整えてくれる機能で、音色の傾向を Clean、Valve、Punch、Transparent の四つから選べる。配信サイトに出す前に、手持ちのスピーカーとイヤホンで聴き比べて「だいたいこのくらい」という基準を作るには十分便利だと思う。ただ、自動で決まった値は出発点であって、曲の性格に合わせて少し戻す作業はやはり要る。

Logic Pro 11 で入った ChromaGlow は、真空管やテープを通したような倍音を足すサチュレーションで、五種類のキャラクターを選べる。トラックが平板に聞こえるとき、少しだけ挿すと前に出てくる。これも Apple silicon の処理能力を前提にした機能で、古い Mac では動かなかった理由はこういうところにある。

もう一つ、Dolby Atmos のミックスに対応している点も、この価格帯では他にない強みになっている。10.7 から、空間オーディオ向けに音を立体的に配置する仕組みが入り、7.1.4 までのスピーカー構成に対応する。専用のスピーカーを揃えなくても、ヘッドホンで仮の確認ができ、Apple Music 向けの空間オーディオ作品を作る道筋が付属品だけで引ける。12 では iPhone で録音した空間オーディオを取り込めるようにもなった。

## 一台で完結させるときの注意点

ここまで見ると万能に思えるが、限られた環境で使う以上、割り切りも要る。まず、Logic Pro は Mac でしか動かない。共同作業の相手が Windows で Cubase や FL Studio を使っているなら、プロジェクトのやりとりはオーディオの書き出しが基本になる。GarageBand のプロジェクトは Logic Pro でそのまま開けるので、iPhone や iPad の GarageBand で書き留めたアイデアを引き継ぐのは簡単だが、その逆、Logic Pro から GarageBand へは戻せない。

周辺の道具としては、iPad や iPhone から Logic Pro を操作できる無料の Logic Remote が便利だ。録音ブースや楽器の前から再生と録音を操作できるので、一人で録るときにパソコンまで歩いて戻る手間が無くなる。外付けの MIDI キーボードがなくても、iPad の画面を鍵盤やドラムパッド代わりに使える。

もう一つの注意点は、便利な機能の多くが「自動で作ってくれる」方向に寄っていることだ。Session Players、Chord ID、Stem Splitter、Mastering Assistant と並べると、曲の大半を Logic Pro が組み立ててくれるようにも見える。けれども、どのフレーズを残し、どこを崩すかを決めるのは結局こちら側で、その判断を早く回すための道具だと考えたほうがいい。迷う時間を短くしてくれる道具であって、迷う必要を無くしてくれる道具ではない。

それでも、Mac と3万円だけで、伴奏づくりから録音、編集、ミックス、マスタリング、空間オーディオまでの道が全部つながっているのは、やはり大きいと思う。プラグインを一本ずつ買い足して環境を組んでいく楽しさとは別に、最初から全部が揃った部屋に入って、すぐに曲を書き始められる気持ちよさがある。最初の DAW に迷っている Mac ユーザーなら、まずはこの一本から始めて、足りないものが見えてから他を考えれば遅くない。

他の DAW と並べて選びたい場合は、[DAW 5本を比べる、机の上のオーケストラを誰に任せるか](/posts/daw-5choice-2026/)も参考にしてほしい。ループを並べて曲を探す作り方に興味があれば、[Ableton Live 12のセッションビューが変える作曲の順番](/posts/ableton-live-12-session-view-2026/)で、Live Loops と近い発想の画面を詳しく取り上げている。
