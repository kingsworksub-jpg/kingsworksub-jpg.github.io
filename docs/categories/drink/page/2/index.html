リアルゴールドの味と仕様 — カフェインなしで元気を配る、黄金の稲妻

赤い缶に走る黄色い稲妻、そこに黒文字で「REAL GOLD」。自動販売機やコンビニの一角で昔からずっと同じ場所を守ってきた栄養ドリンク系炭酸「リアルゴールド」を、隅から隅まで見ていく。 1981年発売、40年以上続くロングセラー リアルゴールド 160ml×30本Amazonで見る → リアルゴールドは1981年に日本コカ・コーラが発売した炭酸系の栄養ドリンクだ。同じ棚に並ぶ大塚製薬「オロナミンC」が先行していた市場に、コカ・コーラが独自のブランドとして参入した形になる。発売当初はガラス瓶のみの展開で、後から缶入りが加わったという経緯も、この手の炭酸栄養ドリンクらしい歴史の刻み方だと思う。 40年以上のあいだ、単に同じ商品を売り続けてきたわけではなく、2004年に大容量派生の「リアルタンク」、2009年に低カロリー志向の「リアルゴールド カロリー1/3」、2022年からはYOSHIKI(X JAPAN)がプロデュースする「リアルゴールドX/Y」など、時代ごとに派生ラインを増やしてきた。そして2025年4月、通常版のパッケージデザインを一新し、新たにPETボトルの「リアルゴールド ビタミンローヤルパワー」を投入している。2026年には『ストリートファイター』とのコラボキャンペーンも展開中で、ロングセラーでありながら今も現役でマーケティングを仕掛け続けているブランドだという印象を受ける。 最大の特徴は「カフェインゼロ」 栄養ドリンク系の炭酸飲料と聞くと反射的にカフェインを連想しがちだが、リアルゴールドの通常版はカフェインを含んでいない。競合のオロナミンCも実はカフェインを含まない設計なので、この点は両者に共通するのだが、リアルゴールドは「がんばるための刺激」ではなく「気分を切り替えるための一本」という立ち位置を取っているように感じる。実際、2025年のリニューアルでブランド側は「無理をするためではなく、楽しむために飲むエナジードリンク」というコンセプトを打ち出しており、従来型の「気合いを入れる」系エナジードリンクの文脈からあえて距離を置きにいっているように見える。 成分面では、杉養蜂園認定のローヤルゼリーエキス、高麗人参(サポニン)エキス、ビタミンC・B2・B6・ナイアシン、アスパラギン酸などのアミノ酸類を配合している。あの黄金色は着色料ではなくビタミンB2由来の天然の色というのも、地味に感心するポイントだ。エネルギーは100mlあたり56kcal、糖質は100mlあたり14g程度で、甘さはしっかりめ。カフェイン刺激で目を覚ますタイプではなく、糖分とビタミン、そしてローヤルゼリー・高麗人参といった伝統的な滋養強壮素材で気分を持ち上げるタイプの飲み物だと理解しておくとしっくりくる。 味わい — 甘さの奥に薬草っぽい後味 一口飲むと、まず柑橘系のような甘酸っぱさが来て、そのあとに高麗人参やローヤルゼリー由来と思われる、ほのかに薬っぽい風味が追いかけてくる。オロナミンCと比べると、こちらのほうがやや甘さの輪郭がまろやかで、後味の刺激も穏やかだと感じる。強炭酸でシュワシュワ弾けるタイプではなく、あくまで「栄養ドリンクに軽い炭酸を足した」くらいの弱めの発泡感なので、キンキンに冷やして一気に飲むというより、常温に近い状態でちびちびやるほうが本来の味わいを拾いやすい気がする。 好き嫌いが分かれるとすれば、この「薬草っぽさ」の部分だろう。栄養ドリンクの独特な風味が苦手な人には引っかかる要素になり得るが、逆にその風味こそが「効いている感じ」を演出してくれる部分でもあり、昔からのファンが求めているのはまさにこの後味なのだと思う。 パッケージ展開と価格・現行性 リアルゴールド 160ml×30本Amazonで見る → 現行のラインナップは缶が160ml・190ml・250mlの3サイズ、加えてPETボトルの「ビタミンローヤルパワー」490mlがある。自動販売機やコンビニでの単品価格はおおむね130円前後、まとめ買いの160ml×30本ケースならAmazonや価格.comで1,500円前後から見つかる。2025年4月にパッケージを刷新したばかりということもあり、生産終了や取り扱い縮小の気配はまったくなく、コンビニ・スーパー・自販機のいずれでも安定して手に入る。 海外に目を向けると、北米の日本食品専門通販サイトでも「Japanese non-caffeinated energy drink」として一定数取り扱われている。カフェインが入っていないという特徴は、海外のエナジードリンク文化(カフェイン・タウリン多めが主流)の中では逆にユニークな個性として紹介されることが多いようだ。 40年以上のあいだ、赤い缶と黄色い稲妻というビジュアルをほとんど変えずに棚を守り続けてきたのは、それだけでちょっとした胆力だと思う。カフェインで無理やり気合いを入れるのではなく、甘さと薬草っぽい後味でふっと気分を切り替える一本として、これからも自動販売機の片隅に居座り続けるのだろう。 関連記事: モンスターエナジー パイプラインパンチの味と仕様 — ノースショアの波打ち際からコンビニの棚へ · 神戸居留地 スパークリングウォーターの味と仕様 — 缶190mlに詰め込まれた飲み切りの強炭酸

スーパーや業務スーパーの棚でよく見かける「神戸居留地」の炭酸水。缶190mlという飲み切りサイズの強炭酸水「スパークリングウォーター プレーン」を、隅から隅まで見ていく。 富永貿易という会社と、「神戸居留地」ブランド 神戸居留地 スパークリングウォーター 強炭酸水 プレーン 190ml×30本Amazonで見る → 製造・販売元は富永貿易株式会社。1923年創業、1949年設立という長い歴史を持つ神戸の会社で、本社は神戸市中央区御幸通にある。「ファブレスメーカー」「商社」「OEM」の3本柱で食品・飲料を幅広く手掛けており、売上高は400億円を超える規模だ。「神戸居留地」はその関連会社である富永食品が1994年から展開しているソフトドリンクブランドで、炭酸水だけでなくコーラやサイダー、コーヒー、緑茶・烏龍茶・紅茶、果汁飲料、さらにはチューハイ・ハイボールといったアルコール飲料まで抱える、思いのほか懐の深いラインナップになっている。 ブランド名の「神戸居留地」は、明治期に神戸に置かれた外国人居留地(旧居留地)にちなんだ名前だと考えられる。旧居留地は西洋の近代都市計画を取り入れた地区として知られ、今も神戸を象徴するエリアのひとつだ。ただし、ブランド名の由来を公式に説明した一次情報は見当たらなかったので、この点は地名にあやかったブランド、という程度の理解にとどめておきたい。 中身は「水と炭酸」だけ 原材料表示を見ると、水と炭酸のみ。100mlあたりのエネルギーは0kcal、たんぱく質・脂質・炭水化物・食塩相当量もすべて0という、混じりけのないスペックになっている。糖もカロリーも気にせず飲めるプレーンな強炭酸水で、そのまま飲むのはもちろん、カクテルや焼酎、果汁飲料の割り材として使うことを前提に作られている商品だと感じる。炭酸ガス圧の具体的な数値や採水地までは公開情報として見つけられなかったが、「強炭酸」というだけあって、開けた瞬間の刺激はしっかりしている。 190ml缶という選択 この商品の個性は、なんといっても190mlという缶のサイズにある。500ml前後のペットボトルが主流の炭酸水市場の中で、あえて飲み切りサイズの缶を選んでいるのがポイントだ。一度開けたら炭酸が抜ける前に飲み切れるので、「気づいたら気の抜けた炭酸水が冷蔵庫に残っていた」という経験がある人には刺さる設計だと思う。ハイボールなら1〜2杯分にちょうどいい量で、ウイスキーや焼酎をソーダ割りにするときの割り材として使うと、無駄なく使い切れる感覚が気持ちいい。 一方で、まとめ買いをするとなると30本という本数はそれなりにかさばるし、缶を何度も開け閉めする手間は当然ペットボトルより増える。単価計算では大容量ペットボトルの方が割安になりやすい面もあるので、「毎回きっちり飲み切りたい派」か「まとめて作り置きしたい派」かで評価が分かれるところだろう。 炭酸の強さと味わい 神戸居留地 スパークリングウォーター 強炭酸水 プレーン タンサンのような定番の強炭酸水と比べても見劣りしない強さだと感じた。喉への当たりは強めだが、後味はすっきりしていて、変な癖が残らない。ハイボールの割り材として使うと、ウイスキーの香りを邪魔せずにガツンとした刺激を足してくれる印象で、割り材用途としての完成度は高いと思う。 なお、同じ「神戸居留地」ブランドには缶入りのハイボール(チューハイ)商品も別で存在する。名前が紛らわしいが、あちらは完成品のお酒であり、今回取り上げているのは糖もアルコールも入っていない無糖の割り材用炭酸水なので、混同しないよう注意したい。 パッケージと展開 同シリーズは350ml缶でも展開されており、プレーンのほかレモン味も用意されている。190ml缶はプレーン専用のようで、ペットボトルでの展開は見当たらなかった。缶飲料は炭酸が抜けにくく品質が保たれやすいというメリットもあり、190ml・350mlどちらも「缶で強炭酸を維持する」という設計思想が一貫している。 価格・現行性 Amazon.co.jpでは30本ケースが1,700円台からと、1本あたり60円前後で購入できる。価格比較サイトで見ると販売店によって価格差がそれなりにあり、公式オンラインショップでは定価から割引された価格で販売されていることもある。ふるさと納税の返礼品としても採用されているブランドで、2026年時点でも富永貿易の公式サイト・自社ECサイトの両方で現行商品として扱われており、販売終了やリニューアルの兆候は見当たらない。スーパーや業務スーパーでの店頭価格は1本50円前後からと、かなり手頃な部類に入る炭酸水だ。 北海道富良野ホップ炭酸水の味と仕様 — ビールでもノンアルビールでもない、第三の選択肢

コーラでもサイダーでもプレーンな炭酸水でもない、「ホップの香りと苦味だけを炭酸水に閉じ込める」という発想の飲み物がある。ポッカサッポロの「北海道富良野ホップ炭酸水」だ。ビールの主原料であるホップを使いながらアルコールもビールらしさも狙わない、ちょっと変わった立ち位置の一本を隅から隅まで見ていく。 ポッカとサッポロ、ふたつの飲料事業が合流してできた一本 ポッカサッポロ 北海道富良野ホップ炭酸水 500ml×24本Amazonで見る → この製品を作っているポッカサッポロフード&ビバレッジは、その名の通り「ポッカ」と「サッポロ」が合流してできた会社だ。缶コーヒーやジュースでおなじみのポッカコーポレーションを、ビール大手のサッポロホールディングスが2011年に子会社化し、2013年にサッポロ飲料・ポッカコーポレーション・北海道ポッカコーポレーションが合併してポッカサッポロフード&ビバレッジが発足している。 異業種同士が一つになったことで、ビール会社が長年培ってきたホップの育種・栽培ノウハウを清涼飲料に応用できる体制が整った。本製品はまさにその産物で、初回発売は2022年3月、2024年3月にパッケージを一新して全国発売という形で展開されている一本だ。 富良野ホップという素材の背景 原材料表示は「ホップエキス(国内製造)/炭酸、香料」とシンプルだが、ここでいうホップは北海道上富良野町産のもの。上富良野町は1923年にホップ栽培が始まった、国内でも有数のホップ産地で、サッポロビールは開拓使麦酒醸造所の時代からこの地でホップの栽培・品種改良に取り組んできた歴史がある。本製品にはサッポロビールが育成した「フラノビューティ」という品種のホップエキスが使われていて、サッポロビール自身も上富良野産ホップを使った限定ビールを展開するなど、この産地への力の入れようが伝わってくる。 香料はホップ本来のフルーティーな香りを補強するために使われているとのことで、天然素材だけに頼らずしっかり香りを立たせにきている設計だと感じた。 味わい — 苦味は控えめ、香りの方が主役 飲んでみての第一印象は、想像していたよりも苦味が穏やかだということ。ビールのようなガツンとした苦味を期待すると拍子抜けするかもしれないが、その代わりにマスカットを思わせるフルーティーで爽やかな香りが鼻を抜けていく。炭酸自体は強すぎず、ゴクゴクと飲めるタイプで、後味もすっきりしている。 無糖・ゼロカロリーという表示通り甘さはまったくなく、食事の合間に飲んでも重たくならない。個人的には単体で飲むよりも、チューハイやハイボールの割り材として使うほうが持ち味が活きる気がした。ホップの香りが酒の風味と噛み合って、一段階複雑な味わいになる印象だ。一方で、香りの強さについては好みが分かれるポイントだと思う。もっとホップらしいクセや苦味を期待していると、思ったより大人しく感じるかもしれない。 ビールでもノンアルビールでもない立ち位置 この製品が面白いのは、いわゆる「ノンアルコールビールテイスト飲料」とは狙っている方向が違う点だ。ノンアルビールはビールの味・香り・のど越しを再現することを目指す飲み物だが、本製品はビールの再現を目的にしていない。あくまでビールの主原料であるホップそのものの香りと苦味を炭酸水に落とし込んだ、いわば「ホップウォーター」というジャンルの飲み物で、ビールでもノンアルビールでもない第三の選択肢として売られている。 ポッカサッポロ自身、30〜50代のビール愛飲者や休肝日を意識する層をメインターゲットに据えているそうで、たしかに「お酒を飲みたい気分だけど今日はやめておく」というときの受け皿として機能する飲み物だと感じる。実際、2025年の販売数量は前年比で6割ほど伸びているとのことで、休肝日需要やノンアル志向の広がりとうまく噛み合っている印象がある。 価格・入手性・現行性 500ml PETボトル単品の希望小売価格はおよそ140〜180円(税別)で、24本入りケースの実勢価格は3,000円前後が相場。今回参照したAmazonの取り扱い(24本入り)もこの価格帯に収まっている。 ポッカサッポロ 北海道富良野ホップ炭酸水 500ml×24本Amazonで見る → 流通はスーパー・ドラッグストア・通販と一通り揃っていて、2024年の全国発売から2年近く経った今も販売数量が伸びているところを見ると、生産終了や取り扱い縮小の気配は感じられない。ビールの主原料であるホップを、あえてビールから切り離して主役に据えるという発想自体が新鮮で、休肝日のお供や割り材として長く手元に置いておきたくなる一本だと思う。 苦味よりも香りで魅せてくるタイプのホップウォーターで、ビールの代替というより「ホップという素材そのものを楽しむ飲み物」として捉えるのがしっくりくる。単体でもいいが、個人的には酒の割り材として使ったときの相性の良さが一番印象に残った一本だった。 関連記事: サンペレグリノの味と仕様 — ロンバルディアの地下水が、世界のテーブルに選ばれる理由 · ヨサソーダの味と仕様 — ブランドが想定するユーザー層も面白い。もともとは10代から30代の男性を中心に据えていたが、その後は40代・50代の男性、30代・40代の女性にまで裾野を広げ、世代や性別を問わない「元気を届ける」ポジションへと軸足を移してきた。エナジードリンクにありがちな刺激の強さで殴るのではなく、水分補給・体のコンディション・気分のコンディションという3つの軸を掲げて、あくまで日常に寄り添うトーンを保っているのが今のドデカミンの立ち位置だと感じる。
