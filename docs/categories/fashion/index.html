ステートメントハットの現在地 — 秋冬2026、帽子が主役になる

ここ数シーズン、帽子がファッション界で急速に存在感を高めている。かつてアクセサリーとしての脇役だった帽子が、アウトフィットの主役になり始めているのだ。特に2026年の秋冬シーズンは、各ファッションウィークでも帽子のシルエットの多様性と大胆さが際立っている。 パリのハイシーズンコレクションでは、演劇的なミリネリ表現が重視されたPhoto: Paris Couture Week 素材の進化も注目すべき点。2026年のフェドーラの大半は、圧縮されたウール・フェルト、またはラビットファーとウールの混紡。この素材の選択は単なるコスト削減ではなく、秋冬の複雑な層別コーディネートに対応する重み感と固さを意図している。コーティング地のコートやニットウェアの上に被ると、帽子が「構造体」として機能する。 バケットハットは、かつてストリートウェアやウォータースポーツの機能着に限定されていた。しかし2026年には、シアリングやボア、最高級フェルト素材で仕立てられたラグジュアリーバケットハットが、パリクチュール・フェッションウィークやミラノで主張を強めている。 日本のストリートスタイルでもバケットハットの存在感は強い。東京ファッションウィークではラグジュアリーなバケットと、厚手のスニーカー、チェック柄パンツという不揃いなボリュームの組み合わせが数多く見られた。これは単なるカジュアルではなく、異なるテクスチャーの意識的な衝突を狙ったスタイリング。 ベレー帽は何十年も「洗練」の記号であり続けたが、2026年には若干の再解釈が加わっている。従来の厳密なシルエットではなく、少し緩い被り方を前提にした設計。また、プレーンな黒や紺だけでなく、バーガンディ、ロスト・グリーン、テラコッタといった秋冬らしい温暖な色展開が広がっている。 ここ数年、フラットシューズがすっかり主役だ。かつてハイヒールが支配していた時期を経て、今はどれだけ歩きやすくて、どれだけきれいなラインが出るかが選ばれる理由になっている。その流れを長く引っ張ってきたのがバレエフラットだった。しかし2026年、この座をじわじわと奪おうとしているのが、ジャズシューズである。 ジャズシューズとは何か ジャズシューズは、もともとダンサーたちが舞台で履くために生まれた靴だ。「スプリットソール」と呼ばれる、土踏まずの位置で前後が分かれた靴底を持つのが特徴で、つま先の返しや床への接地感が自由になる設計になっている。履き口まで伸びたレースアップが足を包むのが、よく見る形だ。 見た目で言うと、硬く野太いダービーシューズほどではないが、華奢すぎるバレエフラットよりもしっかりしている。バレエフラットとダービーシューズのちょうど中間、柔らかくて、それでいて足に添うようなシルエット。革が柔らかく、履くほどに足の形になじむのが本来の素性だ。バレエフラットのような構造的な頼りなさはなく、レースアップの履き口がある分、長時間の歩行にも耐えられる。フラットシューズとしてはかなり実用的な部類だと思う。 1970年代の足音 この靴が時代の象徴になったのは、1970年代のフランスでのことだ。歌手のセルジュ・ギャンズブールがレペットの「ジジ」と呼ばれるモデルを偏愛し、妻のジェーン・バーキンを介して現在のレペットの前身に手を入れさせて、白いレースアップをほぼ毎日履いていた。彼は亡くなるまで、これを1年に30足近く履き続けたともいわれる。ミック・ジャガーも同じくこのスタイルの常連で、細身の色柄のギャンズブールと並んで、時代を代表する履き手だった。 セルジュ・ギャンズブール — 白いレースアップを履きこなし、時代のシンボルにした男Photo: Sergio Gaudenti / Sygma via Getty Images レペットは1956年、パリ・オペラ座のダンサーにポワントシューズを提供していた工房が母体で、「ジジ」という名前はブランド創業関係者の一人、ダンサーのジジ・ジャンメールにちなむ。つまりジャズシューズは、ダンスというルーツを忠実に保ったまま、60年近くを経て再び街に戻ってきた靴なのだ。 なぜ今、また履かれるのか 理由はいくつかある。ひとつは、バレエフラット全盛期の延長線上にあること。ダンス由来のシューズがここ数年ずっと主役だったから、革新的な次が出るのは自然な流れだった。 もうひとつは、いわゆる「ダサい靴」への反動だ。厚底の隠しソール、カスタムクロックス、整形靴風のサンダルなど、分厚いシルエットが続いた後に、細くて、つるりとした、上品な足元が求められるようになった。薄底のスニーカーが人気なのも同じ理由で、ジャズシューズはその延長にありながら、よりフォーマルにも応えられる選択肢という立ち位置だ。 ランウェイを席巻する 2026年のコレクションで、この靴をいちばん強く推したのはセリーヌだった。クリエイティブディレクターのマイケル・ライダーが、春夏では緋色・白・黒・トープの4色を、花柄のドレスやクロップドのカラーパンツと合わせて出した。秋冬では花柄ドレス、マイクロミニ、クロップドのバレルレッグジーンズと組み合わせ、「何にでも合う」ことを証明する見せ方だった。 セリーヌ 2026年春夏 — 白いジャズシューズをまとったルックPhoto: Estrop / Getty Images 続いて、ジル・サンダーのミニマルな解釈、ロエベの上品な作り、プロエンザ・スクーラーの白いグローブレザー、ドリス・ヴァン・ノッテンのクリスタルが散りばめられた華やかな一足、ボッテガ・ヴェネタの編み込みまで、多様な解釈が続いた。スポーツマックスやアルベルタ・フェレッティも、白一色のステージや、シルバー・ゴールドの夜向けの素材を提案している。セリーヌのジャズシューズは、2026年第1四半期のファッション検索プラットフォームの一覧で、最も注目された製品の上位にランクインしていた。 街に広がって この流れがセレブリティたちを経て街に降りてきている。リリー・コリンズはフランス的な着こなしの定番として、マーク・ジェイコブスはジャズシューズに真っ直ぐのデニムを合わせて履いている。シャーリーズ・セロンはボッテガ・ヴェネタの一足で、ベネチア国際映画祭ではマギー・ギレンホールやエマ・コリンが足元にこの靴を選んだ。ハイストリートにも広がり、ザラやCOS、マンゴあたりなら気軽に試せる価格帯で手に入る。ダンサーたちが自前の道具として作ってきただけあって、20,000歩歩くのが前提の普段遣いにも、十分耐えてくれるはずだ。 白Tシャツ×ミディスカート×ジャズシューズ — 夏の定番の組み合わせPhoto: Edward Berthelot / Getty Images あわせ方は、穿き慣れたデニムが外れない。マーク・ジェイコブスとギャンズブールが、50年を隔ててまったく同じ組み合わせで履いているのは面白い。白いTシャツにミディスカート、あるいはフレンチリヴィエラ風の白いリネンシャツに。ダブルブレストのブレザーを羽織れば、落ち着いた大人の正装にもなる。 「スーツ+正装」の着こなしにも一足のジャズシューズでPhoto: Estrop / Getty Images
