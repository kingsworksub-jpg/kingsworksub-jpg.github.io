津軽びいどろ みずばしょう酒器セットの仕様と使い方 — 湿地に咲く白い花を、青いガラスに閉じ込めて

これまで陶磁器や漆器の酒器をいくつか取り上げてきたが、今回は趣向を変えてガラスの酒器を見ていく。「アデリア 津軽びいどろ」の「みずばしょう酒器セット」(徳利1個・盃2個、型番FS-71582)。深いブルーの徳利に、白い花のような模様が浮かぶ盃が寄り添う、冷酒専用の一式だ。 水芭蕉が湖畔に咲くように 津軽びいどろ みずばしょう酒器セット(徳利1個・盃2個)Amazonで見る → 水芭蕉(みずばしょう)は、尾瀬をはじめとする東北から北海道の湿地に自生する多年草だ。白い花びらのように見える部分は実は葉が変形した「仏炎苞(ぶつえんほう)」で、本当の花はその中心にある棒状の部分に小さく密生しているらしい。5月半ばから6月にかけて、雪解け水の残る湿原に群れて咲く姿は、涼しさと清らかさの象徴として和の意匠にたびたび取り入れられてきた。 このセットも、その水芭蕉が咲く風景をイメージしてデザインされているという。ガラスの色合いは深みのあるブルーで統一され、盃の表面には白い模様が浮かぶ。派手な色数を使わずに、湿地の静けさと水の透明感だけで季節感を表現しようとしている、そんな印象を受けた。 浮玉からグラスへ — 津軽びいどろという青森のガラス工芸 このブランドの成り立ちは、酒器とはまったく関係のないところから始まっている。製造元の北洋硝子は1949年、青森市で漁業用の「浮玉(うきだま)」を作る会社として創業した。浮玉とは漁網を海面に浮かせるためのガラス玉で、丈夫さに定評があり、1973年には国内トップクラスの生産高を記録したそうだ。 ところがその後、浮玉の需要はプラスチック製に取って代わられ、急激に減っていく。経営が苦しくなるなかで職人たちが目をつけたのが、地元・七里長浜の砂だった。試しにこの砂をガラスの原料にしてみたところ、透明感のある深い緑色のガラスが生まれ、これが評判を呼んだという。危機をきっかけに新しい素材と向き合った結果、1977年に「津軽びいどろ」というブランドが誕生した経緯を知ると、このガラスの一つひとつに宿る色に、また違った重みを感じる。 製法は「宙吹き」と呼ばれる、紀元前から続くとされる技法だ。1200〜1500度に溶けたガラスを吹き棹の先に巻き取り、息を吹き込みながら形を整えていく。一人前になるまで20年以上かかるとも言われる手仕事で、自社調合の色ガラスは100色以上にのぼるらしい。国内でこれだけの色数を自前で用意できるガラスメーカーは多くないと聞くと、この一本の青にも相応の蓄積があるのだと納得できる。 ちなみに津軽びいどろは、経済産業大臣が指定する「伝統的工芸品」ではなく、青森県が独自に指定する「県指定伝統工芸品」の第一号にあたる。国指定の枠組みに入っていないからといって価値が劣るわけではなく、むしろ地域が自分たちの手でこの技術を守り、伝えてきた歴史の証だと捉えている。 徳利と、対になった盃と セットの中身は徳利1個と盃2個。徳利は口径4cm・高さ12.6cmほどで満水容量365ml、盃は口径7.4cm・高さ4.7cmほどで、1個あたりの満水容量は50mlとされている。化粧箱は天面に銀箔押しが施された貼り箱で、贈り物として渡す前提の作りになっている。 盃が1個ではなく2個セットになっているのは、夫婦や二人一組を連想させる「対」の器という贈答文化の定番的な発想によるものだと思う。実際、結婚祝いや銀婚式・金婚式の贈り物として勧められている場面をよく見かける。もちろん一人で晩酌に使ってもよく、その場合は片方を来客用に取っておく、という使い方もできる。盃自体は小ぶりなので、前菜や珍味を少量盛る器として転用するのもありだと感じている。 手作りだからこそ生まれる、一つひとつの違い 販売ページには「職人による手作りのため、色・重量・サイズに個体差が生じます」という注記が添えられている。これは欠陥ではなく、宙吹きガラス特有の性質だ。同じ型を使い、同じ職人が作業しても、ガラスの粘度や室温、息の吹き込み方のわずかな違いによって、仕上がりは毎回少しずつ変わってくる。機械成形の食器のように寸分違わぬ均一さを求める道具ではなく、手元に届いた一組がその日その職人の手から生まれた一点物なのだと考えると、届いた品を眺める楽しみが増える気がする。 津軽びいどろ 片口あじさいの仕様と使い方 — 龍飛崎の紫陽花を写した一滴

冷酒を注ぐ器といえば徳利を思い浮かべる人が多いと思うが、注ぎ口が開いた「片口」という形もある。アデリアの「津軽びいどろ 片口あじさい」を、この夏らしい水色の器として見ていく。 浮き玉づくりから食卓の器へ アデリア(ADERIA) 津軽びいどろ 片口 あじさい 250ml(F71403)Amazonで見る → 津軽びいどろを作っているのは、青森市の北洋硝子という会社だ。もともとは1949年、漁業で使うガラスの浮き玉(浮き球)を作る会社として始まっている。この浮き玉づくりで培った「宙吹き」という、型を使わず息と道具だけでガラスを膨らませる技術が、今の津軽びいどろの土台になっているらしい。1973年には浮き玉の国内生産量で首位に立ったというから、当時はかなりの規模で作っていたのだろう。 ただ、プラスチック製の浮き玉が普及するにつれて需要は先細りになっていく。そこで1977年、宙吹きの技術をそのまま生かして食器・インテリア雑貨に軸足を移したのが「津軽びいどろ」というブランドの始まりだ。1996年には青森県の伝統工芸品にも指定されている。七里長浜の砂を偶然溶かし込んだところ深い緑色のガラスができた、という逸話も伝わっていて、色ガラスへのこだわりは創業当初からの気質のように思う。 あじさいという意匠 — 龍飛崎の紫陽花 この片口の見た目でいちばん目を引くのは、水色の斑点が散った表面だ。津軽びいどろにはいくつも色柄のシリーズがあるが、これは「盃コレクション」というラインの「あじさい」という柄にあたる。津軽半島の龍飛崎に咲く紫陽花からヒントを得た配色だと知って、なるほどと思った。青森という土地の風景を実際に色にする、というのがこのブランドのものづくりの姿勢のようだ。 紫陽花そのものにも興味深い性質がある。花の色は土壌のアルミニウムイオンの量で決まり、酸性の土ではアルミニウムが溶け出しやすくアントシアニン色素と結びついて青くなり、中性〜アルカリ性の土では赤みが強く出る。同じ株でも土によって色が変わるというのは、園芸をやる人ならよく知る話だろう。花言葉としては「辛抱強い愛情」「家族団らん」などが当てられていて、小さな花が寄り集まって一つの大きな塊になる姿から来ているそうだ。梅雨の時期に咲き、雨に打たれながらも姿を保つ花なので、ちょうど今の季節にひんやりしたガラスの器で使うのにふさわしい柄だと思う。 素材とサイズ — 手仕事ゆえの個体差 素材はソーダガラス。サイズは最大幅・高さともに約95mm、口径87mm、容量は満水で約250ml、重さは285g前後とされている。職人の手作業で一つひとつ吹いて作られているため、色柄や重さ、寸法にはある程度の個体差が出るという説明がある。手にとって並べてみると、同じ「あじさい」でも斑点の出方が微妙に違う個体があってもおかしくない、という前提で選ぶ器だ。 手入れの面では少し注意がいる。公式の商品ページには、耐熱ガラスではないため電子レンジは使えず、食洗機にも対応していないとはっきり書かれている。ソーダガラス自体は一般的に扱いやすい素材だが、この片口のように手吹きで肉厚が均一でないガラスは、急激な温度変化や食洗機の熱・洗剤で傷みやすい。日々の手入れは手洗いが基本、と覚えておいた方がいい。 片口という酒器のかたち — 徳利との住み分け 片口は、片側に注ぎ口が付いた鉢状の器のことで、もともとは醤油やみりんを計って注ぐ台所道具として使われてきた形らしい。それが日本酒の器としても定着したのは、徳利と同じく酒を注ぐための道具として自然に転用されたからだと思う。 徳利との違いは口の広さにある。徳利は首が細く閉じているぶん香りを閉じ込めやすく、燗をつけたときに温度も保ちやすい。一方の片口は口が大きく開いているぶん空気に触れる面積が広く、香りがふわっと立ちやすい。冷酒、特に香りの華やかな吟醸系の酒を、まず目と鼻で楽しんでから注ぐ、という飲み方に向いている形だと感じる。ゆっくり注ぐと注ぎ口から液だれしやすいという注意書きもあったので、そこは徳利にはない片口特有のクセとして覚えておきたい。 津軽びいどろを展開するアデリアの母体は、愛知県で1819年に創業した石塚硝子だ。尾張藩の御用でガラスを作っていたのが始まりというから、200年以上の歴史を持つ会社ということになる。実際、2019年には創業200周年を迎えている。アデリアというブランド自体は1961年に食器ブランドとして立ち上がったもので、津軽びいどろのほかにも、近年人気の「アデリアレトロ」のような復刻デザインのシリーズまで幅広く手がけている。片口一つとっても、老舗ガラスメーカーが地方の伝統技術ブランドを支える、という構図が背景にあるわけだ。 金属、陶器、そして色ガラス。酒器シリーズもだいぶ素材の幅が広がってきた。今回取り上げるのは、青森の伝統工芸「津軽びいどろ」から、祭りをモチーフにした一組「NEBUTA(ねぶた)酒器セット」。片口と盃のペアで、色そのものが主役になっている道具だと思う。 漁業用の浮き玉から始まったガラス工芸 アデリア(ADERIA) 津軽びいどろ NEBUTA 酒器セット(FS71551)Amazonで見る → 津軽びいどろを作っているのは、青森市の北洋硝子株式会社。もともとは1949年創業で、漁業用のガラス製浮き玉(浮き球)を作るメーカーだった。1973年ごろには国内生産量トップになるほど盛んだったというから、当時はかなりの規模だったのだろう。しかしプラスチック製の浮き玉が普及すると需要は一気に縮小していく。その転機に、浮き玉づくりで培った「宙吹き」の技術を食器やインテリアガラスに転用して始まったのが津軽びいどろだった。1977年のことで、1996年には青森県の伝統工芸品指定を受けている。 漁具メーカーが工芸ブランドに転じたという経緯を知ると、この酒器の見え方が少し変わってくる。もとは海で使われる道具のための技術が、今は食卓でお酒を彩るために使われている。素材や用途は変わっても、宙吹きという手仕事の核心は変わっていないというところが面白い。 ねぶた祭りの夜を、8色のガラスに落とし込む NEBUTAシリーズは、その名の通り青森ねぶた祭りをモチーフにしている。毎年8月2日から7日にかけて開催されるこの祭りは、東北三大祭りの一つに数えられ、竹や木の骨組みに和紙を貼って極彩色に彩色した巨大な人形灯籠を山車に乗せ、夜の街を練り歩く。このセットは、そのねぶたの鮮やかな色彩と、祭りのフィナーレを飾る花火の夜空に映える色合いを、8色の色ガラスで表現したものだという。 津軽びいどろは絵付けを一切しない工芸で、色そのものの発色だけで表現するのが特徴になっている。型を使わない宙吹きの製法上、同じ色ガラスを使っても職人が竿を振るタイミングや溶け具合で模様の出方が微妙に変わる。この「ゆらぎ」が、和紙で作られたねぶた人形の質感とどこか通じるものがあるという説明を見て、なるほどと思った。工業製品のような均一さではなく、一つひとつ表情が違う道具だと捉えるのが正しい向き合い方なのだと思う。
