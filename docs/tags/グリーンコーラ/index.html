グリーンコーラ

green cola(グリーンコーラ)の味と仕様 — ギリシャ生まれ、日本の棚に馴染む黒い一本

黒いボトルに緑の筆記体ロゴ、ラベルの隅にはギリシャの国旗と「BORN IN GREECE, BOTTLED IN JAPAN」の一文。コンビニのコーラ棚に紛れ込んだ見慣れないパッケージが、アサヒ飲料の「green cola(グリーンコーラ)」だ。隅から隅まで見ていく。 ギリシャ生まれのブランドが日本に来た経緯 green cola(グリーンコーラ) 500ml×24本Amazonで見る → 「green cola」は2012年にギリシャで生まれたブランドで、すでに世界50カ国以上で売られているという。アサヒ飲料が国際的な食品見本市でこのブランドを見つけ、日本向けにライセンス契約を結んで持ち込んだのが今回の展開の経緯だ。2026年5月12日にまず東京・埼玉・千葉・神奈川のコンビニ限定で先行発売し、同年8月4日に全国のコンビニ・スーパーへと販路を広げている。 ブランドの掲げるコピーは「NO is Smart」。糖分・カロリー・保存料に対して「賢く、ノーと言う」というメッセージで、単なる「ゼロカロリーコーラ」という機能訴求ではなく、選択そのものをスマートさとして打ち出しているのが面白い。味の面では、ギリシャの元のレシピをそのまま持ってきたわけではなく、日本人の舌に合わせて後味を軽くする方向でアサヒ側が調整を加え、ギリシャ本社の了承を得たうえで発売しているという。ちなみに「グリーンコーラ」という名前自体は2010年にもアサヒが別ブランドとして展開していたことがあるが、あちらは果汁・麦芽ベースでカフェインなし、1年ほどで姿を消した別物。今回のgreen colaとは中身もコンセプトも無関係の同名商品なので、混同しないよう付け加えておく。 中身は「植物由来」を前面に出した設計 パッケージのラベルには「植物由来のステビア使用」の文字が大きく入っている。原材料は炭酸水・カラメル色素・酸味料・甘味料(スクラロース、ステビア)・カフェイン・香料で、甘みの中心はステビアとスクラロースの組み合わせ。カフェインはコーヒー豆由来のものを使っているのも、いかにも「素性のはっきりした成分で組み立てました」という姿勢が伝わってくる部分だ。 栄養成分は100mlあたりエネルギー0kcal、たんぱく質・脂質・炭水化物も0g、ナトリウムは1mg程度とほぼ数値が出ないレベル。カフェインは100mlあたり10mg未満で、500mlボトル1本でおよそ50mg相当になる。糖類ゼロ・カロリーゼロ・保存料ゼロを掲げるコーラは他にもいくつもあるが、このブランドは「合成甘味料だけで組み立てた無機質なゼロコーラ」ではなく「植物由来の甘味料を選んだゼロコーラ」という立ち位置を取っているのが差別化のポイントだと感じる。 味わい — コーラとしては軽め、飲み物としては爽やか 飲んでみての印象は、炭酸の強さは中程度で、いわゆる強炭酸系の刺激とは違う穏やかなタイプ。コーラらしいスパイス感や甘さの厚みは正直薄めで、コカ・コーラやペプシのゼロ系と比べると「コーラの輪郭」ははっきりしない部類だと思う。一方で酸味はしっかり効いていて、それが飲み口を軽くしている。人工甘味料特有の後を引く甘さは最初の一口でわずかに感じるものの、すっと消えていくタイプで、いわゆる「ゼロコーラの後味の重さ」が苦手な人には好印象だろう。 コーラそのものを強く求めて飲むと物足りなさが残るかもしれないが、「罪悪感なく飲める炭酸」として単体で評価するなら十分にありだと思う。パッケージの黒と緑のコントラストもスタイリッシュで、鞄に入れて持ち歩きたくなるデザインというのは正直よくわかる。 価格・入手性・現行性 価格はコンビニでの単品購入が1本200円(税抜)前後、税込だと216円程度が相場。まとめ買いの24本ケースだと1本あたりの単価はぐっと下がる計算になる。 green cola(グリーンコーラ) 500ml×24本Amazonで見る → 流通はコンビニ・スーパー・Amazon・楽天と一通り揃っており、2026年8月の全国展開からまだ日が浅いこともあって、生産終了や取り扱い縮小の気配はまったくない。むしろ全国展開直後の3日間で60万ケース(1,440万本)を売り上げたというから、コーラ市場という激戦区に新規ブランドとして食い込めている部類だと思う。ギリシャ発のブランドが日本の炭酸棚にどこまで定着するか、しばらく追いかけてみたい一本だ。 「NO is Smart」というコピーは、ゼロカロリーコーラの機能訴求というより、選び方そのものへのメッセージだと感じる。コーラとしての強さでは既存の大手に一歩譲る部分もあるが、植物由来の甘味料と軽い後味という個性で、独自のポジションを作りにいっている一本だと思う。 関連記事: コカ・コーラ ゼロの味と仕様 — 罪悪感を引き算した、もうひとつの黒い革命
