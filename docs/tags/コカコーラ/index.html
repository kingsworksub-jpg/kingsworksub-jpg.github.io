カナダドライ ザ・タンサン ストロングの味と仕様 — 泡だけを、とことん信じてみる

割り材といえばウィルキンソン、という空気が長らく続いていたところに、コカ・コーラシステムが「THE」を頭に付けて殴り込んできたのが「ザ・タンサン」シリーズだ。その中でもラベルレス・ケース販売専用という一風変わった売られ方をしている「カナダドライ ザ・タンサン ストロング」430ml×24本を、今回は隅から隅まで見ていく。 カナダドライというブランドの出自 カナダドライ ザ・タンサン ストロング ラベルレス 430ml×24本Amazonで見る → カナダドライの歴史は意外と古く、1904年にカナダ・トロントの薬剤師ジョン・J・マクローリンが、シャンパンのような上品な辛口(dry)を目指してジンジャーエールを開発したのが始まりだ。1920年代の米国禁酒法時代には「お洒落なノンアルコール飲料」「カクテルの割り材」として一気に人気が広がり、世界的なブランドに育っていった経緯がある。その後何度か企業の売買を経て、現在は米国のKeurig Dr Pepper傘下のブランドになっている。 日本では1957年にサッポロホールディングスの前身にあたる日本麦酒と米カナダドライ社の提携でひっそり売り出されたのが最初で、1990年に日本コカ・コーラが販売権を取得してからは、コカ・コーラシステムがライセンス製造・販売する体制に切り替わった。ジンジャーエールのイメージが強いブランドだが、今回扱う「ザ・タンサン ストロング」はジンジャーエール系列とは別の、無糖・無香料のプレーンソーダウォーターのラインだ。 「ザ・タンサン」というシリーズの立ち位置 「ザ・タンサン ストロング/レモン」の初代は2018年3月に全国発売され、2019年3月には「より強い刺激・より持続する炭酸」を掲げてリニューアルしている。公式のキャッチコピーは「強炭酸は、おいしさで選ぶ時代へ。」――それまで炭酸水といえば酒の割り材という扱いが中心だったところに、単独の飲み物としても成立する強炭酸を、という狙いが透けて見える。コカ・コーラシステムとしては歴代最高クラスのガスボリュームを謳っているらしく、炭酸ガスそのものまで専用フィルターで濾過して「クリスタルクリアな泡」を実現し、酸味を抑えるためpHにもこだわったと説明されている。 味の面では無糖・ゼロカロリー・ノンカフェインで、原材料はクエン酸ナトリウムなどごくシンプル。飲み比べてみると、ウィルキンソン タンサンよりわずかに炭酸の粒が細かく、刺激も心なしか穏やかに感じる。その代わり微量の塩味がふわっと後を追いかけてくるような印象があり、キリッとした角のあるウィルキンソンに対して、こちらは少し丸みのある強炭酸という棲み分けに見える。2018年の投入経緯を見ても、業界的には「ウィルキンソンに対する自社ブランドの本格対抗馬」という文脈で語られることが多いようだ。 ラベルレス・ケース販売限定というちょっと変わった売り方 今回のASIN(430ml×24本)は2020年8月3日に発売されたラベルレスバージョンで、綾鷹・爽健美茶に続いてコカ・コーラシステムが3ブランド目としてラベルレス化した製品にあたる。通常の490ml有ラベル版とは別物で、Amazon・楽天市場・Yahoo!ショッピングといったオンライン通販のケース販売専用という扱いになっている。コンビニやスーパーの店頭には並ばないので、見かけたことがない人がいても不思議はない。 ラベルレス化の理由は環境配慮――ラベルを剥がす手間やプラスチックごみを減らす狙いに加えて、コロナ禍で伸びたネット通販のまとめ買い需要に対応する意味合いもあったようだ。通常はラベルに記載する原材料表示などの法定表示は、外箱のダンボールに印刷することで対応している。発売時の希望小売価格は税別2,640円/24本ケースだったとのことで、今のAmazon実勢価格(1,300円前後)と比べるとかなり値下がりしていることになる。 割り材としての実力 カナダドライ ザ・タンサン ストロング ラベルレス 430ml×24本Amazonで見る → 公式サイトでは有ラベル版の490mlについて、カシス&グレープのスカッシュやオレンジ&ブランデーのオレンジスカッシュといったカクテルレシピが紹介されていて、直飲み訴求だけでなく割り材としての使い道もちゃんと意識されている。香りのついた「レモン」タイプはウイスキーのハイボールとの相性を推す声が目立つが、無香料の「ストロング」はクセがないぶん、レモンサワーや酎ハイ、カクテル全般にまんべんなく使える汎用型の割り材だと感じる。強炭酸が抜けにくい印象もあり、作り置きしたハイボールが時間が経ってもへたりにくいのはありがたいポイントだ。 価格・入手性 Amazonでは430ml×24本のケースが1,300円前後で扱われていて、これは主要な強炭酸水の中でもかなり安い部類に入る。楽天市場やYahoo!ショッピング、価格.com掲載店を見ると同じ規格で1,700円台から2,700円台まで幅があり、まとめ買いならAmazonが有利なことが多い印象だ。48本ケースのバリエーションも存在するので、消費ペースに応じて選べる。店頭では手に入らない分、切らしたときにすぐ買い足せないのは唯一の弱点かもしれない。 類似の強炭酸プレーンソーダとの違い ウィルキンソン タンサンは炭酸水市場で長年トップを走ってきた老舗ブランドで、粒がやや大きめでガツンとした刺激が持ち味。サンガリア系の強炭酸水は天然水ベースで刺激が比較的マイルドめに作られていて、強炭酸が少し苦手な人にも向いている。その中間くらいに位置するのがこの「ザ・タンサン ストロング」で、刺激はしっかりありつつも角が丸く、微量の塩味で味に輪郭を持たせているのが個性だと思う。どれが一番良いかは好みが分かれるところで、実際に飲み比べてみるのが一番早い。 ラベルレスでケース販売限定という、店頭ではまず出会えない売られ方をしている一本だけに、知らない人もまだ多そうだ。ウィルキンソン一強だった強炭酸水の棚に、静かに割って入ってきた実力派として覚えておいて損はないと思う。 コカ・コーラ アイシー・スパーク from カナダドライ レモンの味と仕様 — 「史上最強」と喉に刺さる泡の正体

「日本コカ・コーラ史上最強の強炭酸水」というキャッチコピーを背負って売り場に並んでいるのが「アイシー・スパーク from カナダドライ レモン」だ。ラベルレス430mlペットボトル×24本というまとめ買い向けの箱を前に、この一本の中身をじっくり見ていく。 「冷却スパーク技術」というアイデア アイシー・スパーク from カナダドライ レモン ラベルレス 430mlPET×24本Amazonで見る → このシリーズの売りは「冷却スパーク技術」と呼ばれる製法にある。仕組みは意外とシンプルで、炭酸ガスは液温が低いほど水に溶け込みやすいという物理現象を利用し、製造時の冷却工程を業界標準よりさらに低い温度まで詰めることで、過去にないガス圧入量を実現したというものだ。新しい添加物や特殊な素材を使っているわけではなく、あくまで冷やし方を工夫した「力技」というのが正直な感想で、そのぶん原理自体はすっと納得できる。あわせて「開栓後も炭酸が長持ちする新処方」も採用されているらしいが、こちらの具体的な仕組みまでは公開情報からは読み取れなかった。 コップに注ぐと、泡が思いのほか大きく、勢いよく跳ねる。飲み終えるまでずっとパチパチと弾け続けている感覚があり、喉に当たる瞬間はまさに「刺さる」という表現がしっくりくる強さだ。きめ細かい泡というより、大粒の泡がまとまって押し寄せてくるタイプの強炭酸だと思う。 原材料と栄養成分はいたってシンプル 原材料表示は、レモン果汁(アルゼンチン製造)、レモンピールエキス/炭酸、香料、酸化防止剤(ビタミンC)、酸味料という構成。栄養成分は100mlあたりエネルギー0kcal、脂質0g、炭水化物0g、たんぱく質0g、食塩相当量0gと、糖類もカロリーも一切含まない無糖・無カロリーの炭酸水に分類される。特定原材料のアレルゲンも含まれていない。果汁を使っているぶん、香料だけで柑橘感を出す透明炭酸とは違い、レモンピール由来のほのかな苦みと香りが感じられるのが個人的には気に入っている。 味の印象 — ウィルキンソンより荒々しい刺激 一口目は、とにかく炭酸の勢いに驚かされる。強炭酸を謳う商品はいくつも飲んできたが、ウィルキンソン タンサンのようなきめ細かい刺激とはタイプが違い、こちらはもっと粒の大きい泡がまとめて弾けるような、荒々しい当たり方をする。レモンの香りは果汁由来のすっきりした苦みがベースで、香料だけの製品にありがちな作り物めいた甘さがない分、後味はかなりドライだ。無糖なので飲んだ後に口の中がべたつかず、そのままごくごく飲み進められる爽快さがある。 このドライな味わいのおかげで、レモンサワーやハイボールの割り材として使うと主張しすぎず馴染みがいい。自家製のジンジャーエール風カクテルを作るときのベースにしても、余計な甘さが乗らないぶん使い勝手がいいと感じている。手元に届いた分は賞味期限がそこまで長くなかったので、まとめ買いする場合はある程度のペースで飲み切る前提で考えたほうがよさそうだ。 なぜラベルレスなのか アイシー・スパーク from カナダドライ レモン ラベルレス 430mlPET×24本Amazonで見る → 今回取り上げている430ml×24本は、通常のラベル付き490ml版とは別に展開されているまとめ買い専用のラベルレスパッケージだ。コカ・コーラシステムは近年、500ml「コカ・コーラ」「コカ・コーラ ゼロ」などを含めてラベルレスボトルの展開を広げている。理由は大きく二つあって、一つはラベル分のプラスチックがまるごと不要になる環境面の配慮、もう一つはラベルを剥がす手間がなくごみの分別が楽になるという消費者側の利便性だ。実際、ラベルレス化によって出荷数量が大きく伸びたという報道もあり、通販でのまとめ買い需要とは相性がいい施策だと思う。一方で、ラベルがない分店頭での見た目の訴求力は落ちるため、店頭ではラベル付き、通販ではラベルレスという棲み分けが進んでいるようだ。内容量が490mlからやや少なめの430mlになっているのも、通販専用パッケージゆえの価格調整だろう。 カナダドライというブランドの中の位置づけ カナダドライは100年以上の歴史を持つジンジャーエール発祥のブランドで、日本では日本コカ・コーラがライセンス販売している。日本国内での展開は大きく二系統に分かれていて、一つは昔からある「カナダドライ ジンジャーエール」のような定番の炭酸飲料、もう一つが今回取り上げている無糖の強炭酸水系だ。 この強炭酸水系は、2018年に発売された「カナダドライ ザ・タンサン・ストロング/レモン」が前身にあたる。2021年5月に「アイシー・スパーク from カナダドライ」としてリニューアル発売されたタイミングで、無糖炭酸水カテゴリー全体が整理され、当時併存していた他の無糖炭酸水ブランドもろとも、このアイシー・スパークに集約された経緯がある。パッケージは2022年4月と2023年2月にも刷新されており、2023年のリニューアル時には人気コンテンツとのコラボボトルも展開された。ジンジャーエールの伝統と、強炭酸というトレンドを掛け合わせたのが、このシリーズの立ち位置だと理解している。 価格・入手性 Amazon.co.jpでは430ml×24本のラベルレス版が1,300円台から2,000円台の間で推移しており、1本あたりに換算すると55〜80円ほど。価格比較サイトでも同様の価格帯で複数の通販サイトが取り扱っており、2026年時点で販売終了やリニューアルの気配は見当たらない。むしろ無糖強炭酸水というジャンル自体が定着してきていることもあって、安定して手に入る一本だと思う。 「史上最強」という肩書きは伊達ではなく、実際に泡の当たりの強さは群を抜いている。きめ細かい炭酸が好みなら物足りなく感じるかもしれないが、喉にガツンとくる刺激を求めているなら、この一本は期待を裏切らないはずだ。 関連記事: キレートレモン Wレモンの味と仕様 — レモン2個分の酸味に振り切った一本 · カナダドライ ジンジャーエールの味と仕様 — 禁酒法時代を生き延びた甘口の実力 · カナダドライ コカ・コーラ ゼロの味と仕様 — 罪悪感を引き算した、もうひとつの黒い革命

赤いコカ・コーラの隣に、ずっと黒いボトルが並んでいる。カロリーゼロ・糖類ゼロをうたいながらも「ダイエット」の名を冠さなかった、コカ・コーラ ゼロを隅々まで見ていく。 「ゼロシュガー」ではなく「ゼロ」のまま コカ・コーラ ゼロ 500ml×24本Amazonで見る → パッケージのラベル上部には大きく「ZERO SUGAR」の文字が躍っているが、日本での正式な商品名は今も「コカ・コーラ ゼロ」のままだ。アメリカ本国では2017年に「Coca-Cola Zero」から「Coca-Cola Zero Sugar」へと名称そのものが変わっているが、日本はそこまで踏み込まず、ラベル表記としてZERO SUGARの文字を大きく扱うにとどめている。通販サイトなどで「ゼロシュガー」という商品名表記を見かけることがあるのはこのラベルの影響で、中身を指す言葉としては間違っていないものの、正式なブランド名としては「コカ・コーラ ゼロ」が今も現役だ。 日本での発売は2007年。以来、2009年に保存料ゼロ化、2010年に合成香料ゼロ化、2015年に強炭酸化と味の刷新、そして2020年8月にはパッケージ・中身ともに5年ぶりの大幅リニューアルを行っている。さらに2025年にはオンライン限定でラベルレスボトル版まで登場しており、20年近く経った今もマイナーチェンジを重ねながら現役を張り続けている一本だ。「昔からあるロングセラー」というより「地味に更新を続けている定番」と捉えるのが実態に近い。 ダイエットコークとは別の道を選んだ理由 ゼロカロリーのコーラといえばダイエットコークが先にあったわけだが、コカ・コーラ社はあえて別ブランドとして「ゼロ」を立ち上げた。背景にあったのは、当時のダイエット系飲料が女性向けというイメージと強く結びついていたこと。味やカロリーに妥協したくない層、特に若い男性層を新たに取り込むために、ダイエットコークとは切り離した黒いパッケージのラインを作った、という経緯がある。 今となってはそこまで性別を意識したマーケティングは薄れているが、「ダイエット」という言葉を避けて「ゼロ」という数字だけで語る割り切り方は、当時としてはなかなか大胆な判断だったのだろうと思う。 甘さの正体と、オリジナルへの距離感 原材料は炭酸、カラメル色素、酸味料、甘味料としてスクラロースとアセスルファムK、香料、カフェイン。エネルギーは100mlあたり0kcal、糖類も0gで、食塩相当量もごくわずかという徹底ぶりだ。 肝心の味だが、ダイエットコークよりもオリジナルのコカ・コーラに近い甘さと後味を狙って設計されているというのが基本コンセプトで、実際に飲み比べると輪郭の作り方が違うと感じる。ダイエットコークが独自の軽やかな方向にまとまっているのに対して、ゼロはあくまで「いつものコーラ」の再現を目指している印象がある。人工甘味料特有のわずかな後味は残るものの、糖類ゼロという制約の中でここまで寄せてくるのはよくできていると思う。カフェイン量について公式は具体的な数値を公表しておらず、「レギュラーコーヒーの6分の1程度、紅茶の3分の1程度」という相対的な目安が示されるにとどまっている。数値を過度に気にする人は、この曖昧さがやや気になるところかもしれない。 黒いボトルが語るもの パッケージの黒は、赤を基調にした通常のコカ・コーラとの差別化はもちろん、「ゼロカロリー」を視覚的に訴求する狙いも込められている。スペンサーロゴをあえて黒にすることで、同じブランドでありながら別物だと一目で分かるようにしているわけだ。アメリカ本国では2016〜2017年ごろに黒地へ赤い円形ロゴを大きく配置するデザインへ刷新され、その後は徐々に赤みを増す方向に寄っていったが、日本版は黒基調をずっと貫いている。 コカ・コーラ ゼロ 500ml×24本Amazonで見る → 容量展開も幅広く、350ml・500ml・700mlのPETボトルに加え、1.5Lの大容量PET、缶とラインナップが揃っている。350mlや700mlはスーパー・ドラッグストア向け、500mlや1.5Lはコンビニ・自販機向けという棲み分けがあり、買う場所によって見かける容量が変わってくる。 価格・入手性 500ml×24本ケースの実勢価格はネット通販で1,900円台後半から2,300円台程度、1本あたりにすると80〜95円ほどが相場になる。コンビニでの単品購入だと1本170円台まで上がるので、まとめ買いした方が単価的にはかなり有利だ。コンビニ・スーパー・ドラッグストアのいずれでも定番として扱われていて、入手性に不安は感じない。
