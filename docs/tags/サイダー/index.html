三ツ矢サイダーの味と仕様 — 140年変わらない透明な甘さの正体

自動販売機でもスーパーでも、当たり前のようにそこにある「三ツ矢サイダー」。缶250ml×20本というオーソドックスな通常版を軸に、この透明な炭酸飲料を隅から隅まで見ていく。 始まりは兵庫の鉱泉水だった アサヒ飲料 三ツ矢サイダー 缶250ml×20本Amazonで見る → 三ツ矢サイダーの歴史は1884年(明治17年)まで遡る。兵庫県川辺郡多田村(現在の川西市)で湧き出ていた天然の炭酸鉱泉水が「平野水(ひらのすい)」として商品化されたのがそもそもの出発点だ。この鉱泉自体は、1881年に宮内省の依頼で全国の水源を調査していた英国人科学者ウィリアム・ガウランドによって見出されたとされている。当初は無糖・無着色、香料も入っていない、ただの天然炭酸水だった。1890年には皇太子(のちの大正天皇)の御用品にも選ばれたというから、当時からかなり格の高い飲み物として扱われていたのだろう。 「三ツ矢」という名前は、平安時代の武将・源満仲が三本の矢を授かったという言い伝えと、この地の領主だった「三ツ矢旗兵衛」に由来すると言われている。1899年に商標登録され、1907年にはフレーバーを加えた「三ツ矢印平野シャンペンサイダー」として発売された。その後、フランス側から「シャンパーニュ」の名を連想させるという指摘があり、1968年に現在の「三ツ矢サイダー」という名称に落ち着いている。翌1969年には人工甘味料を全廃し、砂糖と天然香料だけを使った無色透明のサイダーへとレシピを刷新した。これが、今も続く現行製品の直接の原型だ。1972年にアサヒ飲料(当時のアサヒビール系列)がブランドを継承し、そこから半世紀以上にわたって国民的な炭酸飲料として棚に並び続けている。140年前の鉱泉が、今も缶やペットボトルの中身につながっていると思うと、ちょっと不思議な気分になる。 原材料はいたってシンプル 原材料表示を見ると、果糖ぶどう糖液糖、炭酸、酸味料、香料というごく短い構成になっている。100mlあたりのエネルギーは42kcal、たんぱく質・脂質は0g、炭水化物は11g、食塩相当量は0.03g。果汁は一切使われておらず、あくまで香料でレモンやライムを思わせる爽やかさを再現している飲み物だ。着色料も入っていないので、見た目は炭酸水と見分けがつかないくらい透明なまま。この「果汁ゼロなのに柑橘系の爽やかさがある」という組み立て方は、海外の炭酸飲料と比べたときに三ツ矢サイダーらしさが一番出ている部分だと思う。 味の印象 — スプライトともジンジャーエールとも違う 一口飲んで感じるのは、甘さがすっと引いていく軽さだ。レモンライム系の炭酸飲料としてはスプライトが世界的に有名だが、あちらは果汁を実際に配合しているぶん酸味がはっきりしている。対して三ツ矢サイダーは香料だけで柑橘感を作っているせいか、酸味より先に甘い香りが立つ。個人的には、微かにバブルガムやラムネを思わせる香りがあるように感じていて、この「甘い香り先行、酸味は控えめ」というバランスが、他の透明炭酸とは違う立ち位置を作っているのだと思う。 炭酸の強さについては缶によって印象が少し変わる気がしていて、開けたてはしっかり弾けるものの、時間が経つとやや抜けやすい。個体差か保存状態の差かは分からないが、キンキンに冷やしてすぐ飲み切るのが一番おいしく感じるタイプの炭酸だ。強炭酸を売りにしたウィルキンソン タンサンのような商品と比べると刺激自体は控えめで、そのぶん喉への当たりは優しい。ストレートで飲むのはもちろん、焼酎やウイスキーの割り材にしても、香料の甘さが主張しすぎずちょうどいい脇役になってくれる印象だ。 容量とラインナップの広がり アサヒ飲料 三ツ矢サイダー 缶250ml×20本Amazonで見る → 三ツ矢サイダーは缶160ml・250ml(20本/30本入り)・500ml、ペットボトルの300ml・430ml・500ml・1.5L、ボトル缶300ml、リターナブルびん200mlと、驚くほど幅広い容量で展開されている。今回取り上げている缶250ml×20本は、その中でもオーソドックスな通常版で、糖分・カロリーともに標準的な処方だ。 同じブランドには、カロリー・糖質ゼロの「三ツ矢サイダーZERO」、食物繊維入りの「三ツ矢サイダーW」、2024年に登場した強炭酸仕様の「三ツ矢サイダー ゼロストロング」、クエン酸をたっぷり配合した酸っぱめの「三ツ矢ウルトラストロングレモン」など、派生ラインが次々と増えている。糖ありの通常版と無糖のZERO系は味の輪郭がかなり違うので、「三ツ矢サイダー」とひとくくりにせず、パッケージの表示を確認してから選ぶのがおすすめだ。この記事で扱っているのはあくまで昔ながらの甘さを残した通常版で、素直に甘い炭酸飲料が飲みたいときにはこちらの方が満足度が高いと感じている。 価格・入手性 Amazon.co.jpでは缶250ml×20本が1,500円前後、1本あたり75〜80円ほどで購入できる。価格比較サイトを見ると、缶250ml×30本入りの商品では店舗によって1,480円台から2,000円台まで幅があり、まとめ買いするなら販売店ごとの価格差をチェックする価値はありそうだ。自動販売機・コンビニ・スーパーとどこでも定番として扱われており、2026年時点でも販売終了やリニューアルの気配はない。むしろ派生商品が増え続けている、ブランドとして元気な状態にあると言っていいと思う。 140年前の鉱泉水から始まったブランドが、今も変わらず「甘くて爽やかな透明炭酸」という立ち位置を守り続けているのは、なかなか珍しいことだと思う。強炭酸や無糖系が増えている中で、あえて昔ながらの甘さのある通常版を選ぶのも、たまには悪くない選択肢だ。 関連記事: 三ツ矢サイダーZEROの味と仕様 — 142年ブランドが辿り着いたゼロの完成形 · CRYSTAL SPARK ラムネの味と仕様 — 三ツ矢サイダーZEROの味と仕様 — 142年ブランドが辿り着いたゼロの完成形

「SINCE 1884」という文字を缶に堂々と刻めるブランドは、そう多くない。142年の歴史を持つ三ツ矢サイダーの、糖類ゼロ・カロリーゼロ版である三ツ矢サイダーZEROを隅々まで見ていく。 名前が示す通りの改称 三ツ矢サイダーZEROAmazonで見る → この商品はもともと2019年に「三ツ矢サイダー ゼロ ストロング」として発売されたが、2024年3月に「三ツ矢サイダーZERO」へ改称・リニューアルされている。公式によれば中身は同じで、「ストロング」という言葉が名前から消えた後も強炭酸自体はそのまま維持されているという。Amazon.co.jp上には旧名称のままの商品リスティングも残っているため、購入時にはどちらの表記でも同じ商品を指していると考えて差し支えない。 原材料は炭酸水・酸味料・香料に、甘味料としてアセスルファムKとスクラロースを使用。エネルギー・糖類・保存料・カフェインすべてゼロで、三ツ矢サイダーらしい爽快な後味を保ちながらカロリーオフを実現するというのが商品コンセプトだ。 142年の歴史を背負う一本 三ツ矢サイダーの起源は1884年、兵庫県川辺郡多田村(現・川西市)の炭酸鉱泉水「平野水」にさかのぼる。英国人化学者ウィリアム・ガウランドがこの鉱泉を「理想的」と分析したことがきっかけで商品化され、1897年には皇室御用達にも指定されたという記録が残っている。 三ツ矢サイダーZEROAmazonで見る → 「三ツ矢」というブランド名は、平安時代の武将・源満仲が住吉大社の神託に従って三本の矢を放ち、矢の落ちた場所に居城を築いたという伝説に由来するとされている。「日本最古のサイダー」という通説は厳密には事実と異なるようだが、現存するブランドの中では最古級であることは間違いなく、それだけの歴史を背負った上でカロリーゼロ版まで作っているという事実に、ブランドの本気度を感じる。 味わいとゼロシリーズとしての完成度 通常の三ツ矢サイダーと比べると、糖類を使わない分だけコクの薄さを感じるという声もあるが、開栓時の香りや爽快なキレは三ツ矢サイダーらしさをきちんと踏襲していると評価されている。甘味料でしっかり甘さを補いつつカロリーゼロを実現している設計は、ゼロカロリー系炭酸飲料としてよくできている部類だと思う。 価格・入手性 250ml缶×20本のケースで、実勢価格はAmazon.co.jpで1,400円台。楽天やその他ECサイトでは1,300円台〜2,000円台と店舗によって幅がある。250ml缶のほか500mlペットボトル、1.5Lペットボトルの展開もある。 三ツ矢サイダーZEROAmazonで見る → 改称を経て現在も現行品としてしっかり販売が続いており、ブランドとしての存在感は健在だ。 140年以上前の鉱泉水から始まったブランドが、令和の今もカロリーゼロという形でアップデートを続けている。歴史の重みと時代への適応を両立させている、なかなか懐の深い一本だと思う。 関連記事: 三ツ矢サイダーの味と仕様 — 140年変わらない透明な甘さの正体 · CRYSTAL SPARK ラムネの味と仕様 — 果汁ゼロで蘇る、あの瓶の記憶 · CRYSTAL SPARK グレープソーダの味と仕様 — 香りだけで満足させる無糖設計 · OZA SODAの味と仕様 — 改名の裏にあった二重の意味
