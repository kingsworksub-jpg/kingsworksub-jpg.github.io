ゼロカロリー

ドデカミンのゼロが好きだと叫びたいの味と仕様 — 名前は変わっても、中身は裏切らない

「ドデカミンのゼロが好きだと叫びたい」——正直、初めてこの商品名を見たとき二度見した。長い。しかも意味深に語尾が「叫びたい」で終わっている。この長い名前を背負ったゼロカロリー版ドデカミンを、隅から隅まで見ていく。 毎年名前が変わる、という珍しい商品 ドデカミンのゼロが好きだと叫びたい 500ml×24本Amazonで見る → このゼロカロリー版ドデカミン、実は中身も味もほぼそのままに、パッケージの商品名だけが毎年変わるという珍しい経歴を持っている。 2024年3月26日発売時の名前は「ゼロしか勝たんドデカミン」 2025年には「ドデカミンのゼロがこんなにおいしいわけがない」に改名 2026年、現行の「ドデカミンのゼロが好きだと叫びたい」に改名 律儀に年ごとにコピーライターが頭をひねって新しいフレーズを考え、缶の顔だけを毎年着せ替えている格好だ。中身は変わっていないというのが面白いところで、いわば「ラベルで話題を作り続ける」戦略に振り切った一本だと思う。正直なところ、次の名前が何になるのか気になってしまう。 カロリーゼロでも、味の柱はそのまま 肝心の中身は、100mlあたりカロリー0kcal・糖類0g。合成甘味料でしっかり甘みを作りつつ、カロリーと糖類だけをそっくり抜いた設計になっている。カフェインは100mlあたり5.0mg、500mlボトル1本で約25mg相当。缶コーヒー1本にも満たない量で、いわゆるエナジードリンクの主力であるモンスターエナジーやレッドブルと比べると一桁少ない。ガブガブ飲んでも動悸が心配になるほどの量ではなく、「エナジードリンク」というより「ビタミン・アミノ酸系の強炭酸ソーダ」に近いポジションだと感じる。 配合成分は高麗人参エキス、調製ローヤルゼリー、ガラナ、マカに加えて、アルギニン・アラニン・グリシン・ロイシン・イソロイシン・バリンといったアミノ酸群、ビタミンC、ナイアシン、ビタミンB6と、ドデカミンの看板である「12種類の元気成分」路線はゼロ版でもきっちり踏襲している。カロリーを削ってもコンセプトの骨格は崩さない、というつくりの誠実さは評価したい。 飲み口は「甘さと炭酸のバランス」で好みが分かれる 飲んだ人の感想を見ていくと、評価は割とはっきり二極化している。好意的な側は「炭酸が若干マイルドでごくごく飲める」「スッキリした飲み口で甘さ控えめに感じた」「ゼロカロリーであることを抜きにしても気に入った」という声が目立つ。一方で「甘い、ものすごく甘い、舌にずっと残る」「薬っぽさをうっすら感じる」という指摘もあり、合成甘味料特有の後味は好みが分かれるポイントだと思う。オロナミンCを大きくしたような味、という表現がしっくりくる。 個人的には、キンキンに冷やして一気に半分くらい飲むと甘さが気にならず、常温に近づくほど甘みが前に出てくる印象を受けた。冷蔵庫でしっかり冷やしてから飲むのをすすめたい。 ブランドの背骨は「ファイトバクハツ」 ドデカミン自体は2004年発売、名前の由来はギリシャ語で「12」を意味する「ドデカ」。12種類のビタミン・アミノ酸を配合したというコンセプトをそのまま商品名にした、わかりやすい命名だ。ブランドコピーは「ファイトバクハツ!!」で、栄養ドリンク市場の王者だったリポビタンDの「ファイト・一発!」を強く意識した対抗軸だったと言われている。ゼロ版も「カラダ喜ぶファイトバクハツ」というコピーで展開されており、甘い炭酸を罪悪感なく飲みたい30〜40代を主なターゲットに据えて開発された経緯がある。 ラインナップも通常版・ゼロ版・ストロング版・mini缶・BIG缶・タブレットとかなり幅広く、キングダムとのコラボ缶のような限定デザインも定期的に投入されている。カロリーゼロ版がこれだけ名前を変えながらも生き残り続けているあたり、ブランド全体としての体力は十分にあると見ていいと思う。 価格・入手性 ドデカミンのゼロが好きだと叫びたい 500ml×24本Amazonで見る → Amazonでは500mlペットボトル×24本のケースで1,999円前後、1本あたり80円台という計算になる。楽天やヨドバシ.comでも同じ24本ケースの取り扱いがあり、コンビニでの単品購入(1本200円前後が相場)よりケース買いのほうが単価は明確に下がる。名前が毎年変わるせいで検索するときに少し迷うが、パッケージの「ドデカミン」ロゴと赤いボトルデザインを目印にすれば見分けはつく。生産終了やブランド縮小の気配はなく、むしろ改名のたびに話題を作り続けている印象で、しばらくはこの「名前だけ変わる」路線が続きそうだ。 長い商品名に最初は面食らったが、飲んでみると中身は素直な低カフェイン・ゼロカロリーの強炭酸ソーダで、拍子抜けするくらいまっとうな一本だった。次にどんな名前で店頭に並ぶのか、今から少し楽しみにしている。 関連記事: モンスターエナジー パイプラインパンチの味と仕様 — ノースショアの波打ち際からコンビニの棚へ · リアルゴールドの味と仕様 — カフェインなしで元気を配る、黄金の稲妻 · MATCH(マッチ)の味と仕様 — 部活帰りの喉が知っている、あの黄色い一本 · ドデカミンの味と仕様 — 汗と栄養素が弾ける、現場発の元気ドリンク

コカ・コーラ ゼロの味と仕様 — 罪悪感を引き算した、もうひとつの黒い革命

赤いコカ・コーラの隣に、ずっと黒いボトルが並んでいる。カロリーゼロ・糖類ゼロをうたいながらも「ダイエット」の名を冠さなかった、コカ・コーラ ゼロを隅々まで見ていく。 「ゼロシュガー」ではなく「ゼロ」のまま コカ・コーラ ゼロ 500ml×24本Amazonで見る → パッケージのラベル上部には大きく「ZERO SUGAR」の文字が躍っているが、日本での正式な商品名は今も「コカ・コーラ ゼロ」のままだ。アメリカ本国では2017年に「Coca-Cola Zero」から「Coca-Cola Zero Sugar」へと名称そのものが変わっているが、日本はそこまで踏み込まず、ラベル表記としてZERO SUGARの文字を大きく扱うにとどめている。通販サイトなどで「ゼロシュガー」という商品名表記を見かけることがあるのはこのラベルの影響で、中身を指す言葉としては間違っていないものの、正式なブランド名としては「コカ・コーラ ゼロ」が今も現役だ。 日本での発売は2007年。以来、2009年に保存料ゼロ化、2010年に合成香料ゼロ化、2015年に強炭酸化と味の刷新、そして2020年8月にはパッケージ・中身ともに5年ぶりの大幅リニューアルを行っている。さらに2025年にはオンライン限定でラベルレスボトル版まで登場しており、20年近く経った今もマイナーチェンジを重ねながら現役を張り続けている一本だ。「昔からあるロングセラー」というより「地味に更新を続けている定番」と捉えるのが実態に近い。 ダイエットコークとは別の道を選んだ理由 ゼロカロリーのコーラといえばダイエットコークが先にあったわけだが、コカ・コーラ社はあえて別ブランドとして「ゼロ」を立ち上げた。背景にあったのは、当時のダイエット系飲料が女性向けというイメージと強く結びついていたこと。味やカロリーに妥協したくない層、特に若い男性層を新たに取り込むために、ダイエットコークとは切り離した黒いパッケージのラインを作った、という経緯がある。 今となってはそこまで性別を意識したマーケティングは薄れているが、「ダイエット」という言葉を避けて「ゼロ」という数字だけで語る割り切り方は、当時としてはなかなか大胆な判断だったのだろうと思う。 甘さの正体と、オリジナルへの距離感 原材料は炭酸、カラメル色素、酸味料、甘味料としてスクラロースとアセスルファムK、香料、カフェイン。エネルギーは100mlあたり0kcal、糖類も0gで、食塩相当量もごくわずかという徹底ぶりだ。 肝心の味だが、ダイエットコークよりもオリジナルのコカ・コーラに近い甘さと後味を狙って設計されているというのが基本コンセプトで、実際に飲み比べると輪郭の作り方が違うと感じる。ダイエットコークが独自の軽やかな方向にまとまっているのに対して、ゼロはあくまで「いつものコーラ」の再現を目指している印象がある。人工甘味料特有のわずかな後味は残るものの、糖類ゼロという制約の中でここまで寄せてくるのはよくできていると思う。カフェイン量について公式は具体的な数値を公表しておらず、「レギュラーコーヒーの6分の1程度、紅茶の3分の1程度」という相対的な目安が示されるにとどまっている。数値を過度に気にする人は、この曖昧さがやや気になるところかもしれない。 黒いボトルが語るもの パッケージの黒は、赤を基調にした通常のコカ・コーラとの差別化はもちろん、「ゼロカロリー」を視覚的に訴求する狙いも込められている。スペンサーロゴをあえて黒にすることで、同じブランドでありながら別物だと一目で分かるようにしているわけだ。アメリカ本国では2016〜2017年ごろに黒地へ赤い円形ロゴを大きく配置するデザインへ刷新され、その後は徐々に赤みを増す方向に寄っていったが、日本版は黒基調をずっと貫いている。 コカ・コーラ ゼロ 500ml×24本Amazonで見る → 容量展開も幅広く、350ml・500ml・700mlのPETボトルに加え、1.5Lの大容量PET、缶とラインナップが揃っている。350mlや700mlはスーパー・ドラッグストア向け、500mlや1.5Lはコンビニ・自販機向けという棲み分けがあり、買う場所によって見かける容量が変わってくる。 価格・入手性 500ml×24本ケースの実勢価格はネット通販で1,900円台後半から2,300円台程度、1本あたりにすると80〜95円ほどが相場になる。コンビニでの単品購入だと1本170円台まで上がるので、まとめ買いした方が単価的にはかなり有利だ。コンビニ・スーパー・ドラッグストアのいずれでも定番として扱われていて、入手性に不安は感じない。 世界的に見ても、通常のコカ・コーラの販売数量が伸び悩む一方でゼロシュガー系のラインは各国で成長を続けているというデータがあり、健康志向の高まりを背景に、今のコカ・コーラ社にとってむしろ主力の一角に近い立ち位置になっているようだ。生産終了や販売縮小の気配はなく、2026年時点でも通常のスーパー・コンビニ流通で問題なく手に入る。 「ダイエット」と名乗らずに「ゼロ」という数字だけで勝負を挑んだブランドが、20年近く経ってもマイナーチェンジを重ねながら定番の座を守り続けている。オリジナルの味にどこまで近づけるかという地味な改良の積み重ねが、この黒いボトルの正体なのだと思う。 関連記事: green cola(グリーンコーラ)の味と仕様 — ギリシャ生まれ、日本の棚に馴染む黒い一本
