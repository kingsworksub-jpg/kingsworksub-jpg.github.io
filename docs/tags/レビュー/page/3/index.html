この盃の見た目のインパクトは、透明なガラスの上にもう一枚、薄い色ガラスを重ねる「被せ硝子(きせがらす)」という技法から来ている。職人が透明なガラスの生地に、0.2〜0.3mmほどの薄さで色ガラスをひとつずつ吹き重ねていくのだそうで、この一枚がロックグラスのボディに紅色の帯を作っている。そこにさらに金箔の装飾を施すことで、単色のガラスとは違う奥行きが出ている。 田島硝子はこの被せ硝子を、江戸切子の材料としても長年供給してきたメーカーだと知って、なるほどと思った。切子細工に使われる色ガラスの生地を作る側の会社が、自社ブランドとしてこういう装飾グラスも手がけているというのは、素材屋としての引き出しの多さを感じさせる。 底に沈む富士山 — 酒を注ぐと表情が変わる このシリーズの一番の仕掛けは、グラスの底に成形された富士山のシルエットだ。透明な部分に山の形が浮かび上がっていて、そこに冷酒を注ぐと、酒の色が山の周りに回り込んで、素面のときとは違う富士山の表情になる。日本酒なら淡く、梅酒や果実酒なら色濃く、注ぐものによって同じ富士山が違う顔を見せるのがおもしろい。 肝心の味だが、ダイエットコークよりもオリジナルのコカ・コーラに近い甘さと後味を狙って設計されているというのが基本コンセプトで、実際に飲み比べると輪郭の作り方が違うと感じる。ダイエットコークが独自の軽やかな方向にまとまっているのに対して、ゼロはあくまで「いつものコーラ」の再現を目指している印象がある。人工甘味料特有のわずかな後味は残るものの、糖類ゼロという制約の中でここまで寄せてくるのはよくできていると思う。カフェイン量について公式は具体的な数値を公表しておらず、「レギュラーコーヒーの6分の1程度、紅茶の3分の1程度」という相対的な目安が示されるにとどまっている。数値を過度に気にする人は、この曖昧さがやや気になるところかもしれない。 黒いボトルが語るもの パッケージの黒は、赤を基調にした通常のコカ・コーラとの差別化はもちろん、「ゼロカロリー」を視覚的に訴求する狙いも込められている。スペンサーロゴをあえて黒にすることで、同じブランドでありながら別物だと一目で分かるようにしているわけだ。アメリカ本国では2016〜2017年ごろに黒地へ赤い円形ロゴを大きく配置するデザインへ刷新され、その後は徐々に赤みを増す方向に寄っていったが、日本版は黒基調をずっと貫いている。 コカ・コーラ ゼロ 500ml×24本Amazonで見る → 容量展開も幅広く、350ml・500ml・700mlのPETボトルに加え、1.5Lの大容量PET、缶とラインナップが揃っている。350mlや700mlはスーパー・ドラッグストア向け、500mlや1.5Lはコンビニ・自販機向けという棲み分けがあり、買う場所によって見かける容量が変わってくる。 価格・入手性 500ml×24本ケースの実勢価格はネット通販で1,900円台後半から2,300円台程度、1本あたりにすると80〜95円ほどが相場になる。コンビニでの単品購入だと1本170円台まで上がるので、まとめ買いした方が単価的にはかなり有利だ。コンビニ・スーパー・ドラッグストアのいずれでも定番として扱われていて、入手性に不安は感じない。 世界的に見ても、通常のコカ・コーラの販売数量が伸び悩む一方でゼロシュガー系のラインは各国で成長を続けているというデータがあり、健康志向の高まりを背景に、今のコカ・コーラ社にとってむしろ主力の一角に近い立ち位置になっているようだ。生産終了や販売縮小の気配はなく、2026年時点でも通常のスーパー・コンビニ流通で問題なく手に入る。 「ダイエット」と名乗らずに「ゼロ」という数字だけで勝負を挑んだブランドが、20年近く経ってもマイナーチェンジを重ねながら定番の座を守り続けている。オリジナルの味にどこまで近づけるかという地味な改良の積み重ねが、この黒いボトルの正体なのだと思う。 関連記事: green cola(グリーンコーラ)の味と仕様 — ギリシャ生まれ、日本の棚に馴染む黒い一本
