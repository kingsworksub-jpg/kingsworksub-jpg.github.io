ドデカミンの味と仕様 — 汗と栄養素が弾ける、現場発の元気ドリンク

コンビニのレジ横、栄養ドリンクの棚の隣にいつも強炭酸のオレンジ色のボトルが並んでいる。名前の由来はギリシャ語の「12」。12種類の成分を強炭酸に溶かし込んだアサヒ飲料のドデカミンを、パッケージの隅から隅まで見ていく。 「12」を背負ったネーミング ドデカミン 500ml×24本Amazonで見る → 「ドデカミン」という名前は、ギリシャ語で「12」を意味する「ドデカ」に由来する。ビタミンやアミノ酸など12種類の成分を配合したというコンセプトをそのまま商品名にしてしまったわけで、栄養ドリンクにありがちな「元気」「活力」といった抽象語に頼らず、成分の数を看板に掲げた潔さがある。実際のラベルを見ると、タウリン、アルギニン、オルニチン、グルタミン、分岐鎖アミノ酸(ロイシン・イソロイシン・バリン)、ビタミンB群、ビタミンCといった面々がずらりと並んでいて、確かに「12」を名乗るだけの物量は感じる。 発売は2004年4月14日。当時のキャッチコピーは「ファイトバクハツ」で、大正製薬のリポビタンDが掲げる「ファイト・一発!」を意識した挑戦的な言葉選びだったと言われている。栄養ドリンク市場の主役だったリポビタンDに対して、強炭酸という武器で殴り込みをかけた後発ブランド、というのがドデカミンの出発点だ。 覆面キャラクターと現場のノリ ドデカミンのブランドを語るうえで欠かせないのが、プロレスマスクをかぶった赤い覆面キャラクター「マスク・ド・ドデカミン」の存在だ。困っている人を助けるヒーローという設定で発売当初から広告に登場していたが、しばらく姿を消していた時期があり、2017年4月のリニューアルで13年ぶりに復活した。このリニューアルでは炭酸の強さをさらに引き上げつつ「12種類の成分」という原点のコンセプトは維持するという、攻めと守りを両立させた設計になっている。 ブランドが想定するユーザー層も面白い。もともとは10代から30代の男性を中心に据えていたが、その後は40代・50代の男性、30代・40代の女性にまで裾野を広げ、世代や性別を問わない「元気を届ける」ポジションへと軸足を移してきた。エナジードリンクにありがちな刺激の強さで殴るのではなく、水分補給・体のコンディション・気分のコンディションという3つの軸を掲げて、あくまで日常に寄り添うトーンを保っているのが今のドデカミンの立ち位置だと感じる。 ラインナップは思ったより幅広い 現行の顔ぶれを整理すると、定番の「ドデカミン」(PET500ml)を軸に、より刺激を強めた「ドデカミンストロング」(ボトル缶300ml)、コンパクトな「ドデカミンmini」(缶250ml)、そしてカロリーゼロ・糖類ゼロの「ドデカミンのゼロが好きだと叫びたい」(PET500ml)という4本柱になっている。ゼロ系統は2024年に「ゼロしか勝たんドデカミン」という名前で登場し、その後現在の長い商品名に変わった経緯があり、健康志向の30〜40代に向けて「罪悪感なく甘い炭酸を飲みたい」というニーズを拾いに行った格好だ。 ストロング版は数値を見るとかなり本気で、カフェインは標準のドデカミンの約4倍、アルギニンに至っては大幅増量とブランド史上最大量をうたっている。眠気覚ましというより「戦闘態勢に入りたいとき」向けの一本という位置づけで、同じブランドの中でもキャラクターがはっきり分かれている。 これに加えて期間限定・コラボ商品が絶えず出てくるのもドデカミンらしいところで、2025年には子どもの発想を形にしたという触れ込みの「ぼくの考えた最強のドデカミン」、コンビニ限定の「ドデカぐんぐん」、ボーカロイド系キャラクターとのコラボなどが続き、2026年に入ってからもローソン限定色違い版や、夜向けにクエン酸を強化した「夜は楽しまナイト!」など新しい切り口が次々と出てきている。長寿ブランドにありがちな「昔のまま」ではなく、コラボと限定フレーバーで常に話題を作り続けているブランドだと思う。 中身と数字 標準のドデカミン(PET500ml)は100mlあたり19kcal、糖分は100mlあたり4.7g前後で、ボトル1本で見ると糖質は20g台になる。カフェインは公式表示で100mlあたり10mg、ボトル1本で50mg相当。甘さはしっかりした濃さで、栄養ドリンクというより「強炭酸のフルーツ系ソーダ」に近い飲み口だと感じる。ゼロ版は文字どおりカロリー・糖類ゼロに振り切りつつ、高麗人参エキスやローヤルゼリー、ガラナ、マカといった栄養ドリンクらしい成分は据え置きにしていて、甘さの引き算と機能性の足し算を両立させようとする設計思想が見える。 価格・入手性 コンビニでの単品購入だと1本140〜200円程度が相場で、ケース買いだと1本あたりの単価はぐっと下がる。 ドデカミン 500ml×24本Amazonで見る → 500ml×24本のケース売りだとまとめ買いの単価メリットが大きく、コンビニで単品を買い続けるよりも1本あたりの負担はかなり軽くなる。スーパー・コンビニ・自販機と流通網は幅広く、入手性に不安を感じる場面はない。2026年に入ってもローソン限定色違い版や夜向けの新商品が投入されており、生産終了やブランド縮小の気配はまったく感じられない。むしろ栄養炭酸飲料というジャンル全体が横ばい傾向にあるなかで、リピート購入率の高さで踏ん張っている一本という印象だ。 「12」という数字を看板に掲げてから20年以上、覆面キャラクターの復活やゼロカロリー版の投入、コラボ商品の連発と、地味な改良というより派手な仕掛けで存在感を保ち続けてきたブランドだと思う。強炭酸の刺激とフルーツ系の甘さを両立させたバランスが、コンビニの棚で埋もれない理由なのだろう。 関連記事: モンスターエナジー パイプラインパンチの味と仕様 — ノースショアの波打ち際からコンビニの棚へ · 能作 本錫100%酒器セットの仕様と使い方 — 曲がる金属が注ぐ、やわらかな酒の時間

富山・高岡に、曲がる金属で酒器を作る鋳物メーカーがある。能作の「本錫100%」シリーズから、ぐい呑みと片口小のセットを取り上げる。 高岡が育てた、曲がる金属 能作 本錫100%酒器セット(ぐい呑み・片口小)Amazonで見る → 能作の創業は1916年。高岡銅器という400年続く鋳物産地で、仏具や茶道具、花瓶を手がける工房として始まった会社だ。転機になったのは2003年、世界初とうたう「100%純錫」のテーブルウェアラインを立ち上げたこと。普通、錫の器はアンチモンや銅などを混ぜた合金にして硬さを持たせるものだが、能作はあえて硬化材を一切加えず、純度100%に近い錫のまま鋳造する道を選んだ。 その結果生まれたのが、手で曲げて形を変えられるほど柔らかい金属という、他に類を見ない特性だ。手のひらで押して器の形を変えられる「KAGO」シリーズが看板商品になっているのも、この「柔らかさを弱点ではなく個性にする」という発想から来ている。今回取り上げるぐい呑み・片口セットも、同じ本錫100%の系譜にある器だ。 片口とぐい呑み、それぞれの実力 片口小はH55×W128×D77mmほど、容量は195cc前後。ぐい呑みは1個あたり90cc前後で、手に収まるサイズ感になっている。どちらも化粧箱入りで、贈り物として渡しても恥ずかしくない仕立てだ。 能作 本錫100%酒器セット(ぐい呑み・片口小)Amazonで見る → 能作の直販サイトでは片口小の単品や、片口小にぐい呑み2個を組み合わせたセットが定番として並んでいて、今回のような「片口1個+ぐい呑み1個」という組み合わせは、正規取扱店が独自に組み替えた構成のようだ。中身自体は能作の本錫100%シリーズそのものなので、素材や作りに対する不安はない。 手入れは、思ったより神経を使う 錫は柔らかい金属なので、扱いには多少の慣れが要る。強く握ったりぶつけたりすると簡単にへこむし、表面にも傷が入りやすい。食器洗浄機・乾燥機は使えず、手洗いしてすぐに柔らかい布で水気を拭き取るのが基本になる。 放っておくと酸化して黒っぽい斑点(いわゆる曇り・変色)が出てくるのも錫の性質で、これは不良ではなく素材の特徴だという。気になったら重曹と中性洗剤を練ったペーストで優しくこすればある程度は戻せるらしいが、金属磨き粉やスチールウールでゴシゴシやるのは厳禁。ここは正直、扱いやすさよりも「素材と付き合う手間」を楽しめるかどうかにかかっている道具だと思う。 酒器としての実力 錫の器で飲むと酒がまろやかになる、という話は古くから言われている。イオン効果で角が取れる、熱伝導の良さで冷酒がキンと冷えたまま楽しめる、抗菌性があるので酒が傷みにくい、といった具合だ。実際、錫は熱の伝わりが陶器よりずっと速いので、冷蔵庫で1〜2分冷やすだけでもしっかり冷たくなる感覚はある。 ただ、味がまろやかになるという部分は科学的に完全に立証された話ではなく、あくまで長年語り継がれてきた経験則に近い。個人的には、金属特有のひんやりした口当たりと軽い清涼感が、冷酒をきりっと引き締めてくれる感じが気に入っている。過度な期待はせず、素材の面白さとして楽しむくらいがちょうどいいと思う。 価格・現行性 能作 本錫100%酒器セット(ぐい呑み・片口小)Amazonで見る → 実勢価格はAmazon.co.jpで11,000円台。能作の直販サイトでは、片口小単体が7,000円台、片口小+ぐい呑み2個のセットが14,000円台〜と、価格帯は近い。錆びにくく変形しにくいという錫の性質になぞらえて、結婚10周年を祝う「錫婚式」の贈り物として能作自身が紹介しているくらいで、還暦祝いや退職祝いの品としてもよく選ばれているブランドだ。 能作は現在も高岡の本社工場でこのシリーズを作り続けていて、廃番になった様子もない。片口・ぐい呑みという基本の組み合わせは、シーズンごとの限定デザインとは違って長く定番であり続けそうな器だと思う。 曲がるほど柔らかい金属を、あえてそのまま器にしてしまう発想がおもしろい。扱いには気を遣うが、その手間ごと楽しめるなら、晩酌の道具として長く付き合っていける一組だと思う。 関連記事: BODUM DOUROの仕様と使い方 — ドウロ渓谷のぶどう畑をまとった徳利 · KEITH 純チタン おちょこ 酒器 2個セットの仕様と使い方 — 白酒のために生まれた、どこへでも連れていける盃 · ピーコック 真空二重構造 酒器セットの仕様と使い方 — 魔法瓶メーカーが本気で作った、温度を止める徳利

柳宗理デザイン 清酒グラスの仕様と使い方 — てのひらの形から生まれた、日本酒のための器

脚付きの小さなガラス杯に、金の小さな紋章がひとつ。プロダクトデザインの世界で知らない人はいない柳宗理が手がけた「清酒グラス」を、隅々まで見ていく。 日本酒造組合中央会からの、ひとつの依頼 柳宗理デザイン 清酒グラス 125ml(東洋佐々木硝子)Amazonで見る → このグラスの出発点は、日本酒造組合中央会からの依頼だったという。「お燗も冷酒もこなせる、脚のついた杯がほしい」という、ずいぶん欲張りな注文だ。受けて立ったのが柳宗理で、金沢美術工芸大学で教えていた縁から、金沢の福光屋の福光博氏と協力しながら形を練っていった。 最終形にたどり着くまでにはおよそ2年かかったと伝えられている。柳宗理といえばバタフライスツールやステンレスのケトルのような、工業製品然とした佇まいの仕事で知られるが、この清酒グラスは「盃」という和の道具の記憶をきちんと踏まえた形にまとめてある。一目で「これは日本酒のための器だ」とわかる佇まいに落とし込むのに、それだけの時間が必要だったのだろう。 手のひらが決めた、あの丸み 見た目のいちばんの特徴は、丸く厚みを持たせた縁と、安定感のある高い脚だ。縁を厚くしたのは、日本酒を口に含んだときの当たりを柔らかくするためだと説明されている。脚の部分はただ持ちやすいだけでなく、卓に置いたときの座りの良さまで含めてデザインされているようで、実際に手に取ると、指の腹がすっと吸いつくような曲面になっているのがわかる。 装飾らしい装飾はほとんどなく、胴の途中に小さな金の紋章がひとつ添えられているだけ。この潔さが、半世紀以上たった今見てもまったく古びない理由だと思う。ミニマルなのに素っ気なくならないのは、削ぎ落とした形の中に「日本酒を飲むための道具」という機能がきちんと宿っているからだろう。 素材とつくり — ソーダガラス、東洋佐々木硝子の仕事 素材はソーダガラス。製造を手がけているのは、大阪発祥のガラスメーカー東洋佐々木硝子だ。手吹きの一点物ではなく工業製品として量産されているぶん、価格は驚くほど抑えられていて、店によっては1個500円を切ることもある。柳宗理のデザインらしく、美しさと日常使いのしやすさを両立させる方向に振り切った器だと感じる。 大小2サイズ、そして手入れの注意 このグラスには小(容量60ml前後)と大(容量110〜125ml前後、扱う店によって表記に多少の幅がある)の2サイズがあり、今回取り上げているのは大サイズにあたる。開発の過程では、当初中間的なサイズを作ったところ「お燗にはやや大きい」という声が出て、そこから小サイズが生まれたという経緯があるらしい。冷酒中心に楽しむなら大、お燗を意識するなら小、という選び方が本来の設計意図に近いのだろう。 手入れの面では、電子レンジ・オーブンには対応しておらず、食器洗浄機・乾燥機の使用も推奨されていない。中性洗剤とやわらかいスポンジでの手洗いが基本で、急激な温度変化(熱いものを注いだ直後に冷水にさらす、など)も避けたほうがいい。ガラスとしてはごく一般的な扱い方だが、値段が手頃だからといって雑に扱っていい器ではないと思う。 熱燗か、冷酒か もともとの依頼は「お燗も冷酒もこなせる杯」だったが、現在の販売ページを見る限り、耐熱仕様をうたっている様子はなく、急な加熱は避けたほうが無難な器という位置づけになっている。個人的には、この形の良さがいちばん映えるのは冷酒だと感じる。厚みのある縁が口当たりをまろやかにしてくれるので、キリッと冷やした純米酒や吟醸酒を、脚を軽くつまむようにして飲むのが似合う。 価格と購入先 — 半世紀選手が今も現役 柳宗理デザイン 清酒グラス 125ml(東洋佐々木硝子)Amazonで見る → 価格帯は小サイズで300円台、大サイズでも400〜500円程度からと、デザイナーズプロダクトとしては驚くほど手頃だ。MoMAデザインストアやD&DEPARTMENT、カリモク60のオフィシャルショップ、柳工業デザイン研究会の直販、地元の酒販店など、扱っている販路は幅広い。Amazonでも取り扱いがあり、単体からペア・セットまで見つかる。 生産中止になった様子はなく、発表から半世紀以上たった今もカタログに載り続けているロングセラーだ。デザイナーの名前で語られがちな器だが、実際の値段は缶チューハイ数本分ほどしかしない、というギャップも含めて面白い存在だと思う。 飾り気を削ぎ落としながら、日本酒という飲み物の輪郭だけはしっかり残す。そのバランス感覚こそが、このグラスが半世紀以上も棚から下ろされずにいる理由なのだろう。値段の手頃さも含めて、日々の晩酌に添える一客としてちょうどいい器だと思う。 関連記事: 東洋佐々木ガラス カラフェ・バリエーションの仕様と使い方 — 氷を閉じ込めた、薄まらない冷酒のための器 · 東洋佐々木ガラス 片口
