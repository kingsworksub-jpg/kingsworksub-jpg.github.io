徳利

ピーコック 真空二重構造 酒器セットの仕様と使い方 — 魔法瓶メーカーが本気で作った、温度を止める徳利

徳利とおちょこなのに、中身は魔法瓶。大阪の老舗魔法瓶メーカー、ピーコック魔法瓶工業の「酒器セット ACF-38」を見ていく。陶器でもガラスでもなく、ステンレスの真空二重構造でできた徳利、という時点でもう普通の酒器とは違う設計思想を感じる一本だ。 徳利は真空、おちょこは中空 — ステンレス2枚の間に仕込まれた仕掛け ピーコック 酒器セット ACF-38Amazonで見る → この徳利の芯にあるのは、ステンレスを2枚重ねてその間を真空にする、水筒や魔法瓶と同じ構造だ。真空の層は熱をほとんど伝えないので、注いだ酒の温度が外気に引っ張られにくい。徳利がこの完全な真空二重構造なのに対して、セットのおちょこは中空二重構造という一段軽い作りになっている。おちょこは手にすぐ持って口をつけるものなので、完全真空にして分厚くするより、この使い分けの方が理にかなっていると思う。 容量は徳利が0.3L、おちょこが0.08L×2個。重さは徳利が約190g、おちょこが1個約40gで、ステンレス製にしては軽い部類に入る。テーブルに置いたときの安定感と、片手で持ち上げたときの軽さのバランスがちょうどいい。 保温1時間で63℃以上、保冷1時間で7℃以下 メーカーが公表している数値は、保温効力が1時間後で63℃以上、保冷効力が1時間後で7℃以下。この手の性能表示は魔法瓶メーカーらしい律儀さで、感覚的な「冷めにくい」ではなく、きちんと数字で裏を取っているところに安心感がある。 陶器やガラスの徳利だと、燗酒は注いだ端から冷め始めて、冷酒はあっという間に常温に近づいていく。長っ尻の宴会や、料理の合間に手が止まりがちな家飲みでは、最後の一杯だけぬるくなってがっかりする、という経験は誰にでもあるはずだ。この徳利はその劣化のスピードをかなり後ろにずらしてくれる。ステンレスの器越しに酒の色や輝きを楽しむことはできなくなるが、温度という一番大事な要素を長く守ってくれるのは実用面で大きい。 注ぎ口が狭いのにも理由がある 徳利の口径は3cmほどしかない、絞り込まれた形状になっている。見た目は単に細身の徳利だが、この狭さは保温・保冷にも一役買っている。口が広いと、そこから空気に触れる面積が増えて温度が逃げやすくなるためで、機能を優先した結果としてこのシルエットに落ち着いたのだろうと感じる。おちょこの内側は鏡面仕上げになっていて、注いだ酒の透明感がステンレスの上でも際立つように作られているのも細かい配慮だ。 電子レンジはNG、燗はよそで作ってから移す 食洗機・食器乾燥機には対応しているので、日常使いの手入れは楽な部類に入る。一方で電子レンジと直火・湯せんでの加熱には対応していない。燗をつけたいときは、別の容器やレンジ対応のちろりで温めてから、この徳利に移し替える必要がある。保温力の高さと引き換えに、徳利自体で燗をつける手軽さは犠牲になっている格好だ。この一手間を面倒と見るか、温度が長持ちする代償として納得するかで評価が分かれるところだと思う。 大阪の魔法瓶御三家、3番手のブランド ピーコック 酒器セット ACF-38Amazonで見る → ピーコック魔法瓶工業は1950年、大阪・福島区で創業した会社だ。象印マホービン、タイガー魔法瓶という先発2社に続く形で、同じように動物の名前を社名に冠して立ち上げられたという成り立ちを知って、なるほどと思った。象・虎・孔雀と並ぶ、大阪発祥の魔法瓶御三家の一角ということになる。 創業当初はガラス製魔法瓶の輸出が主力で、国内向けの販売を始めたのはその数年後から。1968年には業界に先駆けて回転式ポットを開発するなど、真空断熱の技術を軸に電気ポットや電気調理器、ステンレスボトルへと製品領域を広げてきた。2025年に創立75周年を迎えていて、この酒器セットもその蓄積の延長線上にある製品だと考えると納得感がある。酒器という枠でくくると変わり種に見えるが、作っている会社からすれば「いつもの真空断熱技術を、徳利という形に落とし込んだだけ」なのかもしれない。 陶器・ガラスの酒器とは、そもそも役割が違う 見た目の情緒や季節感を楽しむなら、陶器やガラスの酒器に分がある。冷酒杯の底に模様が浮かぶような遊び心や、器の質感そのものを愛でる楽しみは、金属の器では再現しにくい。一方でこのステンレス製酒器が強いのは、屋外での家飲みやキャンプ、長時間の来客対応など、温度をできるだけ長くキープしたい場面だ。割れる心配がいらないという気安さも、贈り物として渡すときのハードルを下げてくれる。 酒器としての表情の豊かさを取るか、温度という実用性を取るか。この製品は完全に後者に振り切った設計で、その割り切りの潔さが個性になっていると思う。 価格と購入先 樽のようなにおいが気になったという声を見かけたこともあるが、これは個体差や初期使用時のにおい移りの範囲だと捉えていいと思う。全体としては、機能性を軸にした実用派の酒器として、素直に良い選択肢だという印象を持った。 酒が冷めていく速さにため息をついたことがあるなら、この徳利は試す価値がある。器としての情緒よりも、注いだ一杯目と最後の一杯の温度差をなくすことに全振りした、魔法瓶メーカーらしい割り切りが効いている一本だ。 関連記事: BODUM DOUROの仕様と使い方 — ドウロ渓谷のぶどう畑をまとった徳利 · KEITH 純チタン おちょこ 酒器 2個セットの仕様と使い方 — 東洋佐々木ガラス カラフェ・バリエーションの仕様と使い方 — 氷を閉じ込めた、薄まらない冷酒のための器

冷酒を氷で冷やすと、どうしても味が薄まる。その当たり前の悩みに、ガラスの構造だけで答えを出した器がある。東洋佐々木ガラスの「カラフェ・バリエーション」徳利(氷ポケット付、品番61048DV)を見ていく。 氷を入れるのに、酒には触れさせない 東洋佐々木ガラス カラフェ・バリエーション 徳利(氷ポケット付)360ml(61048DV)Amazonで見る → この徳利のいちばんの見せ場は、胴の中央に空いた大きな空洞だ。ここに氷を入れるのだが、そのポケットは容器の内側に向かって入り組んだ形状になっていて、酒そのものには氷が直接触れない。氷はあくまでガラスの壁を介して酒を外側から冷やす役目に徹し、溶けた水も外にこぼれないよう下方に向かって空洞が続く造りになっている。 「氷で冷やすと薄まる」という冷酒の永遠の悩みを、添加物でも保冷剤でもなくガラスの成形だけで解決しているのが気持ちいい。仕組みを知ってから使うと、ただの装飾だと思っていた胴のふくらみが急に機能パーツに見えてくる。 セミレッドクリスタルという素材 素材はセミレッドクリスタルガラス。クリスタルガラスは酸化鉛や酸化カリウム・酸化バリウムなどを一定量含むガラスの総称で、含有率によってフル・セミといった区分がある。通常のソーダガラスより屈折率が高く、光を受けたときの透明感と輝きが違う。氷ポケットの部分にだけ淡いブルーの色ガラスを差し込んでいるのも効いていて、冷たさを視覚的に伝えるデザインになっていると思う。 成形はハンドメイド。機械成形と手作業の両方の設備を持つ工場で作られているという説明を見かけたが、この徳利は職人の手仕事によるラインの一本だそうだ。量産品にはない、胴の丸みの微妙な揺らぎがそれを物語っている。 サイズと容量 — ちょうど2合 容量は360ml。日本酒の単位でいうと1合=180mlなので、ちょうど2合分が入る計算になる。サイズはΦ46(最大106)×高さ137mmで、重さは約220g。一人で静かに飲むにも、二人でつまみながら飲むにも収まりのいい量だと感じる。 同じシリーズには180ml前後の小サイズもあるようで、来客の人数や飲む量に応じてサイズを選べるのもありがたい。 手入れと温度帯 — 食洗機OK、加熱はNG 食器洗浄機には対応している一方、電子レンジ・オーブン・熱湯を使った加熱には対応していない。氷を使う前提の器なので当然ではあるが、燗をつける道具ではなく、冷酒専用と考えたほうがいい。 ガラス製の酒器全般に言えることだが、急激な温度変化には弱い。冷蔵庫でよく冷やしてから使い、洗浄後は自然乾燥させる、という程度の気遣いで十分長く付き合えると思う。 明治から続く、ガラスの老舗の合流点 東洋佐々木ガラス カラフェ・バリエーション 徳利(氷ポケット付)360ml(61048DV)Amazonで見る → 東洋佐々木ガラスという社名は2002年に生まれたもので、そこには2つの流れが合流している。ひとつは1878年創業の東洋ガラス、もうひとつは1902年に東京・神田で石油ランプの販売から始まった佐々木硝子だ。佐々木硝子は戦後にガラス食器の卸販売へ軸を移し、東証一部にまで名を連ねた時期もあったが、平成に入って経営再建を経験している。その佐々木硝子とハウスウエア事業を担っていた東洋ガラスが統合して、今の社名になった。 本社と工場は千葉県八千代市。1967年には国内初の口部強化ガラス「ハードストロング」を世に出した実績もある会社で、業務用グラスの世界ではよく知られた存在だ。この酒器シリーズでは以前、同社が製造を手がける「柳宗理デザイン 清酒グラス」を取り上げたが、あの脚付きグラスとこの氷ポケット徳利は、実は同じ工場から生まれている。片方は工業デザイナーの名を冠したロングセラー、もう片方は機構そのものが主役という、対照的な個性の出し方が面白い。 価格と購入先 — 現行のシリーズ品 価格は店舗によって幅があり、定価5,600円前後から、セール時には4,400円程度まで下がる例も見かける。取り扱いは業務用食器店や雑貨系のオンラインショップが中心で、Amazonでも購入できる。生産終了や後継機への切り替えを示す情報は見当たらず、現行のシリーズ品として問題なく選べる状態だ。 化粧箱の有無は店舗によって表記が異なるようなので、贈り物として使う場合はギフト対応の可否を購入前に確認したほうが安全だと思う。 氷を入れるだけで、酒は薄めずに冷やす。仕組みとしては単純なのに、実際に手に取ると「よくこんな形を思いついたな」と感心してしまう。デザインの美しさと機能が一致している道具は、使うたびに少し得意げな気分になれる。晩酌の定番になりそうな一本だ。 関連記事: 東洋佐々木ガラス
