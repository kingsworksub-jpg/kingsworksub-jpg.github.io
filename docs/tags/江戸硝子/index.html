江戸硝子

田島硝子 金箔富士 冷酒杯(桜)の仕様と使い方 — 盃の底に、紅と金で沈む富士山

盃の底に富士山が立っている。それも、酒を注ぐたびに色を変える富士山だ。東京の老舗ガラスメーカー、田島硝子の「金箔富士 冷酒杯(桜)」を見ていく。 「被せ硝子」という二重構造 田島硝子 金箔富士 冷酒杯(桜)Amazonで見る → この盃の見た目のインパクトは、透明なガラスの上にもう一枚、薄い色ガラスを重ねる「被せ硝子(きせがらす)」という技法から来ている。職人が透明なガラスの生地に、0.2〜0.3mmほどの薄さで色ガラスをひとつずつ吹き重ねていくのだそうで、この一枚がロックグラスのボディに紅色の帯を作っている。そこにさらに金箔の装飾を施すことで、単色のガラスとは違う奥行きが出ている。 田島硝子はこの被せ硝子を、江戸切子の材料としても長年供給してきたメーカーだと知って、なるほどと思った。切子細工に使われる色ガラスの生地を作る側の会社が、自社ブランドとしてこういう装飾グラスも手がけているというのは、素材屋としての引き出しの多さを感じさせる。 底に沈む富士山 — 酒を注ぐと表情が変わる このシリーズの一番の仕掛けは、グラスの底に成形された富士山のシルエットだ。透明な部分に山の形が浮かび上がっていて、そこに冷酒を注ぐと、酒の色が山の周りに回り込んで、素面のときとは違う富士山の表情になる。日本酒なら淡く、梅酒や果実酒なら色濃く、注ぐものによって同じ富士山が違う顔を見せるのがおもしろい。 底の紅色の帯と金箔の装飾が、山の稜線のあたりに雪ならぬ夕焼けを乗せているようにも見える。ただの飾りグラスというより、酒を注いで初めて完成する器だと思う。 江戸切子ではなく、江戸硝子 見た目の華やかさから江戸切子と混同されがちだが、これは切子(カットを入れる技法)ではなく江戸硝子という別の伝統工芸に分類される。東京都の伝統工芸品に指定されているのは硝子生地そのものの製法で、そこに文様を彫り込むのが江戸切子、色や被せで表情を作るのが江戸硝子、という住み分けになる。この冷酒杯にはカットの切り込みは一切入っておらず、色被せと金箔だけで模様を作っているので、素直に江戸硝子の仕事として見るのが正確だと思う。海外の販売ページではこのあたりがまとめて「エドキリコ」と紹介されていることもあるようだが、厳密には別物ということは知っておいて損はない。 サイズと色 — 「桜」は淡いピンクではなく紅系 口径は56mm、高さ76mmほどの小ぶりなショットグラスサイズで、冷酒をきゅっと一杯という量しか入らない。ラインナップには瑠璃(青)、金赤、黒、緑なども並んでいて、この「桜」はその中でも紅色寄りの一本だ。名前から桜色の淡いピンクを想像していたが、実物は金赤に近い、赤とピンクの中間のような濃いめのトーンだった。パッケージ写真だけで選ぶと色の印象が変わる可能性があるので、そこは知った上で選んだほうがいい。 化粧箱のサイズは70×97×70mmとコンパクトで、贈り物として渡すにも困らないサイズにまとまっている。 冷酒専用 — 電子レンジと食洗機はNG 名前の通り「冷酒杯」なので、燗酒には向かない。急激な温度変化に弱いガラスの性質上、電子レンジや食洗機の使用は避けたほうがよく、手洗いでスポンジを使ってやさしく洗うのが基本の手入れになる。他の食器と一緒に洗うとぶつかって欠けやすいので、単独で洗うくらいの気遣いはしてあげたい一本だ。 ソーダガラス特有の話として、洗浄後に水滴が残ると跡が白く曇って見えることがあるが、これは汚れではなく、乾いて拭き上げれば元の透明感に戻る。神経質になりすぎず、使うたびに拭き上げる習慣をつければ十分だと思う。 1956年創業、江東区のガラスメーカー 田島硝子 金箔富士 冷酒杯(桜)Amazonで見る → 田島硝子は1956年に東京・江東区で創業し、現在は3代目に代を重ねている会社だ。もともとは江戸切子向けの色被せガラスを生地として供給する仕事を長く手がけてきたメーカーで、その中で薄い被せガラスの技術を磨き上げてきた背景がある。この冷酒杯シリーズも、その蓄積の上に生まれたブランド展開のひとつという位置づけになる。 このシリーズを含む「富士山グラス」のラインは、おみやげグランプリでグランプリと観光庁長官賞を受賞した実績を持つ。空港や百貨店の土産物コーナーで見かけることが多いのも納得で、日本らしいモチーフをガラスの技術で仕上げた、お土産の定番という立ち位置を確立している。実際、海外向けのショップでも同じ富士山グラスのシリーズを扱っているところが複数あり、国内外どちらでも通用する一本になっているようだ。 価格と購入先 価格は公式オンラインショップで8,800円(税込)。Amazonでも単体の桜カラーが購入でき、瑠璃(青)との2個セットなど、ギフト向けの組み合わせ販売も見かける。生産終了や後継モデルへの切り替えといった情報は見当たらず、現行ラインナップとして問題なく選べる状態だ。 化粧箱の仕様や同梱物(ポストカードなど)はセット構成によって差があるようなので、贈り物にする場合は購入前に商品ページの内容をよく確認しておくと安心だと思う。 底に沈んだ富士山に酒を注いだ瞬間だけ、この盃は完成する。ただ眺めて美しいだけでなく、使うたびに違う表情を見せてくれるところが、この一杯を手元に置いておきたくなる理由なのだと思う。 関連記事: 廣田硝子 ちろりの仕様と使い方 — 廣田硝子 ちろりの仕様と使い方 — 大正の灯りを一本の耐熱ガラスに閉じ込める

「ちろり」と聞いてすぐに形が思い浮かぶ人は、今どれくらいいるだろうか。本来は錫や銅で作られた、湯煎で燗をつけるための酒器の名前だ。その金属の道具を、東京・墨田区のガラスメーカー廣田硝子がハンドメイドのガラスで作り直したのが今回見ていく一本になる。 そもそも「ちろり」とは何なのか 廣田硝子 ちろり 青 中子付きAmazonで見る → ちろりは江戸時代後期に登場したとされる酒器で、円筒形の器にコの字形の持ち手が付いた独特の形をしている。役割は燗徳利とは少し違っていて、酒を直接火にかけるのではなく、お湯を張った鍋に浸けて湯煎で温めるための道具だ。金属製ならではの熱伝導の良さを活かして、短時間でむらなく燗をつけられるのが本来の使い方になる。 名前の由来は諸説あって、地炉裏(いろり)に埋めて温めたからという説、短時間で燗がつくことから「ちろり」と呼ばれるようになった説、注ぎ口から酒が落ちる音に由来する説などが並んでいる。どれが正解かは決め手に欠けるが、燗酒文化とともに古くから使われてきた道具であることは間違いない。 金属の道具を、あえてガラスで作る 廣田硝子のちろりが面白いのは、本来は不透明な金属だった道具を、透明なガラスに置き換えている点だ。中身の温度が変わっていく様子も、酒の色も、外から丸見えになる。実用の道具としての機能はそのままに、鑑賞の楽しみを足しているという意味で、単なる素材変更以上の再解釈だと思う。 このデザイン自体は1980年に廣田硝子の社内デザイナーが手がけたもので、40年以上ほとんど形を変えずに作り続けられているロングセラーだという。流行り廃りの早い食器の世界で、これだけ長く同じ形が支持され続けているのは単純にすごいことだと思う。 「中子」という発想 — 一本で燗も冷やもこなす このちろりの構造で一番おもしろいのが、内側に入れる「中子」という取り外し可能なパーツだ。冷酒で飲みたいときはこの中子に氷を入れてちろり本体にセットする。氷が酒に直接触れないので、薄まる心配をせずに冷やせる仕組みになっている。逆に燗をつけたいときは中子を外し、ちろり本体をそのままお湯に浸けて湯煎する。 つまり同じ一本のガラスで、季節や気分に応じて燗にも冷やにも対応できるということになる。本体は耐熱ガラス製、中子側はソーダガラス製と素材を使い分けていて、持ち手や蓋まわりには銀メッキを施した真鍮が使われている。ガラスと金属、質感の違う素材が組み合わさっているぶん、テーブルに置いたときの表情も豊かだ。 扱い方の注意点 耐熱ガラスとはいえ、直火にかけて温める使い方は想定されていない。あくまで湯煎が基本で、いきなり火であぶるような使い方は避けたほうがいい。食洗機についても対応をうたっていないので、手洗いでのお手入れが安心だと思う。多少手間はかかるが、ガラスと真鍮の組み合わせという凝った作りを考えれば、そのくらいの気遣いは自然なことに感じる。 廣田硝子という会社 — 1899年創業、江戸硝子の担い手 廣田硝子 ちろり 青 中子付きAmazonで見る → 廣田硝子の創業は1899年(明治32年)。新潟出身の初代・廣田金太が東京でガラス商を始めたのがルーツで、1915年には墨田区にあたる本所区にガラス工場を構え、ランプのほや作りからものづくりを広げていった。関東大震災、東京大空襲と二度の大きな被災を経ながらも復興し、1950年に廣田硝子株式会社として現在の体制になったという歴史を持つ、東京でも指折りの老舗ガラスメーカーだ。 代表的なラインには、大正時代の乳白ガラスを復刻した「大正浪漫硝子」や、江戸切子の技術を受け継ぐシリーズなどがある。効率よりも職人の手仕事を優先するものづくりを掲げていて、このちろりもその方針の延長線上にある一本という位置づけだと思う。 価格帯について この「青・中子付き」モデルはAmazonで38,500円という価格になっている。廣田硝子のちろりシリーズの中では、透明ガラスの基本モデルが2万円前後からラインナップされているので、色ガラスを使ったこのモデルはシリーズの中でも中〜上位の価格帯に位置する。色ガラスは透明ガラスより成形や発色の管理に手間がかかるぶん、価格に反映されている面があるのだろうと思う。派手な値付けというより、手仕事の工程を積み上げた結果としての価格という印象を受けた。 生産終了の兆候は見当たらず、公式サイトや複数の正規取扱店で現行商品として扱われている。長く作り続けられてきたロングセラーということもあって、今すぐ入手できなくなる心配はあまりしなくてよさそうだ。 金属の道具をあえてガラスに置き換えることで、温度の移ろいそのものが見える酒器になった。燗と冷や、季節によって使い分けられる一本を、食卓の主役に据えてみるのも悪くないと思う。 関連記事: 田島硝子 金箔富士
