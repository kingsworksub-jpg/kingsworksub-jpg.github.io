津軽びいどろ 片口あじさいの仕様と使い方 — 龍飛崎の紫陽花を写した一滴

冷酒を注ぐ器といえば徳利を思い浮かべる人が多いと思うが、注ぎ口が開いた「片口」という形もある。アデリアの「津軽びいどろ 片口あじさい」を、この夏らしい水色の器として見ていく。 浮き玉づくりから食卓の器へ アデリア(ADERIA) 津軽びいどろ 片口 あじさい 250ml(F71403)Amazonで見る → 津軽びいどろを作っているのは、青森市の北洋硝子という会社だ。もともとは1949年、漁業で使うガラスの浮き玉(浮き球)を作る会社として始まっている。この浮き玉づくりで培った「宙吹き」という、型を使わず息と道具だけでガラスを膨らませる技術が、今の津軽びいどろの土台になっているらしい。1973年には浮き玉の国内生産量で首位に立ったというから、当時はかなりの規模で作っていたのだろう。 ただ、プラスチック製の浮き玉が普及するにつれて需要は先細りになっていく。そこで1977年、宙吹きの技術をそのまま生かして食器・インテリア雑貨に軸足を移したのが「津軽びいどろ」というブランドの始まりだ。1996年には青森県の伝統工芸品にも指定されている。七里長浜の砂を偶然溶かし込んだところ深い緑色のガラスができた、という逸話も伝わっていて、色ガラスへのこだわりは創業当初からの気質のように思う。 あじさいという意匠 — 龍飛崎の紫陽花 この片口の見た目でいちばん目を引くのは、水色の斑点が散った表面だ。津軽びいどろにはいくつも色柄のシリーズがあるが、これは「盃コレクション」というラインの「あじさい」という柄にあたる。津軽半島の龍飛崎に咲く紫陽花からヒントを得た配色だと知って、なるほどと思った。青森という土地の風景を実際に色にする、というのがこのブランドのものづくりの姿勢のようだ。 紫陽花そのものにも興味深い性質がある。花の色は土壌のアルミニウムイオンの量で決まり、酸性の土ではアルミニウムが溶け出しやすくアントシアニン色素と結びついて青くなり、中性〜アルカリ性の土では赤みが強く出る。同じ株でも土によって色が変わるというのは、園芸をやる人ならよく知る話だろう。花言葉としては「辛抱強い愛情」「家族団らん」などが当てられていて、小さな花が寄り集まって一つの大きな塊になる姿から来ているそうだ。梅雨の時期に咲き、雨に打たれながらも姿を保つ花なので、ちょうど今の季節にひんやりしたガラスの器で使うのにふさわしい柄だと思う。 素材とサイズ — 手仕事ゆえの個体差 素材はソーダガラス。サイズは最大幅・高さともに約95mm、口径87mm、容量は満水で約250ml、重さは285g前後とされている。職人の手作業で一つひとつ吹いて作られているため、色柄や重さ、寸法にはある程度の個体差が出るという説明がある。手にとって並べてみると、同じ「あじさい」でも斑点の出方が微妙に違う個体があってもおかしくない、という前提で選ぶ器だ。 手入れの面では少し注意がいる。公式の商品ページには、耐熱ガラスではないため電子レンジは使えず、食洗機にも対応していないとはっきり書かれている。ソーダガラス自体は一般的に扱いやすい素材だが、この片口のように手吹きで肉厚が均一でないガラスは、急激な温度変化や食洗機の熱・洗剤で傷みやすい。日々の手入れは手洗いが基本、と覚えておいた方がいい。 片口という酒器のかたち — 徳利との住み分け 片口は、片側に注ぎ口が付いた鉢状の器のことで、もともとは醤油やみりんを計って注ぐ台所道具として使われてきた形らしい。それが日本酒の器としても定着したのは、徳利と同じく酒を注ぐための道具として自然に転用されたからだと思う。 徳利との違いは口の広さにある。徳利は首が細く閉じているぶん香りを閉じ込めやすく、燗をつけたときに温度も保ちやすい。一方の片口は口が大きく開いているぶん空気に触れる面積が広く、香りがふわっと立ちやすい。冷酒、特に香りの華やかな吟醸系の酒を、まず目と鼻で楽しんでから注ぐ、という飲み方に向いている形だと感じる。ゆっくり注ぐと注ぎ口から液だれしやすいという注意書きもあったので、そこは徳利にはない片口特有のクセとして覚えておきたい。 津軽びいどろを展開するアデリアの母体は、愛知県で1819年に創業した石塚硝子だ。尾張藩の御用でガラスを作っていたのが始まりというから、200年以上の歴史を持つ会社ということになる。実際、2019年には創業200周年を迎えている。アデリアというブランド自体は1961年に食器ブランドとして立ち上がったもので、津軽びいどろのほかにも、近年人気の「アデリアレトロ」のような復刻デザインのシリーズまで幅広く手がけている。片口一つとっても、老舗ガラスメーカーが地方の伝統技術ブランドを支える、という構図が背景にあるわけだ。 価格と購入先 — 現行のシリーズ 「あじさい」柄の片口は、津軽びいどろの公式オンラインストアで税込2,750円、Amazonでも同じ価格帯で取り扱いがある。品番F71403は「NEBUTA」のシリーズ名でも呼ばれているようで、化粧箱入りのため贈り物にも向いている。母の日・父の日・敬老の日・長寿祝いといった贈答用途で紹介されているのを見かけたが、季節の柄として自宅用に選んでも十分楽しめる器だと思う。 盃コレクションにはお揃いの盃(ぐい呑み)もラインナップされているので、片口と色柄を合わせて選ぶと食卓の統一感が出しやすい。 漁業の浮き玉づくりから始まった技術が、紫陽花の色を映す酒器にたどり着いている、というのがこの片口の面白いところだと思う。派手さより季節感を選びたいときに、食卓に置いておきたい一品だ。 関連記事: 津軽びいどろ みずばしょう酒器セットの仕様と使い方 — 東洋佐々木ガラス 片口 冷酒カラフェの仕様と使い方 — 注ぎ口ひとつに宿る、千三百年の知恵

「片口(かたくち)」と聞いて、すぐに形が思い浮かぶ人はそう多くないと思う。もともとは醤油や出汁、酢といった液体を注ぐための台所道具で、酒器の主役というよりは裏方の存在だった。それがいつのまにか、日本酒の香りを立たせるための器として食卓に上がるようになった。東洋佐々木ガラスが作るこの片口は、そんな器の役割の移り変わりを、ガラスという素材でわかりやすく体現している一本だと思う。 そもそも「片口」とは何なのか 東洋佐々木ガラス 片口 冷酒カラフェ 240mlAmazonで見る → 片口は、片側にだけ注ぎ口が付いた、首のない広口のボウル型の器のことを指す。奈良の平城京跡からも出土例があるそうで、その歴史はおよそ1300年に及ぶという。もとの用途は日本酒に限らず、醤油や出汁、酢、油といった液体全般を注ぎ分けるための調理道具だった。宮廷儀式で使われた「銚子」という柄付きの酒器から、徳利や片口へと形が枝分かれしていった系譜の中に位置づけられる器でもある。 つまり片口は「酒器」として生まれたわけではなく、あくまで実用の台所道具として長く使われてきた器だ。それが冷酒文化の広がりとともに、日本酒を注ぐための、それも視覚的に楽しむための道具として再評価されるようになった、というのが個人的にいちばん面白いと感じるポイントだ。 片口とお猪口・徳利、何が違うのか 同じ「注ぐ・飲む」酒器でも、それぞれ役割が分かれている。お猪口やぐい呑みは口に直接運んで飲むための器で、徳利は首が細くくびれた形で、保温性と見た目の両方を意識した「注ぐ」ための器になる。それに対して片口は、首のない開いたボウル形状に注ぎ口が付いているだけのシンプルな構造だ。 この単純さがかえって使い勝手の良さにつながっていて、洗いやすく、注ぐときに酒が空気に触れる面積も広い。日本酒バーなどで、あえて片口からお猪口に注ぐスタイルが好まれるのは、この「注ぐ所作」自体を楽しませる意味合いが大きいのだと思う。 ガラスで作ることの意味 片口自体は陶器や漆器でも作られるが、この製品はあえてガラスという素材を選んでいる。ガラスは無味無臭で、酒そのものの味を素直に(良くも悪くも)引き出す素材だと言われている。陶器や磁器は酒の角を丸めてまろやかにし、錫は独特の作用でクセを和らげるとされるのに対して、ガラスは酒の個性をそのまま伝えてくる感触がある。 もうひとつの利点は、単純に「見える」ことだ。酒の色合いや透明度、注いだときの揺らぎ、氷を入れたロックスタイルの見た目まで、ガラスなら外から丸ごと楽しめる。この片口の表面には波型の凹凸模様が入っていて、光を受けるとそれだけで小さな景色になる。冷酒や常温の酒との相性がよく、雪冷えから花冷えへと温度が上がっていく過程で香りや甘みが変化していく様子を目で追いながら飲めるのは、ガラスならではの楽しみ方だと感じる。 240mlという設計とお手入れの注意点 スペックを見ると、満水で240ml、実際に酒を注ぐ標準的な高さでは180ml程度、ちょうど一合相当になるよう設計されている。素材はソーダライムガラスで、食洗機には対応しているが、電子レンジは不可だ。耐熱ガラスに比べて熱衝撃への耐性が低いため、急激な温度変化を与えると割れるリスクがある。だから熱燗のような熱い酒を注ぐ使い方は想定されておらず、あくまで冷酒〜常温向けの器として割り切って使うのが正解だと思う。 薄手のガラスなので、食洗機に入れる際に他の食器とぶつからないよう気をつけたほうがいい。この手の薄いグラスをうっかり重ねて洗って欠けさせてしまった経験があるので、その点だけは自分への戒めとして書いておきたい。 なお業務用としてもよく流通していて、48個セットのケース販売で飲食店・酒販店向けに卸されている実績もある。家庭用の単品としてだけでなく、日本酒バーのような場でも使われている器だと考えると、実用性の高さにも納得がいく。 東洋佐々木ガラスという会社 東洋佐々木ガラス 片口 冷酒カラフェ 240mlAmazonで見る → 東洋佐々木ガラス株式会社のルーツは1902年、佐々木宗次郎が東京・神田で石油ランプの販売を始めたことにさかのぼる。1947年に佐々木硝子株式会社として法人化し、1962年には東京証券取引所二部に上場するほどの規模に育った。ところが1999年に会社更生法の適用を申請することになり、2002年、東洋製罐グループの東洋ガラスが持つハウスウエア部門と統合されて、現在の「東洋佐々木ガラス株式会社」という社名になった。 本社は千葉県八千代市にあり、同地の工場は国内最大級のガラス製ハウスウエア生産能力を持つとされる。マシンメイドとハンドメイド両方の製造設備を備え、家庭用から業務用まで幅広いグラスウェアを手がける、業界でも指折りの規模のメーカーだ。ホテルやレストラン向けの強化グラス「HS(ハードストロング)」シリーズなどが代表的な製品ラインとして知られている。今回の片口も、そうした業務用グラスウェアで培われた品質管理の延長線上にある一本なのだと思う。 価格帯と現行性について 価格は728円から880円程度と、酒器としてはかなり手に取りやすい部類に入る。複数の酒類専門店や生活雑貨店、大手ECサイトで現在も継続して取り扱われていて、生産終了を示すような情報は見当たらない。ワンコインに近い価格で、片口という器の楽しさを試してみるにはちょうどいい選択肢だと思う。 もとは台所の裏方だった器が、注ぎ口ひとつと透明な素材のおかげで、食卓の主役になれることを教えてくれる一本だと思う。冷酒を一合分だけ用意して、ゆっくり温度の変化を眺めながら飲む夜も、たまには悪くない。 関連記事: 東洋佐々木ガラス カラフェ・バリエーションの仕様と使い方 — 氷を閉じ込めた、薄まらない冷酒のための器 · 柳宗理デザイン 清酒グラスの仕様と使い方 —
