陶磁器

有田焼 炎華 酒器セットの仕様と使い方 — 黒い炎を宿した徳利とぐい呑み

酒器の産地というと、このブログでもすでに九谷焼や美濃焼を取り上げてきたが、日本の磁器の歴史そのものを語るなら避けて通れないのが佐賀県有田町の「有田焼」だ。今回はその有田焼を名乗る「炎華」という酒器セット(徳利1個・ぐい呑み2個・木箱入り)を隅から隅まで見ていく。 有田焼という産地 — 日本の磁器はここから始まった 有田焼 炎華 酒器セット(徳利1個・ぐい呑み2個)Amazonで見る → 有田焼の起源は1616年、朝鮮出兵に同行してきた陶工・李参平が有田東部の泉山で磁器の原料になる白磁鉱を発見し、日本で初めて磁器を焼いたことに遡るとされている。それまで日本の焼き物は陶器が中心で、白く硬い磁器は中国・朝鮮からの輸入品しか手に入らなかった時代に、国内で磁器が焼けるようになったのは大きな転換点だったらしい。 江戸時代中期以降は、有田で焼かれた磁器が伊万里港から積み出されてヨーロッパにまで輸出され、「Imari」の名でオランダ東インド会社経由で王侯貴族のもとに渡った。透き通るような白磁の肌は当時のヨーロッパで「white gold」と呼ばれ、のちのマイセン窯をはじめとする西洋磁器の発祥にも影響を与えたと言われている。「有田焼」と「伊万里焼」はもともと同じ産地の製品を指す言葉で、現在では生産地としての呼び名が「有田焼」、江戸期の様式を指す呼び名が「古伊万里」というふうに使い分けられることが多い。 1977年には経済産業大臣指定の伝統的工芸品に認定され、現在も佐賀県有田町には100を超える窯元が点在している。焼き物としての産業規模自体は往時に比べると縮小しているようだが、産地としては今も現役で、柿右衛門・今右衛門・香蘭社といった名の知れた窯元がそれぞれの様式を受け継いでいる。今回の「炎華」はそうした個人作家・伝統窯元の作品ではなく、産地の問屋が企画した量産ラインの酒器という位置づけで、価格帯からもそれは見て取れる。 「炎華」という名の由来 — 赤絵ではなく、黒釉の窯変 有田焼というと、白磁に藍色の染付や赤・金の色絵を施した華やかなイメージを持つ人が多いと思う。柿右衛門様式や色鍋島がその代表格で、実際にヨーロッパへ渡った「Imari」もこの手の絵付けが評価された。ところが今回のセットの「炎華」は、そのイメージとは少し違う顔つきをしている。 徳利もぐい呑みも、地の色は深い黒。よく見ると表面には炎が揺らめいたような不規則な模様が浮かび、光の当たり方によって金や緑がかった光沢がふっと現れる。これは絵付けで描いた文様ではなく、釉薬が高温で焼かれる過程で偶然生まれる「窯変」という現象によるものらしい。油滴天目のような、狙って完全に同じ表情を再現するのが難しい、焼き上がってみないと分からない部分が残る仕上げだ。名前の「炎」は、まさにこの窯変が描き出す模様から来ているのだと理解している。 素材の表記も正直に書いておきたい。有田焼というと磁器を思い浮かべがちだが、この「炎華」シリーズは商品情報上、陶器として扱われている。つまり、白く薄い伝統的な染付磁器とは違う、黒釉をまとった陶器寄りの作りだ。有田・波佐見という産地表記自体は正確だが、「有田焼=白磁」という思い込みのままこの商品を見ると、少し意外に感じるかもしれない。 セットの中身とサイズ感 セットの内容は徳利1個、ぐい呑み2個。徳利は直径9cm×高さ12cm程度で容量は360ml(2合)、ぐい呑みは直径6.5cm×高さ4cm程度とやや小ぶりだ。木箱には「感謝を込めて」という文字が箱の側面に入っており、退職祝いや長年の労をねぎらう贈り物として企画された商品だということが箱を見ただけで伝わってくる。 徳利の胴は轆轤目がそのまま残るような、ろくろの筋がうっすら見える成形になっていて、黒釉の照りと相まって落ち着いた存在感がある。ぐい呑みは内側にも同じ黒釉がかかっていて、注がれた酒の色を邪魔しない深い色合いになっている。派手な絵付けの器とは対照的に、静かに主張してくるタイプの酒器だと感じている。 磁器・陶器としての実用面 有田焼 炎華 酒器セット(徳利1個・ぐい呑み2個)Amazonで見る → 有田焼を含む磁器全般は吸水率がほぼ0%とされていて、匂い移りやカビの心配が少なく、表面がガラス質で汚れも落ちやすい。これまでこのブログで扱ってきた木曽杉の徳利や漆の酒器と比べると、お手入れのしやすさという点でははっきり分がある。熱伝導率が高いぶん、熱燗を注ぐと器自体もすぐ温まるので、うっかり熱いまま手に取ると驚くことになる。逆に言えば冷酒を注いだときの、きりっとした冷たさが手のひらにそのまま伝わってくる感覚は気に入っている。 電子レンジや食洗機への対応については、商品ページに明記がなかった。金彩・銀彩を施した有田焼は電子レンジで火花が出ることがあるため不可とされる製品が多いが、今回の「炎華」は黒釉のみで金属加飾は見当たらないぶんリスクは低そうに見える。とはいえ断定はできないので、心配な場合は手洗いにしておくのが無難だと思う。木箱に収まっているぶん、普段使いというより特別な日の酒器という扱いのほうがしっくりくる。 退職祝いという贈答文化と、このセットの立ち位置 商品自体が「退職祝いのお返し」を想定して企画されているのがこのセットの特徴だ。木箱に一言添えられているだけで、開ける前から相手に気持ちが伝わる贈り物になる。日本の贈答文化では、産地の歴史や職人の手が加わった道具に贈り手の気持ちを乗せるという発想が根強く残っていて、有田焼という400年続く産地の名前そのものが、その役割を後押ししている面があると思う。 もちろん自分用に買って晩酌に使うのも普通にありだ。柿右衛門や今右衛門のような窯元ブランドの酒器は数万円クラスになることも珍しくないが、こちらは産地問屋の企画品ということもあって手の届きやすい価格帯に収まっている。有田焼という名前に触れてみたい人の入り口としてはちょうどいい立ち位置だと感じる。 価格・現行性について Amazonでの価格はおおむね7,000円台後半。有田焼やきもの市場という産地の通販サイトでも同じ「炎華」シリーズ(徳利単体、盃単体、セット)が扱われていて、在庫も継続的に確認できる状態だった。生産終了の兆候は見当たらず、現行品として問題なく入手できる。 ちなみに「炎華」には徳利のみ、盃のみといった単品展開もあるので、割れてしまったときや買い足したいときに個別に補充できるのは実用面でありがたいポイントだと思う。 華やかな染付や色絵で魅せる有田焼のイメージとは違う、黒く沈んだ窯変の表情でじわじわ存在感を出してくる酒器だった。贈り物としてはもちろん、自分の晩酌に一本置いておくのも悪くない選択だと思う。 関連記事: 国産美濃焼 黒千代香の仕様と使い方 —
