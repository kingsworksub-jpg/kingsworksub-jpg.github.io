国産美濃焼 黒千代香の仕様と使い方 — 焼酎に千代の香りを移す、直火のもてなし

「ちょか」という響きだけを聞くと、酒器というより丸っこい小動物の名前のように思えてしまう。実際の姿もどこか愛嬌があって、そろばん玉のようにふっくらした胴に、つると注ぎ口が付いた黒い急須型の器だ。この黒千代香(くろぢょか)は、焼酎を直火にかけてじっくり燗をつけるための、鹿児島生まれの伝統的な酒器を、岐阜の美濃焼で作り直した一本になる。 「黒千代香」という名前の由来 国産美濃焼 黒千代香 2合セットAmazonで見る → 黒千代香の起源には諸説あって、これといった定説はないらしい。琉球の泡盛用酒器が伝わったという説もあれば、16世紀末に薩摩に渡ってきた朝鮮系陶工の系譜に連なるという説もある。いずれにしても、日本酒造りに向かない気候の鹿児島で、代わりに焼酎文化が根付き、そのもてなしの道具として発達してきた器だというのが背景にあるようだ。 「黒千代香」という名前そのものは、鹿児島の黒薩摩の窯元が、錦江湾に浮かぶ桜島のシルエットにヒントを得てこの丸い形を考案し、「焼酎が千代に香る」という願いを込めて名付けた、という説が広く知られている。中国の急須「茶壺」に由来する説や、注ぎ口の形がイノシシの牙に似ることから「猪牙(ちょか)」と呼ばれ始めたという説もあり、正直どれが本当なのかは筆者にも判断がつかない。ただ、名前の由来が一つに定まらないくらい古くから、生活に溶け込んだ道具だったということなんだろうと思う。 黒いのは、桜島由来の鉄分を多く含む火山性の土を使った「黒薩摩」の釉薬で焼かれているからだ。この漆黒の光沢を持つ焼き物の系譜は「黒もん」と呼ばれ、龍門司焼や長太郎焼といった鹿児島の窯が本場として知られている。 産地のねじれ — 鹿児島の器を、美濃で作る ここが今回いちばん面白いと感じたポイントなのだけれど、この製品は「国産美濃焼」と銘打たれている。つまり本場・鹿児島の黒薩摩ではなく、岐阜県東濃地方の美濃焼として作られた黒千代香だ。 もともと黒千代香は鹿児島の黒薩摩焼(龍門司焼、長太郎焼など)に固有の器だったが、近年は三重の萬古焼や岐阜の美濃焼でも同じ形の器が作られるようになっている。本場の黒薩摩が持つ希少性やブランド性よりも、実用性と手頃な価格を優先したラインという位置づけになるはずで、この製品にも特定の窯元名は記載されていない。伝統工芸としての一点物というより、日常使いの実用品として割り切って作られたものだと捉えるのが正しい見方だと思う。値段は3,000円台後半と、本場の黒薩摩の器に比べればかなり手が届きやすい部類に入る。 使い方の核心 — 前割りと直火のぬる燗 黒千代香を使いこなす鍵は、器そのものより「前割り」という下準備にある。芋焼酎と水をあらかじめ6対4程度の比率で混ぜ合わせ、一晩から数日、時には1週間ほど寝かせておく。時間を置くことで水と焼酎が分子レベルでなじみ、角の取れたまろやかな味になるとされている。 前割りした焼酎を黒千代香に注いだら、あとは弱火・とろ火でゆっくり温めるだけだ。強火は禁物で、アルコールが急速に飛んで風味が損なわれるだけでなく、器そのものにも負担がかかる。目安の温度は人肌からぬる燗にあたる35〜45℃程度で、熱くしすぎると焼酎の香りや旨味がむしろ逃げてしまうというのが、複数の資料で共通して指摘されている点だった。 これは、お湯を先に注いでから焼酎を後から加える「お湯割り」とは似て非なる飲み方だ。お湯割りが即席の楽しみ方だとすれば、黒千代香の直火燗は、数日かけて熟成させた焼酎を、さらに時間をかけてじっくり温めるという、二段構えの手間を前提にした飲み方になる。せっかちな性格なので、この「待つ」工程を最後まできちんとやり切れる自信はあまりないのだが、それも含めて焼酎と向き合う時間なのだと思えば悪くない。 直火にかけられる理由と、ちょっと眉唾な謳い文句 陶磁器はもともと1,200℃前後で焼成されているので、ある程度の耐熱性は備えている。とはいえすべての陶器が直火に耐えられるわけではなく、耐熱食器では陶土と釉薬の熱膨張率をそろえるためにペタライトという鉱物を配合するなど、専用の技術的な工夫が必要になる。黒千代香が伝統的にどこまでこうした技術に頼っているのかは製品ごとに差がありそうだが、厚手に焼くことで直火に耐える形にしてきたという、職人の経験則に支えられている面が大きいようだ。 販売ページなどでよく「陶器は遠赤外線を発するので焼酎がまろやかになる」という説明を見かけるが、これは正直なところ、裏付けの薄い謳い文句として広く流通している表現だと感じている。嘘だと言い切るつもりはないけれど、科学的な検証をきちんと示している情報には行き当たらなかった。まろやかになる体感自体は前割りと弱火加熱の効果として十分説明がつくので、遠赤外線うんぬんは話半分に聞いておくくらいがちょうどいいと思う。 お手入れ — 洗剤を使わない、という不思議な作法 黒千代香の扱い方でいちばん驚いたのが、「洗剤でゴシゴシ洗わない」という作法だ。陶器は多孔質で、使い込むほど焼酎の香りが器そのものに染み込んでいき、やがてお湯を注ぐだけでほんのり焼酎の香りが立つように育っていく、という独特の楽しみ方があるらしい。使用後は水洗い程度にとどめ、1〜2日かけて自然乾燥させてカビを防ぐのが基本の手入れになる。 電子レンジや食洗機への対応についてはメーカー側の明確な記載が見当たらなかった。急激な温度変化(サーマルショック)がひび割れの主な原因になるとされているので、食洗機の高温すすぎや電子レンジでの加熱は避け、あくまで手洗い・自然乾燥で育てていく器だと考えたほうが無難そうだ。直火にかける際も、加熱前に表面の水気をよく拭き取る、空の状態で火にかけない(空焚き厳禁)、温まった器に急に冷たい液体を加えないといった、温度差を作らない配慮が繰り返し挙げられている。 ちろりや電気酒燗器との違い 同じ「燗をつける酒器」でも、道具によって性格がはっきり違う。ちろりは銅や錫、ステンレスなどの金属製で、湯せん専用の道具だ。熱伝導率が高いぶん、短時間でムラなく均一に温められる。これに対して黒千代香は、前割りした焼酎を直火でじっくり温めるための器で、湯せんはしない。電気酒燗器はさらに現代的な選択肢で、温度を細かく設定・維持できる手軽さが利点になる。 整理すると、黒千代香は「器ごと味に関与させる、手間のかかる伝統的なスタイル」、ちろりは「手早く均一に燗をつける実用スタイル」、電気酒燗器は「温度管理と利便性を優先する現代的なスタイル」というふうに、三者三様の役割分担になっている。手間を楽しみたい夜は黒千代香、とにかく早く一杯やりたい夜はちろりや電気式、という使い分けが現実的なところだと思う。 サイズ・価格・現行性 国産美濃焼 黒千代香 2合セットAmazonで見る → 本体の容量はおよそ400cc(2合相当)、付属のおちょこ2客はそれぞれ40〜50cc程度と、家庭で夫婦や2人で使うのにちょうどいいサイズに設計されている。手作りの陶器らしく、釉薬のムラやダレが個体ごとに出る場合がある旨の注記もあり、その一点物感もこの手の器の楽しみのひとつだと思う。 価格は3,000円台後半から4,000円台後半とサイトによって幅があるが、複数の通販サイトで現在も継続して取り扱われていて、生産終了を示すような情報は見当たらなかった。本場・鹿児島の黒薩摩の黒千代香に比べればかなり手頃な価格帯で、焼酎の「前割り+直火燗」という様式を試してみる入り口としては、ちょうどいい選択肢になっている。 大館工芸社 秋田杉 酒器3点セットの仕様と使い方 — 木曽から立ちのぼる、もう一つの酒の香り

酒器といえばガラスや陶磁器、金属を思い浮かべることが多いが、木でできた徳利とお猪口もある。秋田県大館市の大館工芸社が作る「秋田杉 酒器3点セット」を、今回は隅から隅まで見ていく。 大館曲げわっぱという産地 — 武士の副業から国指定の伝統工芸へ 大館工芸社 秋田杉 酒器3点セット(徳利・お猪口2個)Amazonで見る → 秋田県大館市に伝わる曲げわっぱの起源は平安時代まで遡るとも言われているが、産業として本格的に発展したのは17世紀後半、大館城主・佐竹西家が下級武士の副業として奨励したのがきっかけだったらしい。樹齢200〜300年という天然秋田杉の資源に恵まれた土地柄が、この工芸を支えてきた土台になっている。1980年には経済産業大臣指定の伝統的工芸品にも指定され、今も大館の地場産業として続いている。 大館工芸社は1959年創業のメーカーで、製材から曲げ加工、山桜の皮での縫い留め、底入れ、仕上げまでを一貫して手がけている。現在は伝統工芸士を含む職人が製造にあたっており、曲げわっぱの弁当箱で知られるメーカーだが、徳利やお猪口といった酒器のラインも展開している。 曲げわっぱの技法 — 薄く剥いだ杉を、熱と手で曲げる 曲げわっぱの製法は、天然秋田杉の柾目を薄く剥いで板状にし、それを熱湯に15分ほど浸して柔らかくしたところから始まる。柔らかくなった板を型に沿わせて丸く曲げ、乾燥させて形を固定したあと、継ぎ目を山桜の樹皮で縫い留めて仕上げる。接着剤や金属の留め具にほとんど頼らない、木そのものの性質を利用した技法で、一つの製品が完成するまでに最低でも1年以上はかかるという。 この製法だと木目が一枚板のまま円筒に沿って流れるので、切削や成形とはまた違う、杉本来の木目の美しさがそのまま器の表面に残る。今回のセットも、徳利とお猪口の側面に縦方向の木目がくっきり出ていて、同じ木から作られたはずなのに一つひとつ表情が少しずつ違う。 なぜ杉で酒器を作るのか 杉が酒器の素材として選ばれてきた理由はいくつかあるようだ。まず、杉は熱伝導率が低いため、冷酒を注げば冷たさが持続しやすく、燗酒を注げばほどよい温かさが保たれやすいという性質がある。ガラスや金属の器だと外気の影響を受けて温度が早く変化してしまうのに対し、木の器は中身の温度をゆるやかに保ってくれる、という感覚は実際に使ってみるとよく分かる。 もう一つは香りの効果だ。無塗装の杉であれば木の香りが酒にほのかに移り、味わいに複雑さを加えると言われている。ただし今回のセットはウレタン塗装仕上げになっている点は正確に押さえておきたい。白木のまま使う酒器に比べると香り移りは穏やかで、その代わりに水や汚れへの耐性、お手入れのしやすさという実用面のメリットが出ている仕様だと理解している。無垢の白木にこだわりたい人には物足りないかもしれないが、日常使いの気軽さを取るならこちらの仕様のほうが扱いやすいと思う。 セットの中身とサイズ感 セットの内容は、杉徳利(小)1個と、ぐい呑み(お猪口)2個。徳利は容量約150cc、サイズは60×60×105mm程度。ぐい呑みは容量約35ccで、直径43mm前後×高さ58mm前後とかなり小ぶりなサイズになっている。化粧箱に入って届くので、贈答用としての体裁も整っている。 手のひらに収まるサイズの徳利とお猪口が並ぶと、陶磁器やガラスの酒器とはまた違う、素朴で柔らかい佇まいになる。木目の出方には個体差があるので、届いたものによって色合いや杢目の濃淡が微妙に変わってくる。同じ商品を買っても「自分の一本」感があるのは、天然素材ならではの面白さだと思う。 使い方と手入れの注意点 大館工芸社 秋田杉 酒器3点セット(徳利・お猪口2個)Amazonで見る → 洗い方は、使用後に洗剤とスポンジで洗い、乾いた布で水気を拭き取ってからしっかり乾燥させるのが基本になる。曲げわっぱ全般に言えることだが、電子レンジと食器洗浄機は使えない。急激な乾燥や直射日光も木を反らせたり割れの原因になったりするので、風通しの良い場所で自然乾燥させるのが無難だ。 熱燗にも冷酒にも使える器だが、徳利自体を直火にかけることは想定されていない。燗をつけるときは別の容器でお酒を温めてから、この徳利に移して注ぐという使い方になる。焼酎にも使えるが、個人的には香りの強い純米酒や本醸造あたりの日本酒との相性のほうが好みに合っている。 価格帯・現行性について Amazonでの価格は5,500円前後。大館工芸社の公式オンラインストアでも同一仕様(徳利小・ぐい呑み2個・化粧箱入り)の酒器セットが同じ価格帯で扱われており、単品のぐい呑みが1個880円程度で流通していることを考えると、セットとしての割引がしっかり効いた価格設定になっている。楽天やYahoo!ショッピングでも同ブランドの酒器・ぐい呑みの取り扱いが続いており、現行品として問題なく入手できる状態だ。 なお、Amazon上では「焼印あり」の別バリエーションも見かけるが、今回取り上げたのは焼印なしのシンプルな仕様。木目の美しさをそのまま楽しみたい場合はこちらのほうが向いていると思う。 ガラスや陶磁器の酒器が「光」や「艶」で魅せるのに対して、この杉の酒器は木目と手触り、そして温度の保ち方でじわじわと存在感を出してくる。派手さはないぶん、晩酌の道具として長く使い込んでいくのに向いている一本だと思う。 津軽びいどろ みずばしょう酒器セットの仕様と使い方 — 湿地に咲く白い花を、青いガラスに閉じ込めて

これまで陶磁器や漆器の酒器をいくつか取り上げてきたが、今回は趣向を変えてガラスの酒器を見ていく。「アデリア 津軽びいどろ」の「みずばしょう酒器セット」(徳利1個・盃2個、型番FS-71582)。深いブルーの徳利に、白い花のような模様が浮かぶ盃が寄り添う、冷酒専用の一式だ。 水芭蕉が湖畔に咲くように 津軽びいどろ みずばしょう酒器セット(徳利1個・盃2個)Amazonで見る → 水芭蕉(みずばしょう)は、尾瀬をはじめとする東北から北海道の湿地に自生する多年草だ。白い花びらのように見える部分は実は葉が変形した「仏炎苞(ぶつえんほう)」で、本当の花はその中心にある棒状の部分に小さく密生しているらしい。5月半ばから6月にかけて、雪解け水の残る湿原に群れて咲く姿は、涼しさと清らかさの象徴として和の意匠にたびたび取り入れられてきた。 このセットも、その水芭蕉が咲く風景をイメージしてデザインされているという。ガラスの色合いは深みのあるブルーで統一され、盃の表面には白い模様が浮かぶ。派手な色数を使わずに、湿地の静けさと水の透明感だけで季節感を表現しようとしている、そんな印象を受けた。 浮玉からグラスへ — 津軽びいどろという青森のガラス工芸 このブランドの成り立ちは、酒器とはまったく関係のないところから始まっている。製造元の北洋硝子は1949年、青森市で漁業用の「浮玉(うきだま)」を作る会社として創業した。浮玉とは漁網を海面に浮かせるためのガラス玉で、丈夫さに定評があり、1973年には国内トップクラスの生産高を記録したそうだ。 高岡漆器のルーツは1609年、加賀藩2代藩主・前田利長が高岡城を築いた際、城下に職人を集めて武具や膳、箪笥といった日用品を作らせたことに遡るという。以来、明和年間(1764〜1772年)に中国風の意匠を取り入れたことをきっかけに技法が発展し、明治初期までに「彫刻塗」「勇助塗」「青貝塗(螺鈿)」という3つの技法体系が確立された。1975年9月4日には経済産業大臣指定の伝統的工芸品にも指定されている。 彫刻塗は木地に彫刻を施し、その凹凸を埋めないよう朱や黒の漆を幾重にも塗り重ねる技法。勇助塗は江戸末期に石井勇助が中国明代の漆器を研究して興したもので、唐風の意匠に錆絵や箔絵を組み合わせる。そして青貝塗、いわゆる螺鈿が、今回の主役である盃に使われている技法にあたる。 螺鈿という技法 — 貝殻の虹色はどこから来るのか 螺鈿は、アワビ貝などの貝殻を0.1mm前後まで薄く加工し、刀や針で細かく切り出した破片を漆の上に貼り付けて模様を描く技法だ。高岡の職人はこの「薄貝」の加工精度に定評があるという。 貝殻があの虹色に輝く理由は、色素ではなく構造色によるものらしい。真珠層は炭酸カルシウムの結晶がミクロン単位で何層にも重なった構造をしていて、その層と層の間で反射した光同士が干渉し合うことで、見る角度によって色合いが変わって見える。夜空の星のように、光の当たり方次第で表情を変える装飾になるわけだ。使われている貝の種類によっても発色の傾向は変わり、アワビ貝は青や緑を基調にしつつピンクや黄も覗かせる、わりと華やかな輝き方をする貝だと言われている。 作り方は、まずアワビ貝を薄く剥がして手作業で一枚ずつ切り出し、ガラス面から輝きが透けて見えるよう貼り付ける。次に貝の裏側に着色し、最後に漆で裏打ちして固定する。空の状態では模様がうっすらとしか見えないのに、酒を注いだ瞬間に貝の輝きが液面越しにくっきり浮かび上がる、という体験そのものが設計されている。
