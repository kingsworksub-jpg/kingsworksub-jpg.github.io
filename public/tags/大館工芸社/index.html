大館工芸社

大館工芸社 秋田杉 酒器3点セットの仕様と使い方 — 木曽から立ちのぼる、もう一つの酒の香り

酒器といえばガラスや陶磁器、金属を思い浮かべることが多いが、木でできた徳利とお猪口もある。秋田県大館市の大館工芸社が作る「秋田杉 酒器3点セット」を、今回は隅から隅まで見ていく。 大館曲げわっぱという産地 — 武士の副業から国指定の伝統工芸へ 大館工芸社 秋田杉 酒器3点セット(徳利・お猪口2個)Amazonで見る → 秋田県大館市に伝わる曲げわっぱの起源は平安時代まで遡るとも言われているが、産業として本格的に発展したのは17世紀後半、大館城主・佐竹西家が下級武士の副業として奨励したのがきっかけだったらしい。樹齢200〜300年という天然秋田杉の資源に恵まれた土地柄が、この工芸を支えてきた土台になっている。1980年には経済産業大臣指定の伝統的工芸品にも指定され、今も大館の地場産業として続いている。 大館工芸社は1959年創業のメーカーで、製材から曲げ加工、山桜の皮での縫い留め、底入れ、仕上げまでを一貫して手がけている。現在は伝統工芸士を含む職人が製造にあたっており、曲げわっぱの弁当箱で知られるメーカーだが、徳利やお猪口といった酒器のラインも展開している。 曲げわっぱの技法 — 薄く剥いだ杉を、熱と手で曲げる 曲げわっぱの製法は、天然秋田杉の柾目を薄く剥いで板状にし、それを熱湯に15分ほど浸して柔らかくしたところから始まる。柔らかくなった板を型に沿わせて丸く曲げ、乾燥させて形を固定したあと、継ぎ目を山桜の樹皮で縫い留めて仕上げる。接着剤や金属の留め具にほとんど頼らない、木そのものの性質を利用した技法で、一つの製品が完成するまでに最低でも1年以上はかかるという。 この製法だと木目が一枚板のまま円筒に沿って流れるので、切削や成形とはまた違う、杉本来の木目の美しさがそのまま器の表面に残る。今回のセットも、徳利とお猪口の側面に縦方向の木目がくっきり出ていて、同じ木から作られたはずなのに一つひとつ表情が少しずつ違う。 なぜ杉で酒器を作るのか 杉が酒器の素材として選ばれてきた理由はいくつかあるようだ。まず、杉は熱伝導率が低いため、冷酒を注げば冷たさが持続しやすく、燗酒を注げばほどよい温かさが保たれやすいという性質がある。ガラスや金属の器だと外気の影響を受けて温度が早く変化してしまうのに対し、木の器は中身の温度をゆるやかに保ってくれる、という感覚は実際に使ってみるとよく分かる。 もう一つは香りの効果だ。無塗装の杉であれば木の香りが酒にほのかに移り、味わいに複雑さを加えると言われている。ただし今回のセットはウレタン塗装仕上げになっている点は正確に押さえておきたい。白木のまま使う酒器に比べると香り移りは穏やかで、その代わりに水や汚れへの耐性、お手入れのしやすさという実用面のメリットが出ている仕様だと理解している。無垢の白木にこだわりたい人には物足りないかもしれないが、日常使いの気軽さを取るならこちらの仕様のほうが扱いやすいと思う。 セットの中身とサイズ感 セットの内容は、杉徳利(小)1個と、ぐい呑み(お猪口)2個。徳利は容量約150cc、サイズは60×60×105mm程度。ぐい呑みは容量約35ccで、直径43mm前後×高さ58mm前後とかなり小ぶりなサイズになっている。化粧箱に入って届くので、贈答用としての体裁も整っている。 手のひらに収まるサイズの徳利とお猪口が並ぶと、陶磁器やガラスの酒器とはまた違う、素朴で柔らかい佇まいになる。木目の出方には個体差があるので、届いたものによって色合いや杢目の濃淡が微妙に変わってくる。同じ商品を買っても「自分の一本」感があるのは、天然素材ならではの面白さだと思う。 使い方と手入れの注意点 大館工芸社 秋田杉 酒器3点セット(徳利・お猪口2個)Amazonで見る → 洗い方は、使用後に洗剤とスポンジで洗い、乾いた布で水気を拭き取ってからしっかり乾燥させるのが基本になる。曲げわっぱ全般に言えることだが、電子レンジと食器洗浄機は使えない。急激な乾燥や直射日光も木を反らせたり割れの原因になったりするので、風通しの良い場所で自然乾燥させるのが無難だ。 熱燗にも冷酒にも使える器だが、徳利自体を直火にかけることは想定されていない。燗をつけるときは別の容器でお酒を温めてから、この徳利に移して注ぐという使い方になる。焼酎にも使えるが、個人的には香りの強い純米酒や本醸造あたりの日本酒との相性のほうが好みに合っている。 価格帯・現行性について Amazonでの価格は5,500円前後。大館工芸社の公式オンラインストアでも同一仕様(徳利小・ぐい呑み2個・化粧箱入り)の酒器セットが同じ価格帯で扱われており、単品のぐい呑みが1個880円程度で流通していることを考えると、セットとしての割引がしっかり効いた価格設定になっている。楽天やYahoo!ショッピングでも同ブランドの酒器・ぐい呑みの取り扱いが続いており、現行品として問題なく入手できる状態だ。 なお、Amazon上では「焼印あり」の別バリエーションも見かけるが、今回取り上げたのは焼印なしのシンプルな仕様。木目の美しさをそのまま楽しみたい場合はこちらのほうが向いていると思う。 ガラスや陶磁器の酒器が「光」や「艶」で魅せるのに対して、この杉の酒器は木目と手触り、そして温度の保ち方でじわじわと存在感を出してくる。派手さはないぶん、晩酌の道具として長く使い込んでいくのに向いている一本だと思う。
