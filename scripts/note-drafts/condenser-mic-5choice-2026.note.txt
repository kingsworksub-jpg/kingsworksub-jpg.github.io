# 本文（ここから貼り付け）

宅録初心者のマイク選びは指向性と電源が決め手。Audio-Technica AT2020から Neumann TLM 102・Aston Origin まで、コンデンサーマイク5本を徹底比較。ポップガード・ショックマウント・セットアップコストまで含めた総合評価。

## 導入

宅録を始めるなら、マイク選びが最初の分岐点だ。ダイナミックマイクと違い、コンデンサーマイクは**電源（48V ファントム電源）を必要とする**ため、つなぐ機材の条件も確認が要る。また、指向性（単一指向性か広い感度か）、周波数特性、インピーダンスなどの違いで、録音に映る「空間感」や「音の表情」が大きく変わる。

本記事では、**初心者向けから定番の高級機まで**、5台のコンデンサーマイクを並べた。評価軸は、セットアップのしやすさ、操作感、マイク立ち上げの速さ、将来の拡張性、そして耐久性の5つ。同じジャンル内でも、価格の差がどこに消えているのかを見ていこう。

## 評価軸の考え方

ハードウェアマイクの評判を分けるのは、以下の5点だ：

- **セットアップ**: ケーブル接続、電源確認、接地処理などの初期設定の簡単さ
- **操作性**: マイク本体での調整可能性、ゲイン調整の自由度、マウント交換の容易性
- **マイク立ち上げ**: 「宅録を始めたい」というタイミングから、実際に使えるレベルまでの時間と手間
- **拡張性**: 他のマイク、プリアンプ、オーディオインターフェイスとの組み合わせ柔軟性
- **耐久性**: 経年変化、湿度・温度変化への耐性、修理サポートの手厚さ

これらの軸で5本を評価する。

## 各製品の詳細

### Audio-Technica AT2020 — エントリーの定番

![Audio-Technica AT2020](https://kingsworksub-jpg.github.io/images/condenser-mic/at2020.jpg)

*Audio-Technica AT2020*

（出典: Image: Audio-Technica / <a href="https://www.audio-technica.co.jp/product/AT2020" target="_blank" rel="noopener">公式サイト</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B0006H92QK?tag=nakimoto1-22

AT2020 は宅録の入門機として、ここ20年不動の位置にある。単一指向性（カーディオイド）で、スピーカーやバウンスした音を拾いにくく、ボーカル録音に適している。48V ファントム電源が必須だが、ほぼすべてのオーディオインターフェイスが対応しているため、セットアップの手間は最小限だ。

周波数特性は 20Hz 〜 20kHz で標準的。インピーダンス 100Ω という低インピーダンス設計のため、長いマイクケーブルでも扱いやすい。付属するのはスタンドマウントだけなので、ショックマウントやポップフィルターは必要に応じて買い足すことになるが、それを含めても5本の中でいちばん手頃に始められる。

音は明るくクリアで、ボーカルが前に出てくる。構造がシンプルで壊れにくく、長く使える一本だと思う。

![Audio-Technica AT2020 レーダーチャート](https://kingsworksub-jpg.github.io/images/radar/at2020.svg)

- セットアップ 4 / 操作性 4 / マイク立ち上げ 5 / 拡張性 3 / 耐久性 4

### RODE NT1 5th Generation — ノイズフロアの低さが利点

![RODE NT1 5th Generation](https://kingsworksub-jpg.github.io/images/condenser-mic/rode-nt1.jpg)

*RODE NT1-A の振動板（NT1 シリーズの旧モデル）*

（出典: Photo: ElooKoN / <a href="https://commons.wikimedia.org/wiki/File:Rode_NT1-A_Diaphragm.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B0BQHHZ1QQ?tag=nakimoto1-22

RODE NT1 5th Generation は、2023 年 2 月に発表された NT1 の最新世代だ。単一指向性のカーディオイドで、AT2020 と用途は似ているが、**ノイズフロアの低さ**に加えて、XLR と USB-C の両方で接続できる点が大きな違いになる。

セルフノイズは 4dB(A) と非常に低く、アコースティック楽器や小さな声のナレーションで有利になる。USB-C で直接パソコンにつなぐと 32bit float で録音でき、入力が大きすぎて音が割れる心配をほぼしなくて済む。XLR で使うときは 48V ファントム電源が必要だ。

付属品が充実しており、ポップフィルター一体型のショックマウント、XLR ケーブル、USB-C ケーブルがそろっている。そのため、初期投資はほぼマイク本体の価格に集約される。AT2020 より価格は上がるが、アクセサリ込みで考えるとコスパは高い。

RODE はマイク修理の対応が手厚く、不具合があった場合のサポート体制も整っている。セルフノイズを重視する制作スタイルなら、AT2020 より一段上の選択肢だ。

![RODE NT1 5th Generation レーダーチャート](https://kingsworksub-jpg.github.io/images/radar/rode-nt1.svg)

- セットアップ 4 / 操作性 3 / マイク立ち上げ 5 / 拡張性 4 / 耐久性 4

### AKG C214 — 周波数バランスの優等生

![AKG C214](https://kingsworksub-jpg.github.io/images/condenser-mic/akg-c214.jpg)

*AKG C214（H85 ショックマウント付き）*

（出典: Photo: Lucasbosch / <a href="https://commons.wikimedia.org/wiki/File:AKG_C214_condenser_microphone_with_H85_shock_mount.jpg" target="_blank" rel="noopener">CC BY-SA 3.0</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B003SO5OZQ?tag=nakimoto1-22

AKG C214 は、プロ仕様マイク C414 の流れをくむ単一指向性モデル。周波数特性は 20Hz 〜 20kHz で、中高域にほどよい張りがあり、ボーカルが前に出てくる。全金属のダイキャストボディで、スタジオでの酷使を前提にした作りだ。

48V ファントム電源対応。インピーダンス 200Ω。H85 ショックマウント、ウインドスクリーン、金属ケースが付属するので、ポップフィルター以外はすぐにそろう。

本体には 20dB の PAD と 160Hz のローカットスイッチがあり、ギターアンプやドラムのような大音量の近接録音にも対応できる。そのぶん設定項目はやや増えるが、耐久性とマイク本体の信頼性は群を抜いている。

ボーカル録音の品質を重視し、楽器の録音にも使い回したい層向けだ。

![AKG C214 レーダーチャート](https://kingsworksub-jpg.github.io/images/radar/akg-c214.svg)

- セットアップ 3 / 操作性 3 / マイク立ち上げ 4 / 拡張性 4 / 耐久性 5

### Neumann TLM 102 — 透明感の高級機

![Neumann TLM 102](https://kingsworksub-jpg.github.io/images/condenser-mic/neumann-tlm102.jpg)

*Neumann TLM 102（リフレクションフィルターと組み合わせた例）*

（出典: Photo: Alice Wiegand / <a href="https://commons.wikimedia.org/wiki/File:Neumann_TLM_102ni.jpg" target="_blank" rel="noopener">CC BY-SA 3.0</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B01M63NR80?tag=nakimoto1-22

Neumann TLM 102 は、ドイツの老舗 Neumann の中では「小型で手ごろ」なモデルだが、実際には高級機の部類だ。単一指向性のカーディオイドで、周波数特性は 20Hz 〜 20kHz。特筆すべきは、**非常にニュートラルで透明感のある音質**である。

48V ファントム電源対応。インピーダンス 50Ω。本体には PAD やフィルターのスイッチが一切なく、単一指向性だけというシンプルな構成だ。調整はすべてオーディオインターフェイス側で行うことになるが、そのぶん余計な迷いがなく、6kHz より上にある穏やかな持ち上がりがボーカルをすっきり浮かび上がらせる。

単体ではスタンドマウントのみの付属だが、Neumann 純正のショックマウント EA 4 などのアクセサリが用意されている。修理・メンテナンスのサポートも手厚く、長く使い続けるプロエンジニアが多い。

価格は5本の中で最も高く、AT2020 の数倍になる。その差は音質の透明感と、長年使える信頼性に集約されている。

![Neumann TLM 102 レーダーチャート](https://kingsworksub-jpg.github.io/images/radar/neumann-tlm102.svg)

- セットアップ 3 / 操作性 2 / マイク立ち上げ 3 / 拡張性 5 / 耐久性 5

### Aston Origin — オールインワン設計の異色機

![Aston Origin](https://kingsworksub-jpg.github.io/images/condenser-mic/aston-origin.jpg)

*Aston Origin とポップフィルター*

（出典: Photo: Bizzarle / <a href="https://commons.wikimedia.org/wiki/File:Aston_Origin_large_diaphragm_condenser_microphone.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B019RVU0C0?tag=nakimoto1-22

Aston Origin は、イギリスのメーカー Aston Microphones が 2015 年に発売したモデル。**最大の特徴は、マイク本体に内蔵されたポップフィルターだ**。波形のようなヘッドの内側にメッシュが仕込まれていて、別途ポップフィルターを用意しなくても破裂音を抑えられる。

単一指向性のカーディオイドで、周波数特性は 20Hz 〜 20kHz。ボーカルが突き抜けすぎず、まろやかに録音される傾向がある。48V ファントム電源対応。マイク本体には PAD（−10dB 減衰スイッチ）と FILTER（80Hz ハイパスフィルター）が搭載されており、ゲイン調整と低域カット処理ができる。

**セットアップとマイク立ち上げの項目が高いのは、これ以上ないほどシンプルな設計**のためだ。マイク本体をマウントに付け、ファントム電源を入れて、ケーブルをインターフェイスに繋ぐだけ。別途ポップフィルター購入もなく、初心者が「すぐに宅録を始めたい」というシナリオに最適化されている。

ただし、指向性はカーディオイドのみで、ボーカルやナレーション向けに音作りされている。楽器の録音やステレオ収録まで1本で広くこなすという意味での**拡張性は低め**だ。価格は AT2020 と TLM 102 の中間あたり。

内蔵ポップフィルターが活躍するのは、声を録る場面。ボーカルやスピーチ中心の制作に限定されるなら、Aston Origin は非常に使いやすい。一方、楽器マイキングやマルチマイク運用まで想定するなら、PAD やローカットに加えて付属品も充実した C214 のような機種が向いている。

## どのマイクを選べばいいのか

**最初の一本なら、AT2020 か Aston Origin だ。**

- **すぐに宅録を始めたい・セットアップを最小限にしたいなら、Aston Origin**。内蔵ポップフィルターのおかげで、マイクスタンドに付けてケーブルをつなぐだけで録音を始められる。
- **マイク本体の信頼性と、将来の拡張性を並立させたいなら、AT2020**。価格も安く、のちに上位機を買ってもサブマイクとして使い続けやすい。

**ノイズフロアを重視する録音スタイルなら、RODE NT1 5th Generation**。付属品も充実しており、USB-C でパソコンに直接つなげるので、オーディオインターフェイスを持っていなくても始められる。

**周波数バランスと耐久性を両立させたいなら、AKG C214**。プロスタジオで実績が多く、10 年 20 年単位で使い続ける前提ならこのマイクだ。

**最後に、透明感を最優先にするなら、Neumann TLM 102**。高級機だが、音質での妥協がない。ほかの機材は手頃にそろえ、マイクにだけ予算をかけるという考え方にもよく合う。
