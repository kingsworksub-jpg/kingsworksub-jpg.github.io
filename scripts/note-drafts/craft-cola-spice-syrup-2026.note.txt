# 本文（ここから貼り付け）

オリジナル記事: https://kingsworksub-jpg.github.io/posts/craft-cola-spice-syrup-2026/

コーラの黒い炭酸を分解すると、柑橘の油とスパイス、酸と甘みが残る。漢方の工房を継いだ伊良コーラ、調香師が柑橘を重ねるともコーラ、米麹の甘みを使うUMAMI COLAを例に、原液とボトルの違いと割り方の自由度を考える。

コーラという飲み物は、あまりにも完成された姿で目の前に現れるので、それが何から組み立てられているのかを考える機会がほとんどない。缶を開ければ同じ色、同じ泡、同じ甘さがいつでも待っている。ところが2018年ごろから、日本でも「クラフトコーラ」と呼ばれる小さな作り手たちが、スパイスと柑橘を自分で配合した原液を瓶に詰めて売り始めた。炭酸水で割るのは飲む側の仕事で、濃さも温度も合わせる相手も自分で決める。

この流れが面白いのは、大手のコーラの「別バージョン」を作っているのではなく、コーラという飲み物をいったん部品に戻して、組み立て直しているところだと思う。この記事では、コーラがもともとどういう飲み物だったのかを振り返り、その味を形づくる部品を整理したうえで、伊良コーラ、ともコーラ、UMAMI COLAという3つの作り手を手がかりに、原液という売り方がもたらす自由について考えてみたい。

## コーラはもともと薬局のカウンターで生まれた

![ガーナ北部の市場に並ぶコーラナッツ](https://kingsworksub-jpg.github.io/images/craft-cola/kola-nut-market.jpg)

*市場で山ごとに売られるコーラナッツ。西アフリカでは噛んで疲れを和らげる習慣があった*

（出典: Photo: Dnshitobu / CC BY-SA 4.0）

コカ・コーラが最初に売られたのは1886年5月、アメリカ南部アトランタの薬局だった。考案したのは薬剤師のジョン・ペンバートンで、1杯5セントでソーダファウンテンから注がれていた。その前身は、彼が1880年代前半に売り出した「ペンバートンのフレンチ・ワイン・コカ」という強壮飲料で、フランスで人気を集めていたワインとコカの葉の飲み物を手本にしたものだった。アトランタで禁酒の条例が施行されることになり、ワインを抜いて砂糖と炭酸で組み直した結果が、のちに世界中で飲まれる黒い炭酸になった。

名前の由来になったのは、コカの葉とコーラナッツという二つの原料だ。コーラナッツは西アフリカの熱帯雨林に育つ木の種子で、カフェインを2〜4%ほど含み、テオブロミンやタンニンも持っている。ギニアやシエラレオネ、ナイジェリアなどでは、古くから噛んで喉の渇きや疲れを和らげるものとして親しまれてきたし、客をもてなすときや儀礼の場で分け合う大切な贈り物でもあった。写真のように、市場では小さな山に分けて売られていることが多い。

つまりコーラは、最初から「元気を出すための薬局の飲み物」として生まれている。いまのクラフトコーラの作り手が、スパイスや生薬の知識を出発点にしていることが多いのは、ある意味でこの原点に帰っているとも言える。甘い清涼飲料というより、香りの強い植物を組み合わせて体に効かせる調合物。そう考えると、コーラを手作りするという発想も、決して奇抜なものではないと感じる。

## 黒い炭酸を分解すると、柑橘とスパイスと酸が残る

コカ・コーラの香りの配合は「マーチャンダイズ7X」と呼ばれ、ごく限られた人しか知らない企業秘密として語られてきた。中身は公表されていないが、香りの骨格についてはおおよその見当がついている。手がかりのひとつが、2001年に誰でも使える形で公開された「OpenCola」というレシピだ。そこに並ぶ精油は、オレンジ、ライム、カシア(シナモンの仲間)、レモン、ナツメグ、コリアンダー、ネロリ、ラベンダー。量の多い順に見ると、主役はオレンジとライムで、そこにカシアとナツメグの温かい香りが重なり、ネロリやラベンダーがごく少量で花のような余韻を添える構成になっている。

この配合を眺めていると、コーラの正体は「柑橘とスパイスの飲み物」なのだとよく分かる。私たちがコーラらしいと感じている香りは、実のところレモンやオレンジの皮の苦みと、シナモンやナツメグの甘い温かさが混ざり合ったところに生まれている。そこに砂糖の甘みと、カラメルの色と香ばしさが加わる。

もうひとつ見落としがちなのが酸だ。大手のコーラの多くはリン酸を使っていて、これが舌の両脇をきゅっと締めるような鋭さを生んでいる。リン酸は酸っぱさ以外の香りをほとんど持たないので、柑橘やスパイスの香りを邪魔せずに、甘さを引き締める役目に徹してくれる。一方、クラフトコーラの多くはレモンやライムの果汁、あるいはクエン酸で酸味を出している。こちらは酸そのものに柑橘の明るさがあるので、飲み口がやわらかく、果実の印象が前に出やすい。同じ「コーラ」でも、酸の選び方ひとつで性格がずいぶん変わる。

OpenColaのレシピは、こうして作ったシロップを炭酸水で5倍に割るよう指示している。つまり、コーラはもともと「濃いシロップを炭酸で割る飲み物」として設計されていた。ソーダファウンテンの時代には、店の人がシロップと炭酸水をその場で合わせていたのだから、原液という売り方は歴史をさかのぼれば、むしろ本来の姿に近い。

## 伊良コーラ、漢方の工房から始まった原液

![伊良コーラの原液ボトル。100mlと250mlの瓶が並ぶ](https://kingsworksub-jpg.github.io/images/craft-cola/iyoshi-syrup.jpg)

*伊良コーラの原液。カワセミのラベルに「SINCE 1954」とある*

（出典: Photo: 漱石の猫 / CC BY-SA 4.0）

Amazonで見る: https://www.amazon.co.jp/s?k=%E4%BC%8A%E8%89%AF%E3%82%B3%E3%83%BC%E3%83%A9&tag=nakimoto1-22

日本のクラフトコーラを語るとき、最初に名前が挙がるのが伊良コーラだと思う。作り手は「コーラ小林」を名乗る小林隆英さんで、2018年に東京で販売を始めた。最初は「カワセミ号」と名づけた小さな移動販売車で売り歩き、のちに高田馬場に総本店を構えている。原点にあるのは、祖父が営んでいた漢方の工房「伊良葯工」だ。生薬を刻んで煎じる仕事を受け継ぐような形で、コーラの原液づくりが始まったという。ラベルに描かれたカワセミと「SINCE 1954」の文字は、その工房の歴史を引き継いでいることを示している。

原材料のラベルには、レモンやライム、砂糖に続いて、シナモン、バニラビーンズ、クローブ、コリアンダー、カルダモン、ナツメグといったスパイスが並ぶ。数えると10種類を超え、ひとつひとつを煮出して香りを重ねている。原液をそのまま少し舐めると、まずシナモンとクローブの温かい香りが強く立ち、遅れてレモンの皮のような苦みがやってくる。甘さは砂糖らしくすっきりしていて、ねっとりした重さはない。炭酸水で割ると、この香りの層がほどけて、大手のコーラよりずっとスパイスの輪郭がはっきりした飲み物になる。正直、最初の一口はコーラというより、冷たいチャイやジンジャーエールに近いと感じる人もいると思う。

瓶は100mlと250mlの2サイズがあり、写真の右奥に見えるように色の淡い限定品が並ぶこともある。250mlの原液はおおむね3,000円前後で、決して安い飲み物ではない。ただ、1杯に使う原液は30〜40mlほどなので、1本から7〜8杯は作れることを考えると、1杯あたりの値段はカフェの飲み物より少し安いくらいに収まる。原液のほかに、すぐ飲める缶入りの製品も出ていて、コンビニの棚で見かけることもある。

## ともコーラとUMAMI COLA、甘みと香りの出どころを変える

伊良コーラがスパイスの重なりを前に出すのに対して、ともコーラは国産の柑橘とハーブの香りを軸にしている。作り手は調香師で、香りを組み立てる仕事の延長としてコーラの原液を作っている。15種類以上のハーブやスパイスに、高知県で農薬を使わずに育てたレモンやオレンジ、ライムを合わせ、きび砂糖と黒糖で甘みをつけて、添加物を加えずに仕上げているのが特徴だ。200mlの瓶で5〜6杯分になる計算で、飲食店やホテルにも卸されていて、全国の店でカクテルやノンアルコールの一杯として使われている。香りの印象は伊良コーラよりも明るく、柑橘の皮の爽やかさが先に来るタイプだと思う。黒糖のこくが底にあるので、甘さは控えめでも味が薄く感じない。食事と一緒に飲んでも口の中が重くならないのもいいところだ。

UMAMI COLAは、さらに大胆に甘みの出どころを変えた。砂糖の代わりに、国産の米麹で作った甘酒を甘みのベースにしている。米麹の甘さはブドウ糖が中心で、砂糖のような鋭い甘さではなく、丸く広がる甘さになる。そこにトゥルシー(ホーリーバジル)やエルダーフラワーなど10種類以上のハーブとスパイスを重ねている。麹由来のアミノ酸が含まれるので、名前のとおり、飲んだあとにほんのりとした旨みが残るのが面白いところだ。2020年に東京で生まれたブランドで、ほかの2つと違って、主力は振ってから開ける缶入りの完成品だ。2025年にはセブン-イレブンの一部地域の店舗にも並ぶようになった。原液から始まったクラフトコーラの流れの中で、あえて完成品で勝負しているところにも、作り手の考え方が表れていると思う。

3つを並べてみると、クラフトコーラという言葉でひとくくりにされていても、組み立て方はまったく違う。伊良コーラはスパイスを主役に、ともコーラは柑橘とハーブを主役に、UMAMI COLAは甘みそのものを作り変えるところから始めている。大手のコーラが「誰が飲んでも同じ味」を目指すのに対して、クラフトコーラは作り手がどの部品に重心を置くかで、まるで別の飲み物になる。そこがこのジャンルのいちばんの面白さだと感じている。

## 原液とボトル、割り方を自分で決めるということ

![伊良コーラの淡い色の原液ボトル](https://kingsworksub-jpg.github.io/images/craft-cola/iyoshi-cola.jpg)

*白いラベルの伊良コーラ。季節や限定の原液は色も香りも変わる*

（出典: Photo: スロッさん / CC BY-SA 4.0）

Amazonで見る: https://www.amazon.co.jp/s?k=%E4%BC%8A%E8%89%AF%E3%82%B3%E3%83%BC%E3%83%A9&tag=nakimoto1-22

クラフトコーラの多くは、原液とそのまま飲めるボトルや缶の両方を用意している。どちらを選ぶかで、楽しみ方はかなり変わる。缶やボトルは作り手が決めた濃さと炭酸の強さで完成しているので、作り手が想定した味をそのまま受け取れる。初めて飲むなら、まずこちらで基準の味を知っておくのがいいと思う。一方の原液は、最後の調合を飲む人に任せている。

一般的な目安は、原液1に対して炭酸水が3〜5。濃いめが好きなら1対3、すっきり飲みたいなら1対5くらいから始めて、自分の好みを探していけばいい。炭酸水の選び方でも印象は変わる。強めの炭酸を使えば大手のコーラに近い刺激が出るし、やわらかい炭酸ならスパイスの香りがゆっくり立ち上がる。グラスに氷をたっぷり入れ、原液を先に注いでから炭酸水を静かに足し、マドラーで一度だけ底から持ち上げるように混ぜると、泡が抜けにくい。

割る相手は炭酸水に限らない。牛乳や豆乳で割るとスパイスの香りがやわらかくなり、チャイのような飲み物になる。お湯で割ればホットコーラになり、シナモンやクローブが湯気と一緒に立ちのぼって、寒い夜にちょうどいい。ウイスキーやラムを少し加えれば、ハイボールともラムコークとも違う、香りの強い一杯になる。原液という形は、こうした自由を最初から前提にしている。濃さ、温度、合わせる相手。その全部を決めるのが飲む人だというところに、ボトルの完成品にはない楽しさがあると思う。

保存については、原液は開封したら冷蔵庫に入れ、なるべく早めに使い切るのがいい。添加物を使わない製品が多いので、大手のコーラのように常温で長く置いておけるものではない。そのぶん、香りが新鮮なうちに飲み切る楽しみもある。

## 大手も「割るためのコーラ」を作った

![コカ・コーラ シグネチャーミキサーズ スモーキーノーツのボトル](https://kingsworksub-jpg.github.io/images/craft-cola/signature-mixers.jpg)

*コカ・コーラ シグネチャーミキサーズの「スモーキーノーツ」。ラベルにイランイランやグアヤクウッドの名が並ぶ*

（出典: Photo: FlippyFlink / CC0）

クラフトコーラの広がりは、大手にも影響を与えた。コカ・コーラは2019年にヨーロッパとイギリスで、ウイスキーやラムなどの濃い色の蒸留酒と合わせるためのコーラ「シグネチャーミキサーズ」を発売している。スモーキー、スパイシー、ハーバル、ウッディの4種類で、それぞれロンドンやバルセロナのバーテンダーと共同で開発された。200mlの小さな瓶は、有名な曲線のボトルよりも古い時代の形を模したもので、ラベルには開発したバーテンダーの署名が入っている。

写真のスモーキーノーツのラベルには、イランイラン、アンブレットシード、ペルーバルサム、オークエキス、グアヤクウッドという香りの素材が書かれている。花の香り、ムスクのような種子の香り、樹脂の甘い香り、樽材と燻した木の香り。コーラの骨格に、香水のような素材をあえて上乗せしているのが分かる。大手が自分たちの看板商品をわざわざ「部品」として扱い、そこに香りを足して酒と合わせる前提で売り出したことは、コーラを組み立て直すという発想が、もう小さな作り手だけのものではなくなったことを示していると思う。

ただし、シグネチャーミキサーズはあくまで完成品のボトルで、濃さを変えたり温めたりする自由はない。原液を自分で割るクラフトコーラとは、似ているようで出発点が違う。大手は「この酒にはこの香り」という答えを用意し、クラフトコーラは答えを飲む人に委ねている。どちらが優れているというより、同じ発想の両端にあるものだと感じる。

## まとめ

- 伊良コーラ：甘みの軸 砂糖 / 香りの軸 シナモン・クローブ・カルダモンなどのスパイス / 主な形 原液(100ml・250ml)、缶 / 印象 スパイスの輪郭がはっきりした力強い味
- ともコーラ：甘みの軸 きび砂糖・黒糖 / 香りの軸 高知県産の柑橘とハーブ / 主な形 原液(200ml・720ml) / 印象 柑橘が先に来る明るい味
- UMAMI COLA：甘みの軸 米麹の甘酒 / 香りの軸 トゥルシー・エルダーフラワーなどのハーブ / 主な形 缶入りの完成品 / 印象 丸い甘さと、あとに残るほのかな旨み

コーラを部品に分けてみると、柑橘の油、温かいスパイス、花の香り、酸、甘み、そしてカラメルの色と香ばしさが残る。大手のコーラは、それをいつ誰が飲んでも同じになるよう精密に固定した飲み物で、クラフトコーラは、その部品のどれに重心を置くかを作り手ごとに選び直した飲み物だ。そして原液という形は、最後のひと手間を飲む人の手元に残している。

初めて試すなら、まず缶やボトルで作り手の基準の味を知り、気に入ったら原液を買って、炭酸水の量を少しずつ変えてみるのがいいと思う。濃さを一段変えるだけで、スパイスが前に出たり、柑橘が明るくなったりする。黒い炭酸がどういう部品でできているのかを、自分のグラスで確かめられるのが、クラフトコーラのいちばんの魅力だと感じている。
