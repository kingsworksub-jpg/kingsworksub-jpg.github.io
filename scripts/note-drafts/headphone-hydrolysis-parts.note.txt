# 本文（ここから貼り付け）

合皮のイヤーパッドとヘッドバンドは数年でベタつき、やがて黒い粉になって剥がれ落ちる。加水分解という化学反応の正体と、単品で売られている交換部品を使って自分で張り替える手順、劣化を遅らせる保管の作法まで順にまとめた。

久しぶりに引き出しから出したヘッドホンを耳に当てたら、指先がぬるりとした。イヤーパッドの表面が、溶けかけた飴のようになっている。拭いても取れない。それどころか、拭いた布に黒い皮がぺろりと付いてくる。

ヘッドホンを数年単位で使っていれば、たいてい一度は通る道だと思う。音は何も変わっていないのに、耳に触れる部分だけが先に寿命を迎える。ドライバーもケーブルも筐体も健在なのに、合皮が崩れたというだけで「そろそろ買い替えか」と考えてしまう。もったいない話で、しかも直せる。

厄介なのは、この劣化が使用頻度とあまり関係しないところだ。箱にしまって大事に保管していたほうが早く駄目になることすらある。原因が摩耗ではなく化学反応だからで、だとすれば対処の仕方も「丁寧に使う」とは別の方向になる。ここでは、何が起きているのかという話から、部品を買って自分で替える手順、そして次の一台を長持ちさせる保管の仕方までを順に見ていく。

## ベタつきの正体は、ポリウレタンが水と手を切ること

![机の上に置かれたオーディオテクニカの密閉型モニターヘッドホン](https://kingsworksub-jpg.github.io/images/hp-hydro/ath-m50x.jpg)

*合皮のイヤーパッドとヘッドバンドを持つ密閉型モニターヘッドホン*

（出典: Photo: Jose C Silva / <a href="https://www.flickr.com/photos/61676142@N00/22330935543" target="_blank" rel="noopener">CC BY 2.0</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B00HVLUR86?tag=nakimoto1-22

イヤーパッドやヘッドバンドに使われている「合成皮革」「プロテインレザー」「PUレザー」は、呼び名こそ違うが中身はだいたい同じで、布地の上にポリウレタンの膜を塗った素材だ。手触りが革に近く、安く作れて、縫製も自由がきく。弱点はひとつだけで、その膜が水と反応して分解する。

ポリウレタンの分子は、短い鎖がエステル結合やエーテル結合でつながってできている。このうちエステル結合のほうが水に弱い。空気中の水分が結合部分に入り込むと、鎖がそこで切れる。切れた鎖は短くなり、短い鎖の集まりは膜としての強度を失ってベタつく。これが加水分解で、一度始まると止まらない。切れた端が酸性の成分を残し、それがさらに次の切断を促すため、進むほど加速するという性質まで持っている。

反応の速さを決めるのは、水分と温度だ。湿度が高いほど速く、温度が高いほど速い。人間の頭に乗せている時点でヘッドホンは体温に近い温度にさらされているし、耳のまわりは汗をかく。汗には水に加えて塩分と乳酸が含まれていて、これが反応をさらに後押しする。耳に当たる面が真っ先に崩れ、外側はまだきれいなまま、という壊れ方をするのはそのためだ。

逆に言えば、引き出しの奥や密閉したケースの中は、ポリウレタンにとって最悪に近い環境になりうる。使っていないから湿気を飛ばす機会もなく、温度が上がれば中にこもる。「大事にしまっておいたのに」という嘆きは、素材の側から見れば順当な結果だったりする。目安として、合皮のイヤーパッドの寿命は毎日使って2年から3年、使わなくても5年前後と考えておくと見通しを立てやすい。

## ベタつき、ひび割れ、黒い粉という順番で進む

劣化は段階を踏む。順番を知っておくと、いま自分のヘッドホンがどこにいるのか、まだ待てるのか、すぐ手を打つべきなのかが分かる。

最初の兆候は手触りの変化だ。新品のときのさらりとした感触が消え、わずかに吸い付くようになる。この段階ではまだ見た目はきれいで、指で触って初めて気づく。次に表面の艶が鈍り、しわの深いところが白っぽく粉を吹いたように見えてくる。ここを過ぎると、縫い目や曲げ伸ばしの多い場所から細かいひびが入る。イヤーパッドなら耳の後ろ側に当たる外周、ヘッドバンドなら頭頂部の真ん中あたりが先に割れることが多い。

ひびが入ったあとは早い。ポリウレタンの膜が下地の布から剥がれ、小さな黒い破片になって落ち始める。この破片が髪に付き、肩に落ち、白いシャツに黒い点を散らす。段階としてはここが終わりで、どれだけ丁寧に扱っても元には戻らない。塗り直しや補修材でごまかそうとしても、下地の布まで劣化していれば接着が持たない。

もうひとつ見落としがちなのが、中のクッション材の劣化だ。表面の合皮が無事でも、詰め物のウレタンフォームは潰れていく。へたったパッドは耳と筐体の距離を縮め、密閉が甘くなる。低音が抜け、音像が平たくなり、中低域がぼやける。「最近このヘッドホン、なんだか音が窮屈だ」と感じたら、ドライバーではなくパッドの厚みが減っているだけという場合がある。パッドを替えると音が戻る、というのはこの意味では誇張ではない。

## イヤーパッドは工具なしで外れることが多い

![イヤーパッドを外したヘッドホンと、取り外された2枚のイヤーパッド](https://kingsworksub-jpg.github.io/images/hp-hydro/diy-repair.jpg)

*パッドを外すと、ドライバーを覆う樹脂のプレートが現れる*

（出典: Photo: Bait30 / <a href="https://commons.wikimedia.org/wiki/File:Beats_headphones_diy_repair.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

パッド交換は、身構えるほどの作業ではない。多くのヘッドホンは、パッドの裏側にある柔らかい縁をハウジングの溝に押し込んで留めているだけで、接着も螺子も使っていない。外し方は、パッドの縁を指でつまんで外側へ引き上げ、溝から一箇所外れたら、そこから二、三センチずつ隣へ移りながらぐるりと一周する。力任せに一気に引っぱると縁が裂けるが、どうせ捨てるパッドなので裂けても困らない。所要時間は片側一分といったところだ。

留め方には何種類かある。いま書いた溝にはめ込む方式がいちばん多く、次に樹脂のリングを爪で引っかける方式、そして少数ながら接着剤で貼り付けてある方式がある。見分け方は簡単で、縁を少し持ち上げたときに全体がすんなり動けば溝式、硬い輪郭を感じるならリング式、びくともせず糊の跡が見えるなら接着式だ。接着式だけは手強く、樹脂のヘラを隙間に差し込んで少しずつ剥がし、残った糊をきれいに落としてから新しいパッドを貼ることになる。

取り付けは外すときの逆で、新しいパッドの縁を溝の一箇所に入れ、そこを起点に少しずつ押し込んでいく。コツがあるとすれば、最後の一箇所がどうしても入らないこと。縁を少し引き伸ばしながら親指で押し込めば入る。入れ終わったら、パッドを軽く回してみて、どこかが浮いていないかを確かめたい。一周ぐるりと均等に収まっていないと、そこから空気が漏れて低音が痩せる。

古いパッドを外したら、ハウジング側の掃除も済ませておきたい。溝には崩れた合皮の粉や皮脂が溜まっていることが多い。乾いた布と綿棒で拭き取る程度でよく、アルコールや溶剤は使わないほうがいい。樹脂を曇らせるうえ、残っている部分のポリウレタンの劣化をかえって早める。

## 替えるパッドの素材で、音の性格は変わる

![厚みのある交換用イヤーパッドを装着したオーディオテクニカのヘッドホン](https://kingsworksub-jpg.github.io/images/hp-hydro/custom-earpads.jpg)

*厚みのあるパッドに替えると、耳とドライバーの距離が変わる*

（出典: Photo: P0lykey / <a href="https://commons.wikimedia.org/wiki/File:Audio-Technica_Headphones_(Custom_Earpads).jpg" target="_blank" rel="noopener">CC0</a>）

Amazonで見る: https://www.amazon.co.jp/dp/B00MFM9DKY?tag=nakimoto1-22

純正と同じものを買い直せば音はほぼ元に戻る。これがいちばん無難な選択で、迷うくらいならこれでいい。ただ、交換は素材を変える機会でもあるので、それぞれの性格は知っておいて損がない。

合皮は密閉が強い。耳のまわりを隙間なく塞ぐので、低音が逃げず、外の音も入りにくい。モニターヘッドホンがこの素材を選ぶのは、録音の現場で音を漏らさないためでもある。代償は蒸れと、ここまで書いてきた寿命の短さだ。

ベロア、つまり起毛した布地のパッドは正反対で、通気する。夏でも蒸れず、何時間でもかぶっていられて、しかも布なので加水分解とは無縁だ。ただし空気が通るということは音も通るということで、低音は確実に軽くなる。密閉が緩んだぶん音場は広く感じられ、中高域の見通しは良くなるが、低音の量感を頼りにしていた人には痩せて聴こえる。モニター用途で使っているなら、この変化は無視できない。

本革、とくに羊革のパッドは折衷案になる。密閉は合皮に近く、通気は合皮よりわずかに良く、何より加水分解しない。革として普通に経年変化するだけなので、十年単位で持つ。値段は高い。もうひとつ、スエードやアルカンターラのような起毛の人工素材もあり、こちらはベロアと革の中間くらいの性格をしている。

厚みも音を変える要素だ。純正より厚いパッドにすると耳とドライバーの距離が開き、音場は広がるが低音は減る。薄くすれば逆になる。社外品には「純正より厚め」を売りにしたものが多いので、純正と同じ音を求めているなら、素材だけでなく厚みも元と同じくらいのものを選びたい。

## ヘッドバンドが単品の部品として売られ始めた

パッドは昔から交換部品として売られてきたが、ヘッドバンドは長らく厄介な部位だった。構造体を兼ねているうえ、中をケーブルが通っている機種もあり、メーカーが部品として出していなければ修理に出すしかない。実際、自転車のバーテープを巻く、布のカバーを被せる、スポンジテープを貼るといった力技が、ネット上の定番の対処法になっていた。見た目は妥協するしかない。

ここが2026年10月に少し変わった。オーディオテクニカが、ATH-M50x系のヘッドバンドを単品の補修部品として発売した。品番はHP-HBM50x、税込2,750円。黒と白の二色があり、取り付け用のドライバーが同梱されているので、工具を別途買い足す必要がない。対応するのはATH-M50x、ATH-M50xBT2、ATH-M50xSTS、ATH-M50xSTS-USBの四機種で、同じMシリーズでもM40xやM20xは対象外になる。

この部品の意味は値段以上に大きいと思う。ATH-M50xは実売2万円前後の製品で、ヘッドバンドがベタついただけで買い替えるには高い。かといって修理に出せば送料と工賃で数千円は飛ぶ。2,750円で自分で直せるなら、判断に迷う余地はほとんどない。しかも半田付けは不要で、ハウジング側の螺子を外して古いバンドを抜き、新しいバンドを通して締め直すという手順で済む。

交換のときに気をつけたいのは三点だ。ひとつ、外した螺子は小皿にまとめておくこと。細かいうえに床に落とすと見つからない。ふたつ、ハウジングからケーブルが伸びている機種では、バンドを引き抜く前に配線の通り道を見ておくこと。写真を一枚撮っておけば組み立てで迷わない。みっつ、締めるときに力を入れすぎないこと。樹脂に切られた螺子穴は一度舐めると元に戻らない。付属のドライバーが小さめなのは、強く締めすぎないための配慮でもある。

## 部品の探し方と、値段の目安

![モニターに掛けられたヘッドホンのある机上の作業環境](https://kingsworksub-jpg.github.io/images/hp-hydro/home-studio.jpg)

*吊るして置くだけでも、密閉したケースにしまうより条件はよくなる*

（出典: Photo: Tim Wilson / <a href="https://commons.wikimedia.org/wiki/File:The_Podcave_home_studio_update_(179160280).jpg" target="_blank" rel="noopener">CC BY 2.0</a>）

純正部品にたどり着く最短の道は、メーカーのサイトにある補修部品の検索ページで型番を入れることだ。オーディオテクニカの場合、ATH-M50xで引けばイヤーパッドのHP-M50x（税込2,200円）、1.2メートルと3.0メートルの着脱ストレートコード（各1,650円）、カールコード（2,200円）、6.3ミリの変換プラグ（550円）、ポーチ（1,100円）といった具合に、部品が価格付きで一覧になる。ATH-M40x用のHP-M40xは1,650円、ATH-R70x用のHP-R70xは3,300円と、機種ごとに別の品番が割り当てられている。

この「部品が型番で買える」という体制は、メーカーによって厚みがかなり違う。イヤーパッドだけを出しているところ、ヘッドバンドのクッションまで出しているところ、そもそも部品単位では売らないところがある。買う前に補修部品の一覧を見ておくと、その機種を何年使えるかの見当がつく。価格が同じなら、部品が買えるほうを選ぶ理由はここにある。

社外品という選択肢もあり、こちらは素材と厚みの幅が広い。合皮のほか、羊革、ベロア、スエード、通気孔の空いた穴あきタイプなどが揃っていて、価格帯も千円台から六千円前後まで分かれている。人気機種ほど選択肢が多く、ATH-M50xのような定番は特に充実している。純正が廃番になった古い機種を延命させたいときは、こちらが唯一の道になることも多い。

ひとつ注意したいのは寸法だ。パッドは外径が一ミリ違うだけで溝に収まらなくなる。買うときは必ず対応機種の一覧に自分の型番があることを確かめたい。「〇〇シリーズ対応」という大まかな表記は、同じシリーズでも世代でハウジングが変わっている場合があるので、鵜呑みにしないほうが安全だと思う。

## 替えずに済ませるための、保管の作法

部品が買えるとはいえ、替えずに済むならそのほうがいい。加水分解は水分と温度で進むのだから、対策もその二つに絞られる。

まず、密閉しない。付属の巾着やハードケースにしまうのは、持ち運ぶときだけにしたい。家ではスタンドに吊るすか、机の端に置いておくほうが、合皮にとってはずっと優しい。湿気がこもらず、温度も上がらない。どうしてもケースに入れるなら、乾燥剤を一緒に入れて、半年から一年で入れ替える。

次に、湿度を上げない。室内の相対湿度が五割を超えない環境がひとつの目安になる。日本の夏は放っておけば七割を軽く超えるので、梅雨から夏にかけては除湿機かエアコンの力を借りることになる。押し入れや窓際の密閉された収納は、温度も湿度も振れ幅が大きいので避けたい。

そして、使ったら拭く。耳に当たる面を乾いた布でひと撫でするだけでいい。汗と皮脂を残さないという、それだけのことで寿命はかなり変わる。濡れた布やウェットティッシュ、アルコール系の除菌シートは逆効果で、水分と溶剤がどちらも劣化を早める。直射日光に当てないことも効く。紫外線は劣化の口火を切る役回りを持っていて、日の当たる窓際に置きっぱなしのヘッドホンは、暗い部屋のものより明らかに早く崩れる。

最後に、そもそも合皮を避けるという手もある。買うときにベロアや布のパッドが付いた機種を選べば、この問題の大半は起きない。密閉性と引き換えになるので万人向けではないが、家でじっくり聴く用途なら十分に現実的な選択だと思う。

## それで、直すか買い替えるか

判断の基準は単純で、部品が出ているかどうかに尽きる。パッドが二千円、ヘッドバンドが三千円足らずで買えて、作業が合わせて三十分で終わるなら、二万円の本体を捨てる理由はない。ドライバーユニットもケーブルも、合皮より遥かに長持ちする部品なのだから。

逆に、部品が廃番で社外品の対応表にも型番が見当たらず、しかも中のフォームまで崩れているなら、そこが潮時かもしれない。ただその場合でも、次の一台を選ぶときに「補修部品が型番で買えるか」を条件に入れておくと、同じ話を数年後に繰り返さずに済む。

ベタついたパッドを剥がして新しいものを嵌め、ヘッドバンドの螺子を締め直したヘッドホンは、見た目がほとんど新品に戻る。音も、へたったフォームが元の厚みに戻ったぶんだけ、買った当時の鳴り方に近づく。耳に触れる部分だけを替えるという、それだけの手当てで何年か延びるなら、やってみる価値はある。
