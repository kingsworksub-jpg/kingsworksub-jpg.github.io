# 本文（ここから貼り付け）

名盤リストを順に聴いても途中で止まるのは、何を聴き取るかを決めていないからだと思う。メロディ・グルーヴ・曲の形と的を一つずつ絞り、六週間の聴く順番と入門書六冊を対応させる手順をまとめた。

ジャズを聴こうと思い立った人がまず手に入れるのは、たいてい名盤のリストだ。五十枚なり百枚なりが時代順に並んでいて、解説が付いている。一枚目をかけて、最後まで通して、「悪くなかった」と思う。二枚目も同じように聴いて、やはり「悪くなかった」と思う。そして三枚目あたりで、なんとなく再生しなくなる。

これは根気の問題ではないと思っている。聴く前に「今日は何を聴き取るのか」を決めていないだけだ。リストは目的地の一覧であって、道順ではない。どこを見ればいいか分からないまま景色が流れていけば、何も残らないのは当たり前だと感じる。ここでは、聴き取る的を一つずつ決めていく手順と、その段階に合う本を割り当てる六週間の組み立て方を書く。

## 名盤リストだけでは前に進めない

名盤リストが悪いわけではない。あのリストは、歴史の上で重要だった録音や、長く売れ続けてきた録音を並べたものだ。選ばれた理由はきちんとある。ただ、その順番は「ジャズを初めて聴く人が、どういう順で耳を慣らしていくか」という観点では組まれていない。重要度の順と、入りやすさの順は別物だ。

もうひとつ厄介なのは、感想を書くための物差しが手元にないことだ。知らない音楽を一枚通して聴いたあとに残るのは、良かったか良くなかったかの二択しかない。これだと二枚目を聴く動機が生まれにくい。好きになれたかどうかは運まかせになってしまう。

ジャズの一曲は、短いもので三分、長ければ十分を超える。その中では、最初にメロディが示され、そのあと奏者が順番に即興を取り、最後にもう一度メロディに戻ってくる、という進み方をすることが多い。構造を知らずに聴くと、同じところをぐるぐる回っているように聞こえる。回っているのは事実なのだが、回るたびに中身が変わっている、というのがこの音楽の肝心なところだ。そこが聞こえないうちは、長さだけが印象に残る。

だから、一回の再生につき聴き取る対象を一つだけ決める。対象を絞ると、一枚のアルバムが何度でも新しくなる。五十枚を一周するより、五枚を十回ずつ聴いたほうが、結果として耳は早く育つと思う。

## 耳の置きどころを一つに決める

![ニューヨークのブルーノートで演奏するサックス奏者とベース奏者](https://kingsworksub-jpg.github.io/images/jazz-listening/bluenote-club.jpg)

*一人が吹き、もう一人がその場で応える。ジャズの中身はこの往復にある*

（出典: Photo: Francesca.giovinazzo / <a href="https://commons.wikimedia.org/wiki/File:Bluenote_Jazz_Club_in_NYC.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

聴き取る対象の候補は、大きく四つに分けられる。メロディ、グルーヴ、奏者どうしのやりとり、そして音色だ。メロディは曲の顔にあたる部分で、冒頭と最後に出てくる。グルーヴは、足でリズムを取りたくなるかどうかの感触で、ベースとドラムとピアノが作っている。やりとりは、誰かが吹いたフレーズに別の誰かが反応する瞬間のことだ。音色は、同じ楽器でも奏者ごとに違う、息の混じり方や弦の鳴り方を指す。この四つを同時に追おうとすると、たいてい全部ぼやける。

具体的な手順として、同じ曲を三回続けて聴く方法が分かりやすい。一回目は何も意識せず流す。二回目は、冒頭のメロディを自分で口ずさめるかどうかを確かめる。口ずさめたなら、そのあと即興がどれだけ遠くへ行っても、戻ってくる場所が分かる。三回目は楽器を一つ選んで、その楽器だけを最後まで追いかける。この三回目が、いちばん発見が多い。

追いかける楽器は、曲ごとに変えていい。ベースは曲の土台を作っていて、和音の動きを一番はっきり示している。ドラムは全体の脈を打ちながら、要所で合いの手を入れる。ピアノは和音で返事をする係で、ソロを取っている奏者に相槌を打ったり、わざと外したりする。管楽器や歌はメロディを担当するが、同じメロディを毎回わざと崩して演奏する。崩し方の癖が、その人の個性になる。

聴き終えたら、三行だけ書き残しておくことを勧めたい。気に入った音が一つ、気づいた奏者が一人、分からなかったことが一つ。これだけで、次に聴くときの的が自動的に決まる。分からなかったことは、たいてい次の週の課題になる。

## 曲の形がわかると、迷子にならない

![ジャズクラブでウッドベースを弾く奏者](https://kingsworksub-jpg.github.io/images/jazz-listening/bass-player.jpg)

*ベースを追うと曲の継ぎ目が見えてくる。一周の変わり目で動きが戻る*

（出典: Photo: CookipediaChef / <a href="https://commons.wikimedia.org/wiki/File:Len_Skeat_at_Upwell_Jazz_Club_-_Feb_2020.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

ジャズの演奏には、ほとんどの場合に共通する進行の型がある。短い導入があり、曲のメロディが一通り演奏され、そのあと奏者が順番に即興を取り、最後にもう一度メロディに戻って終わる。最初と最後に出てくるメロディの部分を「ヘッド」と呼ぶ。即興の部分では、曲の和音の流れを何周もくり返しながら、その上で自由に演奏している。この一周を「コーラス」と言う。

一周の長さは曲によって決まっている。古いポピュラーソングを下敷きにした曲なら、八小節のまとまりが四つ並ぶ三十二小節の形が多い。四つのうち三つ目だけ雰囲気が変わる並び方が典型で、この三つ目は「ブリッジ」と呼ばれる。ブルースを下敷きにした曲なら、十二小節で一周する。どちらの場合も、一周し終えると最初に戻るので、注意していると継ぎ目が聞こえてくる。

この継ぎ目が分かると、聴いている最中に「今どのあたりなのか」が掴める。ソロを取る奏者が交代するのは、たいてい一周の頭だ。サックスが何周か吹いて、次にピアノに渡り、そのあとベースが受け取る、という流れが見えるようになる。終盤で、管楽器とドラムが四小節ずつ交互に短いフレーズを投げ合うことがある。これは四小節の交換と呼ばれる定番の見せ場で、形を掴んでいると、ここで何が起きているのかがはっきり分かる。

継ぎ目を掴む近道は、やはりベースを追うことだと思う。ベースは一周の変わり目で必ず出発点の音に戻ってくるので、目印として使いやすい。慣れないうちは、指で四つ数えるのを四回くり返して十六小節、もう一度くり返して三十二小節、という具合に数えてみるといい。数えるのは最初の二、三回だけでよくて、そのうち数えなくても切れ目が感じ取れるようになる。この感覚が手に入ると、長い演奏が長く感じられなくなる。

## 六週間の聴く順番を組む

![ドラムセットでシンバルを叩くジャズドラマー](https://kingsworksub-jpg.github.io/images/jazz-listening/jazz-drummer.jpg)

*ライドシンバルの刻みとブラシの擦れる音。二週目はここだけを追う*

（出典: Photo: Mike a davies / <a href="https://commons.wikimedia.org/wiki/File:Billie_Davies_Female_Jazz_Drummer_1.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

ここまでの考え方を、六週間の順番に落とし込む。一週につき聴き取る対象を一つだけ決めて、その対象がはっきり聞こえる盤を二枚までに絞る。枚数を増やさないのがこつで、同じ盤を一週間かけて何度も聴くほうが、新しい盤を次々に足すより手応えがある。通勤中のような「ながら聴き」とは別に、週に二回ほど、十分だけ腰を据えて聴く時間を取れると理想的だ。

一週目はメロディを覚えることだけに使う。マイルス・デイヴィスの『Kind of Blue』は一九五九年の録音で、どの曲もゆったりしていて輪郭が掴みやすい。同じ年に出たデイヴ・ブルーベック・カルテットの『Time Out』は、四拍子ではない変わった拍子の曲を集めているのに、メロディは驚くほど覚えやすい。二週目はグルーヴとリズム隊に移る。アート・ブレイキーとジャズ・メッセンジャーズの『Moanin'』は一九五八年十月の録音で、ピアノのボビー・ティモンズが書いた表題曲の、あの呼びかけと応答のような出だしが有名だ。ブレイキーのドラムは終始主張が強く、ドラムだけを追う練習にはうってつけだと思う。

三週目は、前の章で書いた曲の形を数えることに充てる。ソニー・ロリンズの『Saxophone Colossus』は一九五六年の録音で、冒頭の「St. Thomas」は形が単純なうえに、ドラムのソロやベースの受け渡しがはっきりしているので、継ぎ目を探す練習がしやすい。四週目は奏者どうしのやりとりを聴く。ビル・エヴァンス・トリオの『Waltz for Debby』は、一九六一年六月二十五日にニューヨークのヴィレッジ・ヴァンガードで録音された。ピアノのエヴァンス、ベースのスコット・ラファロ、ドラムのポール・モチアンの三人が、伴奏と主役の役割を細かく入れ替えながら演奏していて、三人が互いの出方をうかがっている様子がそのまま記録されている。ラファロはこの録音の十日後に交通事故で亡くなっていて、この三人の演奏はこれが最後になった。

五週目は音色と編成の違いに耳を向ける。エラ・フィッツジェラルドとルイ・アームストロングが一九五六年に吹き込んだ『Ella and Louis』は、滑らかな歌としゃがれた歌が交互に出てくるので、声の質の違いがそのまま聴きどころになる。ハービー・ハンコックの『Maiden Voyage』は一九六五年の録音で、同じ管楽器でも響かせ方がまるで違うことが分かる。六週目は歴史の軸に戻す。ジョン・コルトレーンの『A Love Supreme』は一九六四年十二月の録音で、四つの部分が組曲としてつながっている。ここまでの五週間で身につけた聴き方を全部使わないと歯が立たない盤なので、締めくくりに置いている。

- 1：聴き取る対象 メロディを覚える / 聴く盤 Kind of Blue / Time Out / 合わせて読む本 『ゼロから分かる！ ジャズ入門』
- 2：聴き取る対象 グルーヴとリズム隊 / 聴く盤 Moanin' / 合わせて読む本 『ジャズの名盤入門』の該当項目
- 3：聴き取る対象 曲の形を数える / 聴く盤 Saxophone Colossus / 合わせて読む本 『ジャズ・スタンダード』で曲を引く
- 4：聴き取る対象 奏者どうしのやりとり / 聴く盤 Waltz for Debby / 合わせて読む本 『ポートレイト・イン・ジャズ』
- 5：聴き取る対象 音色と編成の違い / 聴く盤 Ella and Louis / Maiden Voyage / 合わせて読む本 『生きているジャズ史』
- 6：聴き取る対象 歴史の中に置き直す / 聴く盤 A Love Supreme / 合わせて読む本 『新書で入門 ジャズの歴史』

## 読む本を、聴く段階に合わせる

本を選ぶときに気をつけたいのは、通読しようとしないことだ。入門書を最初から最後まで読み切ってから聴き始めると、だいたい読み終わる前に力尽きる。その週に聴く盤や、その週の対象に関係する箇所だけを、聴く直前に数ページ読む。この使い方なら、六冊あっても負担にならない。

最初の一冊としては、後藤雅洋の『ゼロから分かる！ ジャズ入門』（世界文化社）が扱いやすいと思う。用語と楽器の役割が図版付きで整理されていて、一週目の土台になる。盤ごとの聴きどころを知りたくなったら、中山康樹の『[ジャズの名盤入門](https://bookclub.kodansha.co.jp/product?item=0000147268)』（講談社現代新書、二〇〇五年）が便利だ。五十枚を取り上げて、それぞれどこを聴けばいいのかを具体的に書いている。二週目以降、聴く前に該当する項目を一つ読む、という使い方に向く。

曲そのものを調べたくなったら、テッド・ジョイアの『[ジャズ・スタンダード 聴いて弾いて愉しむ252曲](https://www.msz.co.jp/book/detail/08772/)』（鈴木潤訳、みすず書房）がある。何度も演奏されてきた曲を二百五十二曲取り上げて、生い立ちと主要な録音を曲名から引ける事典で、六百八十八ページ、九千九百円という堂々とした本だ。最初に買う一冊ではないが、三週目あたりで「この曲は他の人も演奏しているのか」と思い始めたときに効いてくる。

歴史の背骨を一本通したいなら、相倉久人の『[新書で入門 ジャズの歴史](https://www.shinchosha.co.jp/book/610203/)』（新潮新書、二〇〇七年）が二百八ページでまとまっている。この音楽が生まれた背景を、人種や社会の動きと一緒に追う本で、六週目に読むと聴こえ方が変わる。読み物としての通史なら、油井正一の『生きているジャズ史』が立東舎文庫に入っている。一九五〇年代に雑誌へ連載された原稿がもとになっていて、同時代の空気がそのまま残っているのが面白い。息抜きの一冊としては、和田誠と村上春樹による『[ポートレイト・イン・ジャズ](https://www.shinchosha.co.jp/book/353407/)』（新潮文庫）を挙げたい。奏者の似顔絵に短い文章が添えられた本で、通して読む必要がなく、気になった名前のページだけ開けばいい。

## ライブで答え合わせをする

![ニューオーリンズの店で演奏するジャズバンド](https://kingsworksub-jpg.github.io/images/jazz-listening/jazz-vipers.jpg)

*小さな店の近い距離なら、誰が誰に反応したのかが目で見える*

（出典: Photo: Neworleansjazzvipers / <a href="https://commons.wikimedia.org/wiki/File:The_New_Orleans_Jazz_Vipers_at_the_Spotted_Cat_Music_Club_on_Frenchmen_Street,_2013.jpg" target="_blank" rel="noopener">CC BY-SA 3.0</a>）

録音で曲の形を掴んだら、どこかの段階で生の演奏を聴きに行ってほしい。録音では耳だけで探っていた継ぎ目が、ライブだと目で見える。ソロを終えた奏者が次の人のほうを向く、ドラムが一周の頭でシンバルを強く鳴らす、ピアノがうなずく。録音を聴いているときに想像していたやりとりが、そのまま目の前で起きているのが分かる。

最初に行くなら、大きなホールより小さな店のほうがいい。奏者との距離が近いほど、誰が誰に反応したのかが掴みやすいからだ。拍手の作法は一つだけ覚えておけば困らない。曲が終わったときだけでなく、一人のソロが終わった時点で拍手が起きる。周りに合わせていれば自然にできるようになるし、外したところで誰も気にしていない。

生で聴くと、録音で聴いていた盤の印象も変わる。同じ曲でも、その日の客の入りや奏者の調子で中身が入れ替わるのが当たり前だと分かるからだ。録音は、無数にあった演奏のうちのある一回が、たまたま記録されたものにすぎない。そう思えるようになると、名盤という言葉の重さが少し軽くなって、聴くのが気楽になる。

## 六週間のあとに残るもの

六週間を終えても、聴いていない名盤のリストは減らない。むしろ増える。ただ、リストとの付き合い方は変わっているはずだ。一枚目をかけるときに「今日はベースを追う」と決められるようになっていて、聴き終わったあとに書けることが「悪くなかった」以外に三つはある。この状態になれば、あとは放っておいても聴き続けられると思う。

順番や盤は、ここに書いたとおりでなくてもかまわない。大事なのは、一週につき的を一つに絞ることと、読む本をその的に合わせることの二つだけだ。五十枚を順番に消化しようとして三枚で止まるくらいなら、五枚を六週間かけて聴き込んだほうが、結局は遠くまで行ける。
