音楽理論の独学は最初の一冊で止まりがちだ。3か月で一周させるには、書を「通読する本」から「引く本」に変え、鍵盤で音程と度数を確かめ、アプリで反復し、三か月目にだけ代理和音まで手を伸ばす。毎月ごとに書とアプリとの割り当てを具体的に書いた計画。

音楽理論の独学は、最初の一冊で止まりやすい。
意味そのものは分かる。
でも次へ進めない。
語彙は増えるのに、和音の機能は頭に入らない。

これは努力不足ではない。
最初から最後まで通読する、という目的そのものが途中で崩れるからだ。

三か月で一周させるには、目的を置き換える。
本を一冊だけ選ぶ。ただし通読するのをやめる。
必要なページだけ開き、残りは目次として使う。
記憶の判定はアプリに任せる。
記号を距離に変えるのは鍵盤の仕事。

こうすると三つの役割が分かれる。
本は説明のソース。わからないときの答え合わせ。
アプリは記憶の受け皿。判定と反復を担当する。
鍵盤は記号を距離に変える層。

## 通読をやめると、三か月で配れるようになる

三か月の割り方で私が迷ったのは、毎日何分やるかではなかった。
それは最後に述べる。
先に決めるべきは、途中で主教材を入れ替えるかどうかだ。

三か月とも同じ本を使うと、途中で息切れが起きる。
そのときに、本が厚すぎると感じる。
でも本を変えても同じところで止まるなら、それは本のせいではない。
やろうとしていることが通読だからです。

ここが今回の配分の出発点になる。
本の難易度は問題ではない。
最後まで読む、という目標が問題だ。

![机上に置かれた25鍵のMIDIキーボード、白鍵と黒鍵が一列に並ぶ](https://kingsworksub-jpg.github.io/images/music-theory-3month/midi-keyboard.jpg)

*鍵盤は記号を距離に変える層。指が動く先がないと、本は読めても音にならない*

（出典: Photo: Morn / <a href="https://commons.wikimedia.org/wiki/File:Samson_Graphite_25_MIDI_keyboard.jpg" target="_blank" rel="noopener">CC BY-SA 4.0</a>）

Amazonで見る: https://www.amazon.co.jp/s?k=MIDI%E3%82%AD%E3%83%BC%E3%83%9C%E3%83%BC%E3%83%89&tag=nakimoto1-22

三か月を順に割るとき、書もアプリも一つに固定する。
変えるのは三か月目の主教材だけ。
これが配分の要点だ。

## 第1か月：音程と度数

音程を飛ばして和音へ進むことがある。
結果は単純で、和音が聞き取れなくなる。
理由は和音の名称が、音程だけでは決まらないからだ。
同じ三音でも、調が変われば別の名前になる。

一か月目は音程と度数を両方やる。
順序はこうする。
先に指で位置を覚えて、そのあと本を読む。
逆順だと、読んでいても指が動く先を知らない。

鍵盤での練習はこうする。
すべての白鍵に指を置き、音名を対応づける。
次に黒鍵を加える。
音程は、指を何個飛ばすかで分かる。
度数も同じ。基音から指がどこにあるか、で決まる。

![白い鍵盤の上に指が乗ったところ、斜め上から見た鍵の反射](https://kingsworksub-jpg.github.io/images/music-theory-3month/keys.jpg)

*度数とは記号ではなく、鍵と鍵の距離のこと*

（出典: Photo: Gabriel Barletta / <a href="https://commons.wikimedia.org/wiki/File:Fingers_on_the_piano_keys_(Unsplash).jpg" target="_blank" rel="noopener">CC0</a>）

耳の訓練は musictheory.net だけで足りる。
音程、音階、和音、鍵盤の四つに分かれていて、ブラウザだけで動く。
繰り返しの回数に制限がない。アカウントも要らない。

ただ、このサイトは孤立した識別だけだ。
基音から何番目かを問われることはない。
一か月目の主題は度数なので、ここに隙間が残る。

その隙間を埋めるのが Functional Ear Trainer だ。
先に基音を鳴らし、次の音が基音の何番目かを問う。
度数という概念をそのまま問えるので、要る場所に合っている。
文字に頼らない訓練なので、画面が日本語でなくても使える。
iPhone と iPad と Mac と Android に出ている。

一か月目の合格基準はひとつ。
任意の基音について、七つの度のどれかを三秒以内に言えたら合格。

## 第2か月：三和音・疑似和音・進行

二か月目の流れはこう並べる。
三和音を構成する。
転位を求める。
疑似和音を加える。
そのうえで進行を弾く。

よく省略されるのが転位。
三和音にも七和音にもある。
根音の位置が変わるだけで、音の印象は変わる。
構造は同じなのに響きが違う、という感覚が、そのまま進行の判断材料になる。

疑似和音はここで入れる。
半減七和音と減七和音のことだ。
三か月目まで遅らせると、その先がきつくなる。

![古い手書きの楽譜で、密集した音符と和音記号がページいっぱいに並ぶ](https://kingsworksub-jpg.github.io/images/music-theory-3month/manuscript.jpg)

*手書きの和声記号は電報のように密集している。和声の練習とは、その密集を動かせる塊に割る作業である*

（出典: Photo: Wilhelm Friedemann Bach / <a href="https://commons.wikimedia.org/wiki/File:Six_Polonoises_-_Pour_Le_Clavecin_ou_forte_piano_-_compos%C3%A9es_par_-_Guillaume_Friedemann_Bach._-_ci_devant_fameux_organiste_%C3%A0_Halle._-_NB._Ce_manuscript_est_%C3%A9crit_de_la_main_de_l%27auteur_-_btv1b10535113t_(02_of_12).jpg" target="_blank" rel="noopener">Public domain</a>）

耳の訓練には、ここから Complete Ear Trainer を加える。
このアプリは、和音の識別だけでなく分解や進行も見る。
iPhone と Android の両方に対応している。
和音の練習だけなら無料で使える部分がある。

なお、一か月目の度数訓練はそのまま続けておく。
度数を固める前に和音へ寄せると、また壁に来る。

最後に、右手で単音、進行をひととおり弾いておく。
四つの型のそれぞれを、大調と小調の両方で。
この工程を抜くと、三か月目は途中から全部が難しくなる。

## 第3か月：代理和音と変則和声

三か月目の課題は、進行の先にある。
ここまではダイアトニックの中だけだった。
ここから先は、その外へ出る。

![十九世紀の笛の教本の一ページ。上部に題字、下部に音符と和音の記号が並ぶ](https://kingsworksub-jpg.github.io/images/music-theory-3month/theory-book.jpg)

*和声記号の書き方は三百年ほぼ変わっていない。だから使うのは記号ではなく機能である*

（出典: Photo: Henri Altès / <a href="https://commons.wikimedia.org/wiki/File:Grand_method_for_flute,_part._I_-_containing_complete_theory_of_music,_-_by_Henry_Alt%C3%A8s..._-_bpt6k11621179_(017_of_110).jpg" target="_blank" rel="noopener">Public domain</a>）

用語を先に整理しておく。

代理和音は、属和音が別の調に一度逃げるやつ。
記号では V/V と書く。
その次に来るのは V。

変旋和音は、ダイアトニックの外側に一時的に入る和音。
C の半減七和音などが代表例。

どれからやるかは好みで決めてよい。
ここでは一般的な順に並べる。

一、代理和音。
V/V から V に戻るという構造なので覚えやすい。
解析でも作曲でも、最初にここへ目を置くのが手堅い。

二、半減七と減七。
これは絶対に必要な部品。
ここを飛ばすと三か月目の残りが全部きつくなる。

三、変則和音の響き。
ここが三か月目の本体。
単純な進行だけだと、なぜこの和音が効いて聴こえるのかが分からない。
ここを通すと、聴取の次元が一つ上がる。

一周しただけで完成ではない。
三か月は一周であって、完成ではない。
一周した知識が使えるものになるには、もう一巡が必要だ。

## 三か月分の内訳

- 第1か月：書 手元にある本を引く / アプリ musictheory.net と Functional Ear Trainer / 鍵盤でやること 音程と度数を全音
- 第2か月：書 同じ本を引く / アプリ Complete Ear Trainer と Functional Ear Trainer / 鍵盤でやること 転位と四つの進行
- 第3か月：書 新しい本を一通り / アプリ Complete Ear Trainer（進行） / 鍵盤でやること 半減七、減七、代理和音

書は三冊で足りる。

一冊目は手元にあるもので構わない。
和弦の構成と終止式が引ける本ならそれでいい。
出版社も厚度も関係ありません。

二冊目は補助。
毎日五分だけ開く運用なので、軽いものが向いている。

三冊目が本体。
三か月目に一通り目を通すだけでいい。
その後の順序は任意。

この配置のポイントは、**一か月目と二か月目の本を同じにする**こと。
毎日同じ場所を開けるので、ページを探すコストが要らない。
三か月目になって初めて場所が変わる。

三か月目の本には二通りある。
日本語の分厚い資料と、英語だが章立てが明快な教科書。
前者は実例集で、後者は理屈が文章で書かれている。
両方を読む必要はなく、片方に絞ってよい。
英語に抵抗があるなら、二か月目まで日本語の本でそろえておくと、導入が楽になる。

- [MIDIキーボード で探す（Amazon）](https://www.amazon.co.jp/s?k=MIDI%E3%82%AD%E3%83%BC%E3%83%9C%E3%83%BC%E3%83%89&tag=nakimoto1-22)
- [コード理論大全 で探す（Amazon）](https://www.amazon.co.jp/s?k=%E3%82%B3%E3%83%BC%E3%83%89%E7%90%86%E8%AB%96%E5%A4%A7%E5%85%A8&tag=nakimoto1-22)

鍵盤は二十五鍵で足りる。
三か月だけなら、三十七鍵でも不足はない。
鍵数が少ないぶん、鍵に色が付いていて、音と指が見分けやすい。

## 毎週三行だけ記録する

独学で一番多いのは、努力のかけ方がばらつくことだ。
ある週は本を読む翌週はアプリだけ、というように。
注意がばらけると、三か月を浅く広くやる形になって、終わりが来ない。

逃げ道は一つ。毎週三行を書く。

- 今週に何をしたか。どのページを引いたか。
- 鍵盤で何を弾いたか。どの進行を両手で。
- 来週は何をするか。一条だけでいい。

これで十二週間ぶんが三十六行になる。
三か月が終わったら順番に読み返す。

最初に気づくのは、空の行が二つ三つあることだ。
その二つ三つが、そのまま答えを教えてくれる。

自分の場合、二か月目の途中に空の週が一つあった。
理由は、最初から最後まで読もうとしたこと。
三か月目の本に変えたときも、同じことをして、また一つ空いた。

だから守るルールは一つだけでいい。
主教材は最初から最後まで読まない。
それ以外は全部妥協してよい。

## まとめ

三か月で一周させる設計は、こうだった。

- 第1か月は音程と度数に全振りする。指の位置を確定させる。暗記は次の話だ。
- 第2か月は三和音と転位と疑似和音をつなぐ。進行を弾く工程を省略しない。
- 第3か月は代理和音、半減七と減七、変則和音の響き。ここで初めて教材を替える。

一番の反省は、主教材は一冊だけという規則を途中で破ったこと。
一冊だけを持つ前提は、三か月目がその範囲を超える瞬間に効かなくなる。

費用のかけ方はこうだった。
鍵盤は二十五鍵の入門機で足りる。
耳の訓練は一か月目を無料のブラウザ版で済ませ、二か月目から有料版を一つ足す。
三つ入れてはいやになる。

三か月を最初から終わらせず、一周として敷居を上げておくと、四年目の自分のほうが多少は使える状態になっている。
焦らず、かつ手を動かさないこと。
指はもう動いている。
自分の耳を信じる。
